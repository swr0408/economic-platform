# 価格転嫁率（中小企業庁）手動インポート

配布元 `chusho.meti.go.jp`（METI/Akamai）が当サーバIPをブロックし、PDFの自動
ダウンロードが ReadTimeout で失敗する場合の**確実な取得経路**です。

## 使い方

1. ブラウザ等で以下のPDFを取得する（社内ネットや別端末など、ブロックされない経路で）:
   `https://www.chusho.meti.go.jp/keiei/torihiki/follow-up/dl/{YYYYMM}/result_01.pdf`
   - `YYYYMM` は**調査月**（3月調査=`202603`、9月調査=`202609`）。
   - 例: 2026年3月調査 → `https://.../dl/202603/result_01.pdf`

2. このディレクトリに **`{YYYYMM}.pdf`** という名前で置く（調査月。MMは `03` か `09`）。
   - 例: `202603.pdf` / `202609.pdf`

3. 次回の更新（週次スケジューラ／バックエンド再起動時のキャッチアップ／
   管理画面「今すぐ更新」）で `_import_manual_pdfs()` が自動で解析・DB取込する。
   既存ネット取得と同じパーサー（`_parse_pdf`）を使う。

## 補足

- ネット取得は1実行=1本のみ・週次に抑制済み（Akamai BAN回避）。一度BANされると
  単発でも数時間ダウンするため、ブロック中はこの手動経路が確実。
- 取込後、ダッシュボード集約キャッシュ `japan:price:dashboard:v1` の削除で
  チャートに即反映される（または週次更新を待つ）。
- 半年次。公表時期: 3月調査→6月下旬 / 9月調査→12月。
