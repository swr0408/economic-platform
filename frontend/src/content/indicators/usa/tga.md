## TGA（Treasury General Account / 財務省一般勘定）

TGAは、米財務省がFRBに保有する政府の運転資金口座です。実務上は「米財務省の当座預金・決済口座」に近く、税収、国債発行による調達資金、政府支出、国債利払いなどの資金フローがこの口座を通じて処理されます。米財務省のDaily Treasury Statementでは、政府の営業現金残高、入金・出金、公的債務取引、税還付などが日次で確認でき、財務省の営業現金はニューヨーク連銀の口座で管理されています。

## TGAを見る意味

TGAは、米国の短期金融市場やドル流動性を見るうえで重要です。理由は、TGAの増減がFRBバランスシートの負債側で「準備預金」と入れ替わるためです。TGAが増えると、銀行システム内の準備預金が減りやすくなります。反対に、TGAが減ると、政府支出などを通じて民間部門へ資金が戻り、準備預金が増えやすくなります。

重要なのは、TGAの増減だけではFRBの総資産が増減するわけではない点です。税金の支払いなどでTGAが増える場合、FRBの負債側で「銀行準備預金」が減り、「TGA」が増えるだけです。したがって、TGAはQEやQTそのものではなく、FRBバランスシート内の流動性配分を変える要因として扱います。

## 基本的な読み方

TGA上昇は、一般にドル流動性に対して引き締め方向です。税収の入金、国債発行による資金調達、政府が支出より多く資金を吸収している局面では、民間部門や銀行システムから財務省口座へ資金が移り、準備預金を減らしやすくなります。

TGA低下は、一般にドル流動性に対して緩和方向です。政府支出、社会保障給付、利払い、還付金などによってTGAから民間部門へ資金が流れると、銀行準備預金が増えやすくなります。St. Louis Fedは、社会保障給付や国債利払いでTGAが減ると受け取り側の銀行の準備預金が増える一方、4月中旬の税収期にはTGAが増え、準備預金が減りやすいと説明しています。

## 主な変動要因

TGAは、毎月・四半期・年度末の財政資金フローで大きく変動します。特に重要なのは、4月中旬の所得税入金、四半期の法人税入金、国債入札・発行、政府支出、社会保障給付、国債利払い、債務上限問題に伴うTGA取り崩し・再積み上げです。ニューヨーク連銀は、債務上限問題の間は財務省がTGAを取り崩すことで準備預金が一時的に増え、債務上限解決後にTGAを再構築すると準備預金を吸収して短期金融市場を引き締めやすいと説明しています。

近年のTGAは、財務省の現金管理方針の影響も受けます。ニューヨーク連銀によれば、2015年以降の財務省の現金管理方針では、TGAからの1週間分の資金流出を賄える程度の現金を保有する方針が採られており、経済規模や連邦債務の拡大とともに必要な現金残高も名目ベースで大きくなりやすい構造があります。

## 市場への影響

TGAの増加は、単独では「市場から資金を吸収する方向」として扱います。特にFRBのQTで準備預金が減っている局面や、ON RRP残高が小さくなっている局面では、TGA再積み上げによる流動性吸収が短期金利、レポ金利、SOFR、Tビル需給に影響しやすくなります。ニューヨーク連銀は、TGA再構築とバランスシート縮小が重なった局面でシステム流動性が低下し、レポ市場の金利上昇圧力が強まったと説明しています。

ただし、TGAの増加が必ず株安・ドル高・金利上昇を意味するわけではありません。市場への影響は、同時期のFRB資産規模、準備預金残高、ON RRP、国債発行年限、Tビル需要、MMF資金、レポ市場の需給、税収・支出カレンダーによって変わります。FRBのFEDS Notesでは、QTや財務省証券発行がレポ金利の感応度を高める可能性があり、その影響は準備預金やON RRPなどのFed-provided liquidityの水準によって変化すると分析されています。

## 併せて見るべき指標

TGA単体ではなく、次の指標と組み合わせて確認します。

| 指標 | 見る意味 |
| --- | --- |
| 準備預金残高 | TGA増減が銀行システムの流動性にどれだけ影響しているかを見る |
| ON RRP | MMFなどの余剰資金バッファーが残っているかを見る |
| SOFR・TGCR・レポ金利 | 短期金融市場の逼迫度を見る |
| 米国債発行予定 | TGA再積み上げの資金調達圧力を見る |
| Daily Treasury Statement | 日次の入出金、現金残高、債務取引を確認する |
| H.4.1 | 週次でFRBバランスシート上のTGA・準備預金・RRPを確認する |

## 実務的な判断ポイント

TGAが急増している場合は、税収入金や国債発行による財務省の資金吸収が進んでいる可能性があります。この場合、準備預金やON RRPが同時に減っているかを確認します。準備預金とON RRPが大きく減り、SOFRやレポ金利が上昇している場合は、短期金融市場の流動性が引き締まっている可能性を重視します。

TGAが急減している場合は、政府支出や債務上限制約下でのTGA取り崩しによって、民間部門へ資金が戻っている可能性があります。この場合、準備預金が増えているか、短期金利の上昇圧力が和らいでいるかを確認します。

TGAが高水準でも、ON RRPが十分に残っている場合やFRBが流動性供給を行っている場合は、市場への引き締め効果が吸収されることがあります。一方、ON RRPが枯渇に近く、準備預金も低下している局面では、TGAの追加上昇が短期金融市場に与える影響は大きくなりやすくなります。
