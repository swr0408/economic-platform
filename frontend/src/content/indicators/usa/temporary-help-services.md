# 臨時社員（Temporary Help Services）

## 概要

臨時社員の動向を見るとき、実務で一般に参照されるのは、BLS（米労働統計局）の Temporary Help Services 雇用です。これは派遣・臨時スタッフを供給する事業所の雇用者数を示す系列で、米雇用統計の事業所調査（CES）に含まれています。これは「短時間労働者全体」や「一時的な仕事に就く人全体」と同義ではなく、BLS 上はあくまで temporary help agency workers を中心に捉える指標です。

## なぜ注目されるのか

この指標が注目される理由は、企業が需要変動に対して正社員よりも機動的に調整しやすい雇用だからです。需要が回復し始めた局面では、企業は本格採用の前段階として臨時スタッフの活用を増やしやすく、逆に需要が鈍化した局面では、正社員の削減に先立って臨時スタッフの利用を絞りやすくなります。BLS も、Temporary Help Services の雇用変化は米国全体の雇用変化に先行しやすいと説明しており、Conference Board もこれを雇用先行指数（Employment Trends Index）の構成要素として採用しています。

## 増加・減少の意味

臨時社員の増加は、企業の採用意欲や需要の持ち直しを示すことが多く、景気や総雇用の改善を先取りする材料として見られやすくなります。反対に、臨時社員の減少は、企業がまず変動的な労働投入から絞り始めている可能性を示し、雇用環境の軟化を示唆しやすくなります。Conference Board も temporary help services を hiring の先行指標と位置づけています。

## 先行性の位置づけ

この指標は失業率のような遅行指標ではなく、非農業部門雇用者数や採用動向に対する短期の先行指標とみるのが適切です。ただし、常に景気全体に対して機械的に先行するわけではありません。景気減速局面でも、企業が人手不足を警戒して雇用を抱え込む場合や、業種ごとの調整差が大きい場合には、通常よりシグナルが鈍ることがあります。したがって、「必ず最初に増える」「必ず真っ先に削られる」と断定するより、比較的早い段階で増減が表れやすい指標と捉えるのが実務的です。

## 見方のポイント

単月の増減だけで判断するより、数か月単位の方向性を見ることが重要です。1か月だけの増加・減少はノイズを含みやすいため、3か月前比や半年程度のトレンドで確認したほうが、企業の採用スタンスの変化を捉えやすくなります。また、臨時社員だけで景気や雇用の強弱を断定するのではなく、失業保険申請件数、JOLTS 求人件数、失業率、平均労働時間などと併せて読むと精度が上がります。失業保険申請件数は労働市場の悪化を早く示しやすい週次の先行指標であり、JOLTS は求人・採用・離職を通じて労働需要を確認するために有用です。

## 実務上の整理

臨時社員の増加は企業が需要増加に対応し始めているサイン、臨時社員の減少は企業が雇用調整を先行的に始めているサインと捉えるのが基本です。したがって、景気と雇用の転換点を早めに察知するうえで有用ですが、単独で結論を出す指標ではなく、労働市場全体の補助指標として使うのが適切です。
