## 指標・資料の位置づけ

**Quarterly Refunding（四半期定例入札・借換発表）**は、米財務省が四半期ごとに公表する、米国債の発行計画・借換計画・市場性国債の資金調達見通しに関する公式資料群です。単一の経済指標ではなく、米国債の供給量、年限構成、短期証券と中長期債の発行バランス、TGAの想定残高、TBACの提言、入札予定、買入れオペ予定などをまとめて確認するための債券市場向け資料です。米財務省自身も、債務管理政策の変更は通常、四半期ごとのリファンディング過程を通じて検討・伝達されると説明しています。

Quarterly Refundingは、米国債市場における「供給サイド」の最重要イベントの一つです。FOMCが金融政策の需要・金利環境を示すイベントだとすれば、Quarterly Refundingは財務省がどの年限で、どの程度の国債を市場に供給するかを示すイベントです。特に米10年債利回り、米30年債利回り、タームプレミアム、ドル、株式市場、金、金融環境の分析で重要になります。

## 公表主体・公表頻度・確認先

公表主体は**U.S. Department of the Treasury（米財務省）**です。米財務省はQuarterly Refundingのページで、四半期ごとに米国債発行・債務管理政策に関する資料やデータを公表しています。

公表は四半期ごとで、通常は2月・5月・8月・11月の四半期リファンディング期に行われます。TreasuryDirectは、米国債入札スケジュールは通常、2月・5月・8月・11月の第1水曜日に行われるQuarterly Refundingの記者会見で公表されると説明しています。

## 主要資料の読み方

### Financing Estimates（市場性国債の借入見込み）

Financing Estimatesは、米財務省が今後の四半期にどの程度の**privately-held net marketable borrowing（民間保有ベースのネット市場性国債借入）**を見込んでいるかを示す資料です。これは米財務省の資金調達見通しを見るうえで最初に確認すべき項目です。

見るべき項目は、主に以下です。

| 項目 | 意味 |
| --- | --- |
| Borrowing Estimate | 対象四半期に民間市場からどれだけネットで資金調達する見込みか |
| End-of-Quarter Cash Balance | 四半期末のTGA、つまり財務省一般勘定の想定残高 |
| 前回見通しとの差 | 借入見込みが上方修正・下方修正されたか |
| 修正理由 | 税収、歳出、期初現金残高、償還、SOMA関連などの影響 |

重要なのは、借入見込みが大きく増えても、それがすぐに長期金利上昇を意味するわけではない点です。増加分がT-Bill中心で吸収されるのか、中長期債の増発で吸収されるのかによって、市場インパクトは大きく異なります。

### Policy Statement（Quarterly Refunding Statement）

Policy Statementは、Quarterly Refundingの中核資料です。実際の借換入札の金額、年限、今後の発行方針、T-Bill、TIPS、FRN、Buybackに関する方針が記載されます。

同資料では、四半期中の残りの資金調達は、定例のT-Bill入札、Cash Management Bills、月次の国債、TIPS、2年FRN入札で賄うと説明されています。

## 最重要チェック項目

### 1. 借入見込みの増減

まず確認すべきは、次の四半期・その次の四半期の借入見込みが前回から増えたか、減ったかです。増加している場合、米財務省がより多くの国債を発行する必要があることを意味します。ただし、利回りへの影響はどの年限で発行するかに依存します。

短期証券中心であれば、影響は主に短期金融市場、T-Bill需給、MMF、ON RRP、TGA、準備預金に出やすくなります。中長期債中心であれば、10年債・30年債利回り、タームプレミアム、株式バリュエーション、ドル、金利感応株への影響が強まりやすくなります。

### 2. Coupon Auction Sizes（中長期債の入札サイズ）

市場が最も注目するのは、2年・3年・5年・7年・10年・20年・30年債の入札サイズです。特に10年債、20年債、30年債の増額は、デュレーション供給の増加として受け止められやすく、長期金利やタームプレミアムに影響しやすい項目です。

2026年5月の声明では、財務省は現行の入札サイズで財政見通しやSOMAポートフォリオの変化に対応できるとし、名目クーポン債とFRNの入札サイズを少なくとも今後数四半期は維持する見通しを示しました。

### 3. T-Billで吸収するのか、Couponで吸収するのか

借入需要が増えても、財務省が短期証券であるT-Billを増やして吸収する場合と、中長期債を増やして吸収する場合では市場への影響が異なります。

T-Bill中心の場合、長期金利への直接的な圧力は限定されやすい一方、短期金融市場の資金吸収、ON RRP残高、MMFの投資先、TGA増減、銀行準備預金に影響します。Coupon中心の場合、デュレーション供給が増えるため、長期金利上昇やタームプレミアム拡大の材料になりやすくなります。

### 4. TGA想定残高

TGAは米財務省がFRBに保有する口座です。TGA残高が増える局面では、市中から資金が吸収されるため、銀行準備預金や短期金融市場の流動性に影響する場合があります。逆にTGAが取り崩される局面では、市中流動性を押し上げる方向に働きやすくなります。

Financing Estimatesでは、借入見込みと同時に四半期末のTGA想定残高が示されます。借入額だけでなく、借入によってTGAを積み上げるのか、財政支出に使うのかを区別して読む必要があります。

### 5. TBAC Report / TBAC Minutes

TBACはTreasury Borrowing Advisory Committeeの略で、米財務省に対して国債発行・債務管理に関する助言を行う委員会です。米財務省は、Primary Dealerとの面談後にTBACから助言を受け、TBACは財務長官向けの正式な報告書を出し、会合議事録は翌日に公表されると説明しています。

TBAC ReportとMinutesは、単なる結果発表ではなく、市場関係者が財務省に何を提言しているかを読む資料です。特に以下を確認します。

| 確認項目 | 見方 |
| --- | --- |
| Coupon増額の必要性 | 今後の中長期債増発リスクを判断 |
| T-Bill比率 | 短期債依存が高まっているか |
| 財政見通し | 赤字・借換需要が拡大しているか |
| SOMA・FRB保有国債 | QTや償還が資金調達に与える影響 |
| 市場流動性 | 国債市場の需給・流動性リスク |
| Buyback | 流動性改善や古い銘柄の需給調整策 |

2026年5月のTBAC Minutesでは、現行の発行サイズは2026年度残りの借入需要を満たすには十分だが、現在のクーポン入札サイズとBill供給を前提にすると、Primary Dealerの中央値予測では2027〜2028年度に1.3兆ドルの資金調達不足が示唆されると説明されています。

## 市場への影響

### 米国債利回り

Quarterly Refundingで中長期債の入札サイズが増える、または将来的な増額が示唆される場合、米国債市場ではデュレーション供給増加として受け止められやすくなります。特に10年債・20年債・30年債の増額は、長期金利上昇やタームプレミアム拡大の材料になります。

一方で、借入増加をT-Billで吸収する方針が示される場合、長期金利への直接的な上昇圧力は相対的に限定されやすくなります。ただし、T-Bill増発は短期金融市場の需給、MMF、ON RRP、TGA、銀行準備預金に影響するため、流動性面の確認が必要です。

### ドル

米国債利回りが上昇する場合、金利差の観点からドル高材料になりやすい一方、財政悪化懸念や米国債需給悪化が意識される場合は、ドルの信認・リスクプレミアム面で逆方向に働くこともあります。したがって、Quarterly Refundingは単純に「借入増＝ドル高」と読むのではなく、米金利、財政リスク、リスク選好、海外投資家需要を合わせて判断します。

### 株式市場

中長期債増発によって長期金利が上昇する場合、株式市場にはバリュエーション面で逆風になりやすくなります。特にグロース株、ハイテク株、不動産、公益、REITなど金利感応度の高いセクターは影響を受けやすいです。

一方、T-Bill中心の資金調達で長期金利が安定する場合、株式市場への直接的な金利上昇圧力は抑えられやすくなります。ただし、TGA積み上げによる流動性吸収が大きい場合は、リスク資産にとってマイナス材料となる可能性があります。

### 金・コモディティ

米長期金利の上昇は、金にとっては実質金利上昇を通じて逆風になりやすいです。ただし、財政悪化懸念や米国債需給不安が強まる場合、金は安全資産・通貨代替として買われることもあります。Quarterly Refundingを見る場合は、名目金利だけでなく、実質金利、ドル、財政リスク、地政学リスクも同時に見る必要があります。

## 実務上の読み方

Quarterly Refundingを見る際は、次の順番で確認すると整理しやすくなります。

1. **Financing Estimatesで借入見込みを確認する**: 借入見込みが前回から増えたか、減ったかを確認します。あわせて四半期末TGA想定残高も確認します。
2. **Policy Statementで入札サイズを確認する**: 2年、3年、5年、7年、10年、20年、30年、FRN、TIPSの入札サイズが増額・据え置き・減額されたかを確認します。
3. **Bill Guidanceを確認する**: 追加の資金調達をT-Billで吸収するのか、CMBを使うのかを確認します。
4. **TBAC Report / Minutesを確認する**: 今回の決定だけでなく、次回以降の増額リスク、Primary Dealerの見方、財政見通し、SOMA、国債市場の流動性論点を確認します。
5. **Auction Scheduleを確認する**: 実際の入札日、発表日、決済日を確認します。入札が集中する週は、金利・ドル・株式市場のボラティリティが高まりやすくなります。
6. **Buyback Scheduleを確認する**: 米財務省の買入れオペが流動性支援目的なのか、キャッシュマネジメント目的なのかを確認します。Buybackは国債市場の特定年限・特定銘柄の需給に影響する場合があります。

## 判断の目安

| 内容 | 市場の受け止め方 |
| --- | --- |
| 中長期債の入札サイズ増額 | 長期金利上昇・タームプレミアム上昇要因 |
| 10年・20年・30年債の増額 | デュレーション供給増として特に重要 |
| 借入増をT-Bill中心で吸収 | 長期金利への直接圧力は相対的に限定的 |
| TGA積み上げ | 市中流動性の吸収要因 |
| TGA取り崩し | 市中流動性の供給要因 |
| TBACが将来のCoupon増額を示唆 | 次回以降の長期金利上昇リスク |
| Buyback拡大 | オフ・ザ・ラン銘柄の流動性改善材料 |
| TIPS増額 | インフレ連動債需給・実質金利に影響 |
