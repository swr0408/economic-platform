## FRB総資産とは

FRB総資産とは、一般的には米国連邦準備制度の連結総資産を指します。厳密には、FRB本体だけではなく、12の連邦準備銀行を連結したバランスシート上の総資産です。公式統計では、FRBの週次統計 H.4.1 "Factors Affecting Reserve Balances of Depository Institutions and Condition Statement of Federal Reserve Banks" に掲載されます。H.4.1は、各連邦準備銀行のバランスシート、12地区連銀の連結バランスシート、預金取扱機関の準備預金に影響する要因、その他の資産・負債・コミットメント情報をまとめた統計です。

市場でよく参照される系列は、FRED上の WALCL：Assets: Total Assets: Total Assets (Less Eliminations from Consolidation): Wednesday Level です。単位は百万ドル、頻度は週次、基準日は水曜日時点、季節調整なしです。

## FRB総資産で何を見るのか

FRB総資産は、米国中央銀行のバランスシート規模を示す代表的な指標です。主に、金融政策の量的側面、すなわち量的緩和（QE）・量的引き締め（QT）・流動性供給・金融ストレス対応を確認するために使われます。

FRB総資産が増える主な要因は、米国債やMBSの買入れ、レポ取引、金融機関向け貸出、中央銀行間スワップ、各種流動性ファシリティの利用拡大などです。一方、総資産が減る主な要因は、保有証券の満期償還・期限前償還、再投資停止、貸出や流動性ファシリティの返済、レポ残高の減少などです。

重要なのは、総資産の増加＝常にリスクオン、総資産の減少＝常にリスクオフではないという点です。たとえば、QEによる資産買入れで総資産が増える場合は金融緩和的に解釈されやすい一方、銀行不安時の緊急貸出で総資産が増える場合は、むしろ金融ストレスの発生を示すことがあります。

## 主な構成項目

FRB総資産の中心は、米国債と政府機関MBSです。H.4.1の連結バランスシートでは、2026年5月6日時点で総資産は6,709,505百万ドル、証券保有残高は6,417,568百万ドル、そのうち米国債は4,434,161百万ドル、MBSは1,981,060百万ドルです。つまり、FRB総資産の大部分は、米国債とMBSで構成されています。

主な項目は以下です。

| 項目 | 内容 | 見方 |
| --- | --- | --- |
| 米国債 | Treasury bills, notes, bonds, TIPSなど | QE/QTや再投資政策の中心 |
| MBS | 政府機関保証の住宅ローン担保証券 | 住宅金融・長期金利・信用配分に関係 |
| 貸出 | Primary credit、BTFPなど | 金融機関の資金繰り・ストレス確認に有用 |
| レポ | Repurchase agreements | 短期金融市場への資金供給 |
| 中央銀行流動性スワップ | 外国中銀向けドル供給 | ドル資金市場の緊張度を確認 |
| その他資産 | 外貨建て資産、未収収益、施設関連資産など | 通常は補助的項目 |

なお、H.4.1では米国債やMBSの一部項目が額面・現在額面、未償却プレミアム・ディスカウントなどとして表示されます。したがって、FRB総資産は市場価格ベースの保有証券評価額そのものではなく、H.4.1上の会計ベースのバランスシート指標として読む必要があります。

## QE・QTとの関係

FRBが米国債やMBSを買い入れると、FRBの資産側に証券が増え、負債側には銀行準備預金などが増えます。これが量的緩和、いわゆるQEです。QEは長期金利の低下、金融環境の緩和、リスク資産価格の押し上げ要因として意識されます。

反対に、FRBが保有証券の満期償還分を再投資せず、バランスシートを縮小させる政策がQTです。2022年以降のQTでは、FRBは保有証券の償還分を一定の上限まで再投資しない形で、バランスシート縮小を進めました。2022年時点の計画では、米国債は当初月300億ドル、のち月600億ドル、政府機関債・MBSは当初月175億ドル、のち月350億ドルの上限で縮小する方針が示されていました。

その後、2025年10月29日のFOMCでは、2025年12月1日に保有証券の縮小を終了することが決定されました。以降、米国債の償還分は全額ロールオーバーし、政府機関債・MBSの元本支払い分は米国短期国債に再投資する方針です。これは、MBS残高が自然に減る一方で、短期国債の保有が増え、FRBのポートフォリオ構成が徐々に米国債中心へ移ることを意味します。

## 総資産と「市場流動性」は同じではない

FRB総資産は重要な流動性指標ですが、総資産だけで市場流動性を判断するのは不十分です。FRBのバランスシートでは、資産側が増減するだけでなく、負債側の内訳も大きく変化します。特に重要なのは、以下の項目です。

| 負債側の項目 | 市場への意味 |
| --- | --- |
| 準備預金 | 銀行システム内の流動性。短期金融市場の安定性に直結しやすい |
| TGA：米財務省一般勘定 | 米財務省のFRB預金。増えると民間側の流動性を吸収しやすい |
| ON RRP | MMFなどがFRBに資金を預ける制度。流動性の吸収・緩衝材として機能 |
| 現金通貨 | 市中に出ている紙幣。増加するとFRB負債側で準備預金を圧迫しやすい |

たとえば、FRB総資産が横ばいでも、TGAが大きく増えると準備預金が減少し、短期金融市場では流動性が締まりやすくなります。FRB自身も、TGA変動やON RRPの残高が準備預金や短期金利の安定性に影響することを論じています。

H.4.1の表1では、TGAや準備預金も確認できます。2026年5月6日時点では、TGAは862,757百万ドル、準備預金は3,051,481百万ドルです。FRB総資産を見る際は、総資産だけでなく、準備預金・TGA・ON RRP・短期金利をセットで確認する必要があります。

## 「FRB総資産」と「Total factors supplying reserve funds」は違う

H.4.1には、連結バランスシート上の Total assets とは別に、表1の Total factors supplying reserve funds という項目があります。これは準備預金に影響する供給要因を整理したもので、純粋な会計上の総資産とは一致しません。2026年5月6日時点でも、表1のTotal factors supplying reserve fundsは6,760,849百万ドル、表5のTotal assetsは6,709,505百万ドルであり、数値が異なります。

そのため、データを扱う際は、以下のように区別します。

| 用語 | 主な用途 |
| --- | --- |
| Total assets / WALCL | FRB連結バランスシートの総資産を見る |
| Securities held outright | FRBの米国債・MBS保有の中心部分を見る |
| Reserve balances | 銀行システム内の準備預金を見る |
| TGA | 財務省預金による流動性吸収・放出を見る |
| ON RRP | MMF等の余剰資金吸収・短期市場の緩衝材を見る |
| Total factors supplying reserve funds | 準備預金に影響する供給要因を見る |

## 市場分析での実務的な使い方

FRB総資産は、短期売買の単独シグナルではなく、金融環境の背景を把握するための中長期指標として使います。

特に確認すべきポイントは、以下です。

- **総資産の方向性**: 増加しているのか、減少しているのか、横ばいなのかを確認します。QE局面では増加、QT局面では減少しやすくなります。
- **増減の中身**: 米国債・MBSの買入れによる増加なのか、銀行向け貸出や流動性ファシリティによる増加なのかを分けて見ます。前者は金融緩和、後者は金融ストレス対応の意味合いが強くなります。
- **準備預金の水準**: 市場流動性を見るうえでは、総資産よりも準備預金の変化が重要になる局面があります。準備預金が急減すると、レポ市場や短期金利にストレスが出やすくなります。
- **TGA・ON RRPとの組み合わせ**: TGAが増えると民間流動性を吸収しやすく、TGAが減ると民間流動性を放出しやすくなります。ON RRPは、余剰流動性の吸収先・緩衝材として確認します。
- **金利・ドル・株式との併用**: FRB総資産だけでリスクオン・リスクオフを判断せず、米2年金利、米10年金利、実質金利、DXY、信用スプレッド、SOFR、レポ金利、株価指数と併せて判断します。

## 判断上の注意点

FRB総資産を見る際に、特に注意すべき誤解は以下です。

| 誤解 | 正しい見方 |
| --- | --- |
| FRB総資産が増えれば必ず株高 | QEによる増加なら支援材料だが、緊急貸出による増加は金融ストレスの可能性がある |
| FRB総資産が減れば必ず株安 | QTは引き締め方向だが、景気・金利・企業業績・財政要因も同時に見る必要がある |
| 総資産＝マネーサプライ | 総資産は中央銀行のバランスシート規模。M2などのマネーサプライとは別指標 |
| 総資産＝市場に直接流れる資金 | 実際には負債側の準備預金、TGA、ON RRPの内訳が重要 |
| MBS減少＝FRBがMBSを売却している | 多くの場合、元本返済・期限前償還・再投資方針による残高変化であり、売却とは限らない |
| H.4.1の全項目が同じ意味 | Total assets、securities held outright、reserve balances、TGA、ON RRPは用途が異なる |
