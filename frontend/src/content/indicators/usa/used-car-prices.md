## 指標の概要

中古車価格は、米国インフレを分析するうえで重要な財価格指標です。特に米国CPIでは、中古車価格が大きく変動すると、コア財インフレやコアCPIの月次変化に影響を与えることがあります。

本項目では、主に以下の2系列を比較します。

| 系列 | 内容 | 主な役割 |
| --- | --- | --- |
| CPI中古車 | 米BLSが公表するCPIの「Used cars and trucks」 | 消費者物価に直接反映される中古車価格 |
| Manheim中古車 | Cox Automotive / Manheimが公表する卸売中古車価格指数 | CPI中古車に先行しやすい卸売市場の価格指標 |

CPI中古車は、消費者が直面する中古車価格をCPIのルールに基づいて指数化したものです。一方、Manheim中古車は、卸売オークション市場の中古車価格を反映する指標です。両者は同じ「中古車価格」を扱いますが、価格段階・算出方法・反映タイミングが異なるため、完全には一致しません。

## CPI中古車とは

CPI中古車は、米BLSが公表する消費者物価指数のうち、「Used cars and trucks」に該当する項目です。BLSの説明では、対象には2〜7年落ちの中古車が含まれ、乗用車だけでなく、ピックアップトラック、バン、SUVなどのライトトラックも含まれます。

FREDでは、CPI中古車の系列は `CUSR0000SETA02` として取得できます。系列名は "Consumer Price Index for All Urban Consumers: Used Cars and Trucks in U.S. City Average" で、単位は Index 1982-1984=100、頻度は 月次、季節調整済み系列です。

CPI中古車は、消費者物価指数に直接組み込まれるため、米国CPIやコアCPIの分析では最終的に確認すべき公式系列です。

## Manheim中古車指数とは

Manheim Used Vehicle Value Indexは、Cox Automotiveが公表する米国の卸売中古車価格指数です。米国の卸売中古車市場を追跡するベンチマークとして使われ、ディーラーや市場関係者が中古車市場の需給変化を把握する際に参照します。公式の月次指数は、原則として毎月第5営業日に公表されます。

Manheimは卸売価格を反映するため、CPI中古車よりも市場価格の変化を早く捉えやすい傾向があります。ディーラーが卸売市場で仕入れた中古車価格は、一定のラグを伴って小売価格に反映される可能性があります。そのため、Manheim中古車はCPI中古車の先行指標として利用されます。

ただし、ManheimはCPIそのものではありません。CPI中古車は消費者向け価格、Manheimは卸売オークション市場の価格であり、両者の乖離は通常発生します。

## 基本的な見方

### 1. CPI中古車が上昇している場合

CPI中古車が上昇している場合、CPI上の中古車項目がインフレ方向に寄与していることを意味します。中古車はコア財に含まれるため、食品・エネルギーを除いたコアCPIの変動要因としても注目されます。

中古車価格が上昇しやすい主な背景は以下です。

| 背景 | 価格への影響 |
| --- | --- |
| 新車供給不足 | 中古車需要が高まりやすい |
| リース戻り車両の不足 | 中古車在庫が減り、価格が下がりにくい |
| 新車価格の高止まり | 消費者が中古車に流れやすい |
| 自動車ローン環境の変化 | 低価格帯の中古車需要に影響しやすい |
| 卸売価格の上昇 | 遅れて小売価格に波及する可能性 |

### 2. CPI中古車が低下している場合

CPI中古車が低下している場合、中古車価格はCPIに対してディスインフレ方向に作用します。特に2021〜2022年のように中古車価格が大きく上昇した後は、ベース効果によって前年比が大きく低下しやすくなります。

ただし、前年比がマイナスでも、前月比が上昇している場合やManheimが先に反発している場合は、将来的なCPI中古車の下げ止まりに注意が必要です。

### 3. ManheimがCPI中古車に先行して上昇している場合

Manheimが先に上昇している場合、卸売中古車価格が底打ちまたは再加速している可能性があります。卸売価格の上昇が小売価格へ転嫁されると、数か月後にCPI中古車のマイナス幅縮小、または前月比の上昇として表れる可能性があります。

ただし、消費者需要が弱い場合や在庫が十分にある場合は、卸売価格の上昇が小売価格に転嫁されにくいことがあります。

### 4. ManheimがCPI中古車に先行して低下している場合

Manheimが低下している場合、卸売市場では中古車価格の下押し圧力が強まっている可能性があります。その後、ディーラーの販売価格に反映されれば、CPI中古車にも遅れて下落圧力が出やすくなります。

この場合、コア財インフレの鈍化要因として確認します。

## 市場分析での使い方

中古車価格は、米国インフレ分析で以下のように使います。

### 1. コアCPIの上振れ・下振れ要因を見る

中古車はコア財の一部です。中古車価格が大きく上昇すると、コアCPIの月次上昇率を押し上げる要因になります。反対に、中古車価格が下落すると、コアCPIの鈍化要因になります。

### 2. 財インフレの再加速を確認する

サービスインフレが粘着的な局面でも、財価格が落ち着いていればCPI全体の上昇圧力は抑えられます。一方、中古車価格が再加速すると、財インフレの下げ止まりとして警戒されます。

### 3. ManheimでCPI中古車の先行方向を見る

Manheimが数か月にわたり上昇している場合、CPI中古車にも遅れて上昇圧力が出る可能性があります。Manheimが低下している場合は、CPI中古車にも遅れて下落圧力が出やすくなります。

### 4. 自動車市場全体の需給を確認する

中古車価格は、新車価格、新車在庫、ローン金利、消費者信用、リース戻り車両の供給などに影響されます。中古車価格単体ではなく、自動車市場全体の需給指標として確認することで、より実務的な判断が可能になります。
