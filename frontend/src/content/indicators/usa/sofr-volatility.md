## SOFRとは

SOFR（Secured Overnight Financing Rate、担保付翌日物調達金利）は、米国債を担保にして翌日物で資金を借りる際のコストを示す米ドル短期金利指標です。ニューヨーク連銀は、SOFRを「米国債を担保とする翌日物資金調達コストの広範な指標」と定義しています。主な対象市場は米国債レポ市場であり、銀行間の無担保調達金利ではありません。

SOFRは、ニューヨーク連銀が米国財務省金融調査局（OFR）と協力して算出・公表しています。公表時刻は通常、米国東部時間の各営業日午前8時頃です。

## 算出方法

SOFRは、米国債レポ取引の実取引データをもとにした取引ベースの金利です。算出には、トライパーティ・レポ、GCF Repo、FICCのDVPサービスを通じて清算される二者間の米国債レポ取引が含まれます。SOFRはこれらの取引レベルデータから、取引量加重中央値として算出されます。

SOFRでは、特定銘柄の米国債を入手する目的で行われる「specials」と呼ばれるレポ取引の一部が除外されます。specialsは、特定の証券を借りたい需要が強い場合に、通常の一般担保レポより低い金利で成立することがあるため、通常の資金調達コストを歪める可能性があります。

## LIBORとの違い

SOFRは、米ドルLIBORの代替指標として重要です。ARRC（Alternative Reference Rates Committee）は2017年、SOFRを米ドルLIBORの望ましい代替金利として選定しました。SOFRは実取引に基づく担保付翌日物金利であり、米国債レポ市場という厚い市場を基礎にしている点が特徴です。

LIBORは銀行の無担保調達コストを反映する性質がありましたが、SOFRは米国債担保付きの翌日物レポ金利です。そのため、SOFRは銀行信用リスクやターム・プレミアムを直接含む指標ではありません。米ドル金利市場の基準金利としては重要ですが、「銀行信用不安そのものを測る指標」として扱うのは不適切です。

## SOFRが重要な理由

SOFRは、米ドル金利市場の基準金利として、デリバティブ、変動利付債、ローン、証券化商品など幅広い金融契約で参照されます。ARRCは、SOFRについて、取引量が大きく、透明性が高く、操作されにくい性質を持つと説明しています。

市場分析では、SOFRそのものだけでなく、SOFR先物、SOFR OIS、SOFRスワップ金利も重要です。スポットSOFRは「足元の翌日物レポ金利」を示す一方、SOFR先物やOISは将来の政策金利期待や短期金利見通しを織り込みます。したがって、金融政策の先行指標として見る場合は、日次SOFR単体よりもSOFR先物・OISカーブの方が有用です。

## SOFR AveragesとSOFR Index

ニューヨーク連銀は、日次SOFRに加えて、30日・90日・180日のSOFR平均とSOFR Indexも公表しています。SOFR AveragesはSOFRの複利平均であり、SOFR Indexは2018年4月2日を初期値1.00000000として、SOFRを日次で複利計算した累積指数です。

長期の金利契約や利息計算では、1日分のSOFRだけを見るより、SOFR AveragesやSOFR Indexを使う方が実務上は自然です。日次SOFRは短期資金市場の状態を見る指標、SOFR AveragesやSOFR Indexは一定期間の複利ベースの調達コストを見る指標として使い分けます。

なお、Term SOFRはCMEなどが公表する将来見通し型のターム物SOFRであり、ニューヨーク連銀が公表する日次SOFR、SOFR Averages、SOFR Indexとは区別する必要があります。ARRCはTerm SOFRの利用を一定範囲で認めていますが、金融安定性の観点から利用範囲は限定的に扱うべきものとしています。

## 公表・改定ルール

SOFR、SOFR Averages、SOFR Indexは通常、各営業日に公表されます。ただし、SIFMAが米国政府証券市場の全面休場を推奨する日は公表されません。

公表後に計算エラーや取引データの遅延・修正が判明した場合、ニューヨーク連銀は同日午後2時30分頃に改定することがあります。ただし、日次SOFRの改定は、原則として金利の変化が1bpを超える場合に限られます。

## チャートの見方

SOFRの水準は、米ドル翌日物資金市場の調達コストを示します。通常はFRBの政策金利レンジや短期金融市場の需給環境に沿って動きます。FOMCで政策金利が変更されると、SOFRも段階的に水準を変えることが多くなります。

SOFRの日次変化は、前営業日から何bp動いたかを示します。通常時は小幅な変動にとどまることが多いですが、月末、四半期末、年末、米国債需給の変化、レポ市場の資金需給、政策金利変更の直後などには変動幅が大きくなることがあります。

20日ボラティリティは、SOFRの日次変化幅をもとにした20営業日程度のローリング標準偏差として見ると実務上分かりやすい指標です。本ダッシュボードでは、20日ボラティリティを「SOFRの日次変化の標準偏差」、単位はbpsとして整理しています。

## 20日ボラティリティの解釈

20日ボラティリティは、SOFRの「水準」ではなく、SOFRの日々の変化がどの程度荒くなっているかを見る指標です。

SOFRの水準が上昇していても、毎日ほぼ同じ水準で推移していればボラティリティは低くなります。一方、SOFRの水準が大きく上昇していなくても、日々の上下が大きければボラティリティは上昇します。

実務上は、以下のように見ます。

| 状態 | 解釈 |
| --- | --- |
| SOFR水準が安定、ボラティリティも低い | 米ドル短期資金市場が比較的安定している状態 |
| SOFR水準が政策金利変更に沿って低下・上昇 | FOMCによる利下げ・利上げの反映 |
| SOFR水準が急上昇、ボラティリティも上昇 | レポ市場の資金需給が一時的に逼迫している可能性 |
| 月末・四半期末・年末に一時的な上昇 | バランスシート制約や期末要因による短期的な歪みの可能性 |
| SOFRが急変しても翌日以降に戻る | 一時的なテクニカル要因の可能性が高い |
| SOFR上昇が数日以上続く | レポ市場の流動性や担保需給を追加確認する必要がある |

## 分析上の注意点

SOFRは政策金利そのものではありません。FRBが直接決める政策金利はFF金利の誘導目標レンジであり、SOFRは米国債レポ市場で成立した翌日物取引に基づく市場金利です。

SOFRは銀行信用リスクを直接測る指標ではありません。米国債を担保とするレポ金利であるため、銀行間の無担保信用リスクを含んでいたLIBORとは性質が異なります。

SOFRの1日だけの急変を、すぐに金融危機や政策変更のサインと判断するのは危険です。SOFRは月末・四半期末・年末、米国債発行・決済、レポ市場の担保需給、短期資金市場のバランスシート制約などで一時的に動くことがあります。

SOFRのスポット値は、将来の利下げ・利上げ期待を直接示すものではありません。将来の政策金利期待を確認する場合は、SOFR先物、OIS、米国債利回り、FedWatch系データなどを併用します。

## 実務での使い方

SOFRは、米ドル短期金利市場の基準金利として確認します。日次SOFRの水準は、足元の翌日物資金調達コストを見るために使います。SOFRの20日ボラティリティは、短期金利市場の変動が安定しているか、荒れているかを判断する補助指標として使います。

トレードやマクロ分析では、SOFR単体で売買判断を行うのではなく、米国債利回り、FF金利見通し、OIS、ドルインデックス、株式市場、クレジットスプレッドと合わせて確認します。SOFRが安定している場合は、短期資金市場が大きく混乱していないと判断しやすくなります。一方、SOFRが政策金利から大きく乖離したり、ボラティリティが急上昇したりする場合は、米ドル資金市場の需給変化を警戒する必要があります。
