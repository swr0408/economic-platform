# グローバル製造業PMI

## 概要

グローバル製造業PMI（S&P Global / J.P.Morgan Global Manufacturing PMI）は、世界の製造業の景況感を示す月次の総合指標である。**50**を境に景気の拡大・縮小を判断する。

## 原油価格との関係

グローバル製造業PMIと原油価格には連動性がみられるが、明確な先行指標として使うには弱い:

- グローバル製造業PMIは、原油の先行指標というより**景気要因で原油が動いているかを確認するための同時確認指標**として使う方が適切
- 原油が上昇している一方でグローバルPMIが弱い場合は、**景気要因ではなく供給不安や地政学要因**で原油が上がっている可能性を疑うべき

## 実務上の使い方

- グローバルPMIが改善トレンド → 原油の景気要因による上昇を裏付けやすい
- グローバルPMIが悪化トレンド → 原油高が供給・地政学要因主導である可能性
- ISM製造業指数と合わせて確認すると、米国と世界全体の景気方向感を比較できる
