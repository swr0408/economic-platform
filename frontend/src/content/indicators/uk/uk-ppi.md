## 概要

英国のPPIは、ONS（Office for National Statistics）が公表する**英国の製造業者が売る財と買う財の価格変動**を測定する指標です。headline PPIは "goods bought and sold by UK manufacturers" であり、製造業の財価格が中心で、米国型の広い総合PPIではありません。

PPIは**産出価格（Output）**と**投入価格（Input）**の2系列で構成されます：

| 系列 | 内容 | 注目度 |
|------|------|--------|
| **Output PPI（Factory Gate Price）** | 製造業者が出荷する財の価格 | 最高 |
| **Input PPI** | 製造業者が加工のために購入する原材料・燃料の価格 | 高（先行性あり） |

産出価格は、英国の製造業者が販売する財の工場出荷段階の価格を示す。ONSはこれを factory gate price と説明しており、労働費、原材料費、エネルギー費、金利、建物維持費、賃料などを含む一方、税は含まない。投入価格は、製造業者が加工や日常運営のために購入する原材料・燃料などの価格を示す。これは最終製品に組み込まれる材料だけでなく、企業の日常的な操業に必要な投入も含む。

さらに**輸出価格指数（EPI）**と**輸入価格指数（IPI）**も別に公表されている。PPIを理解する際は、国内向けの価格動向を見る統計と、対外取引価格を見る統計を区別しておくことが重要であり、企業物価の全体像をみるにはEPI・IPIもあわせて確認すると実務上の解像度が上がる。

## PPIが反映する価格の性質

PPIは、企業の希望価格や単なる定価ではなく、通常の取引価格を基準に作成される。ONSの調査票では、報告する価格は割引後で、VATを除いた価格であることが求められている。また、月ごとに比較可能で、現在の取引実態を代表する価格であることも重視されている。したがって、PPIは「企業が付けたい価格」というより、実際の取引に近い価格動向を捉える統計として理解するのが適切である。

## 発表スケジュール

- **発表機関**: ONS（Office for National Statistics）
- **頻度**: 毎月中旬（通常CPIと同日発表）
- **時間**: GMT 7:00（日本時間 16:00 / 夏時間 15:00）
- **対象月**: 前月分

## 他国PPIとの比較

| 国・地域 | 名称 | カバレッジ | サービス |
|----------|------|-----------|---------|
| **英国** | Output/Input PPI | 製造業の財価格 | 別統計（SPPI、四半期） |
| ユーロ圏 | Industrial PPI | 工業製品のみ | 別統計（SPPI） |
| ドイツ | Industrial PPI | 国内生産・国内販売の工業製品 | 別統計（四半期） |
| 日本 | CGPI | 財のみ（約900品目） | 別統計（SPPI、月次） |
| 米国 | PPI（FD-ID） | 財＋サービス＋建設 | PPIに内包 |

英国も、PPI本体は財、サービスはSPPIで別管理という構造です。英国のSPPI（Services Producer Price Indices）は英国ベースの顧客向けに提供されるサービス価格を**四半期ベース**で測定しています。

## Output PPI と Input PPI の関係

Input PPI（原材料・燃料）はOutput PPI（出荷価格）に先行する傾向があります。

- **Input PPI**: 原油・金属等の国際商品市況や為替の影響を直接受け、変動が大きい
- **Output PPI**: Input PPIのコスト変動が製品価格に転嫁されるまでにラグがある

Input PPIの急変動は、数ヶ月後のOutput PPIの方向感を示す先行シグナルとして有用です。

実務で確認したいポイントとして、まず投入価格と産出価格の方向差を確認すると有効である。投入価格だけが強く上がっている場合は、企業収益への圧迫が示唆されやすく、産出価格も追随している場合は価格転嫁が進んでいる可能性がある。さらに、輸入価格指数を併せてみることで、海外発のコスト上昇が国内製造業にどの程度波及しているかを把握しやすくなる。

## Output PPI → CPI の波及構造

英国は、Output PPIからCPIへの連動が**非常に強い国**です。最適ラグは**4ヶ月**で、同月相関もかなり高く、上流価格の変化が比較的明確に消費者物価へつながっています。

| 国・地域 | 生産者物価 → 消費者物価 | 最適ラグ |
|----------|----------------------|---------|
| **英国** | Output PPI → CPI | **4ヶ月** |
| 米国 | PPI → CPI | 1ヶ月 |
| ユーロ圏 | PPI → HICP | 5ヶ月 |
| ドイツ | PPI → CPI | 5ヶ月 |
| 日本 | CGPI → CPI | 7ヶ月 |

英国では、PPIを見ることで数ヶ月先のCPIの強弱を比較的読みやすいと言えます。実務上は、英国インフレの先行確認として**CPI単独よりもPPIを先に見る価値が高い国**です。

Output PPI前年比を**4ヶ月先行シフト**してCPI前年比と重ねると、CPIの方向感を読む補助として有用です（データ比較ページのタイムシフト機能で確認可能）。

ただし、PPIは消費者物価そのものではない。対象はあくまで英国製造業者の財価格であり、サービス価格はSPPI、消費者段階の物価とは対象が異なる。そのため、PPIはCPIの参考材料にはなるが、CPIをそのまま先取りする指標ではない点に注意が必要である。英国中銀も、PPIと消費者物価は共動しやすい局面がある一方、両者の乖離が生じることがあると説明している。

## マーケットへの影響

- **予想上振れ**: BOE利上げ期待→ポンド高・ギルト金利上昇
- **予想下振れ**: BOE利下げ期待→ポンド安・ギルト金利低下
- **CPIと同日発表**: CPIの方が注目度は高いが、PPIが補強材料として機能

Input PPIの急変動はポンドや原油価格との連想で短期的なインパクトを持つことがあります。

## トレードの着眼点

- **CPI先行指標**: Output PPI前年比の4ヶ月先行シフトでCPIの方向感を予測
- **Input → Output パイプライン**: Input PPIの変動がOutput PPIに波及するまでのラグを追跡
- **原油・ポンド連動**: Input PPIは原油価格とポンド/ドルの影響を強く受ける
- **BOE政策への示唆**: PPIのトレンド変化はBOEの金融政策判断に影響

## 利用時の注意点

PPIは月次統計だが、直近2か月は暫定値で、過去12か月は改定対象である。またONSは、2025年にPPIとSPPIのchain-linking methodologyの修正を公表しており、過去系列を扱う際は最新公表系列を使うことが重要である。分析や比較に用いる場合は、古い控え値ではなく、最新版のONS系列で統一するのが望ましい。

## 関連指標

- **英国CPI/CPIH**: Output PPIが約4ヶ月先行
- **ユーロ圏PPI**: 欧州全体のインフレ動向との比較
- **PPI（米国）**: サービス含む広義PPI（ラグ1ヶ月）
- **CGPI（日本）**: 日本版の企業物価（ラグ7ヶ月）
