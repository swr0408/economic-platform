## 概要

中国の Baidu遷徙 などの位置情報ベースの人流・人口移動データは、中国国内のサービス活動や都市活動の強弱を把握するための補助指標として利用できる。

Baidu遷徙は、スマートフォンの位置情報やBaidu Map系サービスの利用データをもとに、都市間・地域間の人口移動、流入・流出、移動規模の変化を可視化するデータである。特に、春節、国慶節、労働節などの大型連休前後や、景気回復局面、感染症・規制解除後の経済活動再開を確認する際に参考になりやすい。

このデータは、中国の非製造業のなかでも、特に **サービス業、交通、旅行、宿泊、外食、小売、観光、都市活動、労働者の移動** など、人の移動を伴う分野と関係しやすい。

## 非製造業との関係

中国の非製造業PMIは、製造業以外の景況感を示す指標であり、主に **サービス業** と **建設業** を含む。

Baiduの人流・人口移動データは、このうち特にサービス業との関係が強い。人の移動が増える局面では、交通機関の利用、旅行、宿泊、外食、小売、娯楽、都市部での消費活動が活発化しやすいため、サービス業の景況感改善と同方向に動くことがある。

一方で、非製造業PMIには建設業も含まれる。建設業は、不動産投資、インフラ投資、政策支援、資金調達環境、天候などの影響を受けやすく、人流データだけでは説明しにくい。そのため、Baidu人流データは **非製造業全体を直接測る指標ではなく、サービス業を中心とした非製造業の補助指標** として扱うのが適切である。

## 見るべきポイント

### 1. 都市間・地域間の移動量

都市間の移動が増えている場合、出張、観光、帰省、労働者の移動、経済活動の再開が進んでいる可能性がある。

特に、大都市への流入が強い場合は、労働者の職場復帰、企業活動の再開、都市部消費の回復を示す材料になる。

### 2. 大型連休後の戻り

中国では春節や国慶節などの大型連休によって人流が大きく変動する。

そのため、単純な日次比較ではなく、連休前後の反動や季節性を考慮する必要がある。特に春節は毎年日付が変わるため、通常の前年比だけでは景気判断を誤ることがある。

春節後に大都市への人口流入が早く回復している場合、工場・企業・サービス業の再開が順調に進んでいる可能性がある。

### 3. サービス消費との関係

人流の増加は、以下のようなサービス消費と関係しやすい。

| 関連分野 | 人流増加時に確認したい内容 |
|--------|------------------------|
| 交通 | 鉄道、航空、道路利用の回復 |
| 旅行・観光 | 観光地への移動、ホテル稼働、旅行需要 |
| 外食 | 飲食店利用、外食売上 |
| 小売 | 商業施設、都市部消費の回復 |
| 宿泊 | ホテル需要、出張・観光需要 |
| 都市活動 | 大都市への通勤・労働者回帰 |

## 実務上の使い方

Baidu人流データは、月次統計よりも高頻度で確認できるため、中国国内需要の変化を早めに把握する材料になる。

例えば、人流が明確に回復している場合、サービス消費、旅行需要、外食、小売、都市部の経済活動が改善している可能性がある。逆に、人流が弱い場合は、消費者の移動が鈍く、サービス業の回復力が弱い可能性がある。

ただし、Baidu人流データは景気そのものを直接測る指標ではない。あくまで人の移動を通じて、サービス業や都市活動の強弱を推測するための補助データである。
