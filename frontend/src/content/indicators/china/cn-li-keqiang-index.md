## 1. 李克強指数とは

李克強指数とは、中国の実体経済を把握するために使われる非公式の景気指標です。名称は、中国の元国務院総理である李克強氏に由来します。

李克強氏は、国務院総理に就任する前、遼寧省の幹部だった2007年に、中国の公式GDP統計よりも実体経済の動きを把握しやすい指標として、以下の3つを重視していると述べたとされています。

- 電力消費量
- 鉄道貨物輸送量
- 銀行融資

この3つのデータをもとに、中国経済の実勢を推測するために作られた指標が、一般的に「李克強指数」と呼ばれています。

公式GDPは、政府目標や統計上の平滑化の影響を受けやすいと見られることがあります。一方で、電力消費、鉄道貨物、銀行融資は、企業活動や物流、信用供給と直接結びつくため、実体経済の動きを確認する補助指標として使われます。

## 2. 李克強指数を構成する3つの指標

### 電力消費量

電力消費量は、工場、鉱業、建設関連、インフラ、商業施設などの活動量を反映しやすい指標です。

中国では製造業や重工業の比率が大きかった時期が長く、電力使用量は工業活動の強弱を見るうえで重要な材料とされてきました。

電力消費量が増加している場合、工場稼働、建設活動、素材需要、生産活動が強まっている可能性があります。反対に、電力消費量が鈍化している場合、工業生産や企業活動が弱まっている可能性があります。

ただし、近年は省エネ化、産業構造の変化、サービス業の拡大、再生可能エネルギーの普及などにより、電力消費量だけで中国経済全体を判断することは難しくなっています。

### 鉄道貨物輸送量

鉄道貨物輸送量は、石炭、鉄鉱石、鋼材、化学品、農産物、工業製品などの輸送動向を反映します。

特に中国では、重工業、資源、建設、インフラ投資と鉄道貨物輸送の関係が強いため、鉄道貨物輸送量は旧来型の景気循環を確認するうえで有用です。

鉄道貨物輸送量が増加している場合、素材需要、建設活動、工業生産、在庫補充が強まっている可能性があります。反対に、鉄道貨物輸送量が鈍化している場合、工業・建設・資源関連の活動が弱まっている可能性があります。

ただし、物流手段の変化にも注意が必要です。道路輸送、海上輸送、航空貨物、コンテナ輸送、デジタル関連サービスの拡大により、鉄道貨物だけでは現代の中国経済全体を十分に捉えにくくなっています。

### 銀行融資

銀行融資は、企業や地方政府、家計に対する信用供給の動きを示します。

中国経済では、銀行融資や社会融資総量が、不動産投資、インフラ投資、企業投資、地方政府関連プロジェクトに大きな影響を与えます。そのため、銀行融資の増加は、信用拡張を通じた景気刺激のサインとして見られることがあります。

銀行融資が増加している場合、企業投資、インフラ投資、不動産投資、資金需要が強まっている可能性があります。反対に、銀行融資が鈍化している場合、信用環境の引き締まり、投資意欲の低下、景気減速圧力を示すことがあります。

ただし、銀行融資は政策の影響を強く受けます。中国では政府や人民銀行の方針によって信用供給が拡大・抑制されるため、融資の増加が必ずしも民間需要の自然な回復を意味するとは限りません。

## 3. 一般的なウェイト

市場で使われる李克強指数では、代表的に以下のようなウェイトが用いられることがあります。

| 項目 | ウェイト例 |
|------|---------|
| 銀行融資 | 40％ |
| 電力消費量 | 40％ |
| 鉄道貨物輸送量 | 20％ |

ただし、李克強指数は中国政府が公式に発表している統計ではありません。
そのため、データベンダーや分析機関によって、使用する系列、計算方法、ウェイトが異なる場合があります。

実務上は、李克強指数を単一の絶対的な数値として見るのではなく、中国の工業・信用・物流の方向感を確認する補助指標として扱うのが適切です。

## 4. 李克強指数が示すもの

李克強指数は、中国経済のなかでも特に以下の分野を反映しやすい指標です。

- 製造業
- 重工業
- 建設関連
- インフラ投資
- 不動産関連需要
- 素材需要
- エネルギー需要
- 鉄道物流
- 銀行信用
- 投資循環

そのため、李克強指数は中国経済全体というよりも、工業・投資・資源需要を中心とした旧来型の景気循環を見る指標として有用です。

特に、中国の製造業や建設活動が強い局面では、電力消費量、鉄道貨物輸送量、銀行融資が同時に改善しやすく、李克強指数も上昇しやすくなります。

一方で、サービス業、個人消費、デジタル経済、金融サービス、教育、医療、観光、娯楽などの動きは、李克強指数には十分に反映されにくい点に注意が必要です。

## 5. 基本的な見方

| 李克強指数の動き | 読み方 |
|---------------|------|
| 上昇 | 中国の工業活動、物流、信用供給が改善している可能性 |
| 低下 | 工業生産、建設活動、素材需要、信用供給が鈍化している可能性 |
| 公式GDPより強い | GDP統計以上に実物経済・投資循環が強い可能性 |
| 公式GDPより弱い | GDP統計ほど実体経済が強くない可能性 |
| 電力・貨物は強く、融資が弱い | 実需はあるが信用拡張が弱い可能性 |
| 融資は強く、電力・貨物が弱い | 政策的な信用供給が先行している可能性 |

李克強指数を見る際は、単月の数値よりも、数か月単位のトレンドを見ることが重要です。

短期的には、旧正月、天候、政策イベント、在庫調整、輸送規制、エネルギー制限などの影響を受けることがあります。そのため、単月の急変だけで景気判断を行うのは避けるべきです。

## 6. 中国経済の構造変化による注意点

李克強指数を使ううえで最も重要な注意点は、中国経済の構造変化です。

李克強氏が3つの指標に言及した2007年当時、中国経済は製造業、重工業、建設、インフラ投資の存在感が非常に大きい経済でした。そのため、電力消費量、鉄道貨物輸送量、銀行融資を見ることで、中国の景気実態をある程度把握しやすい環境にありました。

しかし、2010年代以降、中国では第三次産業、サービス業、個人消費、デジタル経済の比重が上昇しています。経済全体に占める製造業や重工業の相対的な重要性は低下し、サービス産業の存在感が高まっています。

この構造変化により、李克強指数は現在の中国経済全体を完全に表す指標ではなくなっています。

特に、以下の分野は李克強指数では捉えにくいです。

- サービス消費
- EC・デジタルサービス
- IT関連産業
- 金融サービス
- 医療・教育
- 旅行・外食
- 高付加価値サービス
- 個人消費の質的変化
- EV・半導体・再生可能エネルギーなど新興産業の一部

そのため、李克強指数は現在では、中国全体のGDP代理指標というより、工業・建設・素材需要・信用循環を見る補助指標として位置づけるのが適切です。
