## 国債発行（Government Bond Issuance）とは

国債発行は、中国財政部（MOF）が公表する国債の発行予定・入札結果・発行額を確認するためのデータです。中国政府がどの年限の国債を、どの程度の規模で、どの条件で市場に供給しているかを把握できます。データは主に財政部債務管理司の「業務公告」に掲載され、発行通知、入札結果公告、特別国債や貯蓄国債の公告などが順次公表されます。

この指標は、単に「政府が資金を調達している」という情報だけでなく、国債市場の需給、年限別の供給圧力、財政政策の資金調達動向、長期金利への潜在的な影響を確認するために使います。

## 確認できる主な内容

### 1. 入札予定

入札予定では、今後実施される国債入札について、銘柄、年限、発行予定額、入札日、入札時間、入札方式などを確認します。たとえば財政部の発行通知では、7年債の再発行について「競争性招標面値総額1310億元」、入札時間「2026年5月14日10:35〜11:35」、入札方式「修正的多重価格、標的は価格」といった情報が示されています。

入札予定で特に重要なのは、発行額そのものだけではなく、どの年限に供給が集中しているかです。短期債が多い場合は短期資金需給や短期金利への影響を確認し、10年・20年・30年・50年などの長期・超長期債が多い場合は、長期金利やイールドカーブの形状への影響を確認します。

### 2. 入札結果

入札結果では、実際の発行額、発行価格、落札利回り、票面利率、上場日などを確認します。たとえば、2026年第73号公告では、記帳式附息国債の再発行について、計画額1700億元、実際の発行額1700億元、再発行価格100.31元、折合年收益率1.23%、票面利率1.29%と公表されています。

貼現国債の場合は、票面利率ではなく、額面より低い価格で発行され、償還時に額面で返済されることで利息相当分が生じます。財政部の公告でも、91日貼現国債について、発行価格99.772元、折合年收益率0.92%、満期時に額面償還することが示されています。

### 3. 月次供給量

月次供給量は、一定期間内にどの種類の国債がどれだけ供給されたかを集計して見るための項目です。画面例では、附息国債、貼現国債、貯蓄国債などに分けて月次発行額を集計しています。今回のキャッシュデータでは、2026年4月は合計10,040.8億元、2026年5月は合計2,650.2億元として集計されています。

月次供給量を見る際は、単月の発行額だけで判断せず、前月比、過去数か月平均、年限構成、再発行の多さ、特別国債の有無を合わせて確認します。

## 国債の種類

### 記帳式国債

記帳式国債は、電子的に債権が記録される流通可能な国債です。財政部の説明では、記帳式国債は主に機関投資家向けに一次市場で発行され、上場後は個人投資家も二次市場で購入可能です。存続期間中に市場で取引できるため、価格は市場金利や需給によって変動します。

記帳式国債は、債券市場の金利形成に直接関係しやすいため、金融市場を見る上では最も重要です。

### 附息国債

附息国債は、定期的に利息が支払われる国債です。1年から10年未満の記帳式国債は年1回利払い、10年以上の記帳式国債は半年ごとに利払いされると説明されています。

附息国債では、票面利率と落札利回りを混同しないことが重要です。票面利率は債券の利払い条件であり、落札利回りは入札結果として市場が要求した利回りです。再発行の場合、既存銘柄と同じ票面利率・起息日を引き継ぎ、発行価格で実勢利回りが調整されます。

### 貼現国債

貼現国債は、1年未満の短期国債です。額面より低い価格で発行され、満期時に額面で償還されます。価格と額面の差が実質的な利息となります。中国の記帳式国債では、1年未満の国債は貼現発行されると説明されています。

短期金利、資金需給、流動性環境を見る場合は、貼現国債の発行額と落札利回りが重要です。

### 貯蓄国債

貯蓄国債は、主に個人投資家向けの国債です。財政部の説明では、貯蓄国債は個人向けに販売され、存続期間中に市場で上場取引されない一方、記帳式国債は市場で取引可能です。

そのため、貯蓄国債は家計の安全資産需要を見る上では有用ですが、債券市場のリアルタイムな金利形成を読む材料としては、記帳式国債ほど直接的ではありません。

## 入札方式の読み方

中国の記帳式国債は、競争入札によって票面利率または発行価格が決まります。財政部の「記帳式国債招標発行規則」では、原則として入札時間は10:35〜11:35、入札対象は利率または価格であり、低い利率または高い価格の入札が優先されるとされています。

主な方式は以下です。

| 入札方式 | 読み方 |
| --- | --- |
| 単一価格入札 | 落札者が共通の価格または利率で引き受ける方式。市場全体の落札水準がそのまま発行条件になりやすい。 |
| 修正的多重価格入札 | 加重平均の中標利率・価格を基準にしつつ、一定条件に応じて価格・利率が調整される方式。中国の記帳式国債で頻繁に使われる。 |

発行通知に「標的為利率」とある場合は利率入札、「標的為価格」とある場合は価格入札です。新発債では利率入札、再発行や貼現債では価格入札が使われるケースが多く見られますが、実際の判定は必ず各公告の記載を確認します。

## 市場での見方

国債発行を見るときは、以下の順番で確認します。

| 確認項目 | 見るポイント |
| --- | --- |
| 発行総額 | 月次・週次で供給が急増していないか |
| 年限構成 | 短期債中心か、10年超の長期・超長期債中心か |
| 入札結果 | 落札利回りが市場実勢より高いか低いか |
| 発行価格 | 額面100を上回るか下回るか |
| 票面利率 | 既存銘柄との比較、再発行時の条件確認 |
| 再発行の有無 | 既存銘柄に統合される供給か、新規銘柄か |
| 分销・上場日 | 実際に市場流通が始まるタイミング |
| 特別国債の有無 | 財政政策・長期資金調達の強まりを示す可能性 |

特に重要なのは、発行予定額と入札結果を分けて見ることです。発行予定額は「供給計画」、入札結果は「市場がどの条件で吸収したか」を示します。予定額が大きくても、低い利回りで円滑に消化されていれば需要は強いと見られます。一方、落札利回りが上振れし、発行価格が弱い場合は、投資家需要がやや弱い可能性があります。
