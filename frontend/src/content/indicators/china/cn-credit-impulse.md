## 1. クレジットインパルスとは

クレジットインパルスとは、新規信用供給がどれだけ加速・減速しているかをGDP比で示す指標です。
単純な「貸出残高の伸び」ではなく、信用供給の増加ペースの変化を見る指標です。

中国の場合は、銀行貸出だけでなく、より広い信用供給を示す**社会融資総量（Total Social Financing / TSF）**をベースに見ることが多いです。社会融資総量には、人民元建て貸出、外貨建て貸出、信託貸付、委託貸付、社債、政府債、株式調達などが含まれます。

そのため、中国のクレジットインパルスは、単なる銀行貸出ではなく、中国経済全体に対する信用供給の勢いを確認する指標として使われます。

## 2. 基本的な読み方

クレジットインパルスが上昇している場合、信用供給が加速しており、景気を押し上げる力が強まりやすいと見ます。企業や地方政府、家計への資金供給が増えやすく、投資、在庫積み増し、インフラ需要、製造業活動、商品需要に波及しやすくなります。

一方、クレジットインパルスが低下している場合、信用供給の加速感が弱まり、景気への支援効果が低下しやすいと見ます。ただし、低下しているからといって貸出残高そのものが減少しているとは限りません。多くの場合は、信用供給の伸びが鈍化している、または前年と比べて信用拡張の勢いが弱まっている状態を示します。

整理すると、以下のように見ます。

| クレジットインパルス | 景気への意味 |
|------------------|------------|
| 上昇 | 信用供給が加速。景気・投資・商品需要・製造業活動を押し上げやすい |
| 横ばい | 信用環境の押し上げ効果は中立に近い |
| 低下 | 信用供給の加速感が鈍化。景気への支援効果が弱まりやすい |
| 大きくマイナス圏 | 信用環境が景気の重石になりやすい |

## 3. 中国クレジットインパルスが重要な理由

中国は世界の製造業、資源需要、インフラ投資、貿易循環に大きな影響を持つため、中国の信用サイクルは中国国内だけでなく、世界経済にも波及しやすいです。

特に、中国で信用供給が拡大すると、以下の経路で世界景気に影響します。

| 波及経路 | 内容 |
|--------|------|
| インフラ投資 | 鉄鋼、銅、セメント、建機、資源需要に影響 |
| 不動産・建設 | 鉄鉱石、銅、エネルギー、素材関連に影響 |
| 製造業投資 | 機械、電子部品、半導体関連、FA関連に影響 |
| 在庫循環 | 製造業PMI、新規受注、輸入、商品価格に影響 |
| 貿易 | 日本、韓国、台湾、豪州、ドイツなど外需依存国に影響 |
| リスク選好 | 株式、資源国通貨、新興国市場に影響 |

そのため、中国クレジットインパルスは、中国景気の先行指標であると同時に、グローバル製造業サイクルの先行確認指標としても使われます。

## 4. PMIとの関係

中国クレジットインパルスは、中国製造業PMI、グローバル製造業PMI、米ISM製造業指数などに先行しやすいとされています。

信用供給が増えると、企業の資金繰りが改善し、投資、仕入れ、生産、在庫積み増しが進みやすくなります。その結果、一定の時間差を置いて、製造業PMIや新規受注に改善が出やすくなります。

一般的には、半年〜1年程度のラグで比較されることが多いですが、景気局面によってラグは変わります。実体経済への波及には1年以上かかる場合もあります。

実務上は、以下のように見ます。

| クレジットインパルス | PMIへの示唆 |
|------------------|------------|
| 上昇基調 | 数か月〜1年後のPMI改善要因になりやすい |
| 低下基調 | 数か月〜1年後のPMI悪化要因になりやすい |
| 底打ち | 将来的な製造業サイクル改善の初期サインになりやすい |
| ピークアウト | 将来的な製造業サイクル鈍化の警戒サインになりやすい |

ただし、PMIは信用供給だけで決まるわけではありません。外需、輸出受注、在庫調整、米国景気、欧州景気、為替、地政学リスク、商品価格などにも左右されます。

そのため、クレジットインパルスはPMIの方向感を読む材料として有用ですが、単独で判断せず、PMIの内訳も確認する必要があります。

特に見るべき項目は以下です。

| 確認項目 | 見る理由 |
|--------|--------|
| 中国製造業PMI | 中国製造業全体の景況感 |
| 新規受注 | 内需の強さ |
| 新規輸出受注 | 外需の強さ |
| 生産 | 実際の製造活動 |
| 在庫 | 在庫循環の転換点 |
| 購入価格 | 原材料価格・インフレ圧力 |
| 出荷価格 | 企業の価格転嫁力 |
| グローバル製造業PMI | 中国信用サイクルの外部波及 |

## 5. 米10年債利回りとの関係

中国クレジットインパルスは、米10年債利回りと連動する局面があります。
主な理由は、中国の信用拡張が世界景気、商品市況、インフレ期待、リスク選好に影響するためです。

中国の信用供給が拡大すると、世界景気の改善期待が高まり、資源価格や製造業サイクルが上向きやすくなります。その結果、米長期金利にも上昇圧力がかかる場合があります。

一方、中国クレジットインパルスが低下すると、世界景気や商品需要への警戒感が強まり、米長期金利の低下要因になる場合があります。

ただし、米10年債利回りは中国要因だけでは動きません。以下の要因の影響が非常に大きいです。

### 米10年債利回りを動かす主な要因

- FRBの政策金利見通し
- 米国CPI・PCEなどのインフレ指標
- 米国雇用統計
- 実質金利
- 期待インフレ率
- タームプレミアム
- 米財政赤字・国債需給
- リスクオン・リスクオフ
- ドル需給
- 地政学リスク

そのため、中国クレジットインパルスは、米10年債利回りの補助的な先行確認指標として使います。
「中国クレジットインパルスが上昇しているから米10年債利回りも必ず上がる」といった機械的な判断は避けるべきです。

## 6. 日本株・日経平均との関係

中国クレジットインパルスは、日本株、とくに景気敏感株や外需関連株を見るうえでも重要です。

中国の信用供給が拡大すると、中国内需、インフラ投資、製造業投資、商品需要が改善しやすくなります。その結果、日本企業の一部にも追い風となります。

影響を受けやすい代表的な業種は以下です。

| 業種・テーマ | 影響を受ける理由 |
|-----------|---------------|
| 機械 | 中国の設備投資・製造業投資に連動しやすい |
| FA・ロボット | 中国製造業の設備投資と関係が深い |
| 半導体製造装置 | グローバル製造業・電子部品需要に影響されやすい |
| 電子部品 | 中国・アジア製造業サイクルに連動しやすい |
| 素材 | 鉄鋼、化学、非鉄などが中国需要の影響を受けやすい |
| 商社 | 資源価格・中国需要・世界景気に影響されやすい |
| 海運 | 貿易量、資源輸送、製造業サイクルに影響されやすい |
| 自動車関連 | 中国需要、世界景気、為替の影響を受けやすい |

日経平均は、半導体、電子部品、機械、外需、景気敏感セクターの影響を受けやすいため、中国クレジットインパルスの改善は中期的な支援材料になる場合があります。

ただし、日経平均は中国要因だけではなく、米国株、ドル円、米金利、日本企業の業績、指数寄与度の大きい個別銘柄にも強く左右されます。

そのため、中国クレジットインパルスは、日経平均を見るうえでは以下のように使うのが実務的です。

| クレジットインパルス | 日本株への見方 |
|------------------|--------------|
| 上昇基調 | 外需株・景気敏感株・資源関連に追い風になりやすい |
| 低下基調 | 製造業株・素材株・中国関連株には逆風になりやすい |
| 底打ち | 中国関連株や景気敏感株の反転材料になりやすい |
| ピークアウト | 製造業サイクル鈍化への警戒材料になりやすい |

ただし、株式市場は期待で先に動くため、クレジットインパルスの反転を確認した時点で、関連銘柄がすでに織り込んでいる場合もあります。株価を見る際は、PMI、企業業績、為替、米株、バリュエーションも併せて確認します。

## 7. PMIが50を下回る局面での見方

中国製造業PMIが50を下回る局面では、中国景気が減速している可能性が高まります。
このような局面では、中国当局が景気下支え策を強めやすく、クレジットインパルスの底打ちを探る材料になります。

ただし、PMIの50割れだけでクレジットインパルスの反転を判断するのは不十分です。
政策対応の強さは、不動産市況、地方政府債務、人民元相場、デフレ圧力、輸出環境、雇用情勢などによって変わります。

実務上は、PMIが50を割った局面で、以下のような指標に改善が出ているかを確認します。

| 確認項目 | 見るポイント |
|--------|------------|
| 社会融資総量 | 信用供給が増えているか |
| 人民元建て新規貸出 | 銀行貸出が増えているか |
| M1 | 企業の手元流動性・資金回転が改善しているか |
| M2 | 広義流動性が拡大しているか |
| 政府債発行 | 財政政策が強まっているか |
| 地方政府専項債 | インフラ投資の原資が増えているか |
| 不動産販売 | 不動産需要が底打ちしているか |
| 不動産投資 | 建設・資材需要の下げ止まり |
| PPI | 製造業デフレ圧力の改善 |
| 輸入 | 内需・資源需要の改善 |
| 銅・鉄鉱石価格 | 中国需要の市場反映 |
| 人民元相場 | 資本流出圧力・政策余地の確認 |

PMIが50を下回り、同時にクレジットインパルスが底打ちし始める場合は、数か月〜1年先の中国景気・グローバル製造業サイクルの改善を示唆する可能性があります。

一方、PMIが50を下回っていても、社会融資総量やM1、政府債発行、不動産指標に改善が見られない場合は、政策効果が弱く、景気低迷が長引く可能性があります。
