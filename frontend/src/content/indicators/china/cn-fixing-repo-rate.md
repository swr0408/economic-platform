## 指標の概要

**Fixing Repo Rate（FR / FDR）**は、中国の銀行間レポ市場における短期資金調達コストを示すベンチマーク金利です。中国外汇交易中心（CFETS / ChinaMoney）が公表しており、毎営業日の午前9:00〜11:30のレポ取引金利をもとに、11:30に公表されます。対象系列は、FR001・FR007・FR014・FDR001・FDR007・FDR014です。

レポ取引とは、債券などを担保に資金を借り入れ、一定期間後に買い戻す短期金融取引です。したがって、Fixing Repo Rateは中国の短期流動性、銀行間資金需給、政策金利の波及状況を確認するうえで重要です。

## FRとFDRの違い

| 系列 | 正式な性格 | 対象市場・対象取引 | 主な見方 |
| --- | --- | --- | --- |
| FR001 / FR007 / FR014 | Interbank Fixing Repo Rate | 銀行間市場のレポ取引全体 | 銀行間市場全体の短期資金調達コスト |
| FDR001 / FDR007 / FDR014 | Fixing Depository-institutions Repo Rate | 預金取扱金融機関による、国債・中央銀行証券・政策銀行債を担保とするレポ取引 | 銀行など中核的金融機関の資金調達コスト |

FRは、銀行間市場におけるO/N、7日物、14日物レポ取引を対象に算出されます。FDRはそのうち、預金取扱金融機関によるDR001・DR007・DR014取引をもとに算出されます。FDRの対象機関には、政策銀行、大型商業銀行、株式制商業銀行、都市商業銀行、農村商業銀行、外資系銀行、農村信用社、村鎮銀行などが含まれます。

## 各系列の意味

| 系列 | 意味 |
| --- | --- |
| FR001 | 銀行間レポ市場全体の翌日物レポ固定金利 |
| FR007 | 銀行間レポ市場全体の7日物レポ固定金利 |
| FR014 | 銀行間レポ市場全体の14日物レポ固定金利 |
| FDR001 | 預金取扱金融機関間の翌日物レポ固定金利 |
| FDR007 | 預金取扱金融機関間の7日物レポ固定金利 |
| FDR014 | 預金取扱金融機関間の14日物レポ固定金利 |

「001」は翌日物、つまりオーバーナイト、「007」は7日物、「014」は14日物を意味します。短期金融市場を見る場合は、特にFR007 / FDR007が重要です。7日物は中国人民銀行の7日物リバースレポ金利やDR007との比較対象になりやすく、金融政策の波及や市場流動性を見るうえで中心的な年限です。中国人民銀行の英語版トップページでもDR007が主要な市場指標として表示されています。

## 算出方法

FR001・FR007・FR014は、毎営業日の午前9:00〜11:30に成立したR001・R007・R014の取引金利を対象にします。同一相手先・同一金利の取引が複数ある場合は、サンプル上は1件として扱われます。そのうえで、金利を低い順に並べ、並べた件数をNとした場合、[N/2]を切り捨てた値 + 1番目の金利を当日のFixing Rateとします。つまり、単純平均や出来高加重平均ではなく、中央値に近い方法で決定されるベンチマークです。

FDR001・FDR007・FDR014も同様に、午前9:00〜11:30のDR001・DR007・DR014取引を対象に算出されます。ただしFDRは、預金取扱金融機関による、国債・中央銀行証券・政策銀行債を担保とするレポ取引が対象です。取引データが存在しない場合は、該当期間のSHIBORに365/360を掛けた値が代替的に使用されます。

## データの見方

Fixing Repo Rateが上昇している場合、短期資金の調達コストが上がっており、銀行間市場の流動性がややタイト化している可能性があります。逆に低下している場合は、短期資金が潤沢で、資金調達環境が緩和的になっている可能性があります。

ただし、単日の上昇・低下だけで金融政策の方向性を判断するのは適切ではありません。中国の短期金利は、月末・四半期末・年末、春節などの長期休暇前後、税期、国債発行、人民銀行の公開市場操作などの影響を受けやすいためです。実務上は、水準、トレンド、FRとFDRの差、7日物と翌日物の差、14日物の急騰を組み合わせて確認します。

## 重要な確認ポイント

### FR007 / FDR007の水準

FR007やFDR007は、中国の短期金融市場を見るうえで最も使いやすい系列です。特にFDR007は、預金取扱金融機関の7日物資金調達コストを表すため、DR007や中国人民銀行の7日物リバースレポ金利との比較に適しています。

FDR007が政策金利や通常レンジより大きく上振れしている場合、銀行間市場の資金需給がタイト化している可能性があります。一方、政策金利を下回って安定している場合は、市場流動性が比較的潤沢である可能性があります。

### FRとFDRのスプレッド

FRは銀行間市場全体、FDRは預金取扱金融機関に限定された系列です。そのため、FRがFDRを大きく上回る場合、銀行など中核的な預金取扱金融機関よりも、広い銀行間市場側で資金調達コストが上がっている可能性があります。

ただし、FR−FDRスプレッドの拡大を直ちに信用不安と解釈するのは避けるべきです。担保条件、取引参加者、時期要因、短期的な資金需給によっても変動します。

### 001・007・014の年限差

通常、資金の期間が長くなるほど、金利は高くなりやすいです。したがって、FR014やFDR014がFR001・FDR001に比べて大きく上昇している場合、2週間程度の資金調達に対する警戒感、休暇・月末・四半期末をまたぐ資金需要、または一時的な流動性プレミアムの上昇を示している可能性があります。

一方で、翌日物だけが急騰している場合は、ごく短期の資金需給の逼迫を示すことがあります。7日物・14日物まで連動して上昇している場合は、より広範な流動性タイト化として確認します。
