## SHIBORとは

SHIBORは、Shanghai Interbank Offered Rate（上海銀行間同業拆放利率）の略で、中国本土の銀行間人民元資金市場における代表的な短期金利指標です。中国語では「上海銀行間同業拆放利率」と表記され、信用力の高い銀行で構成される报价銀行団が提示する人民元の銀行間無担保資金の出し手側レートをもとに算出されます。公式説明では、SHIBORは「単利・無担保・卸売性」の金利と定義されています。

SHIBORは、中国の短期金融市場における資金需給、銀行間流動性、金融環境の変化を把握するために使われます。特に、翌日物から1カ月物までの短期ゾーンは日々の流動性変化を反映しやすく、3カ月物以上はより中期的な資金調達環境や金利見通しを確認する際に利用されます。

## 公表主体・算出方法

SHIBORは、全国銀行間同業拆借中心の技術プラットフォーム上で計算・公表されます。公表される期間は、O/N、1W、2W、1M、3M、6M、9M、1Yの8種類です。报价銀行団は18行の商業銀行で構成され、これらの銀行は公開市場操作のプライマリーディーラー、または外為市場のマーケットメーカーであり、中国の人民元貨幣市場で比較的活発に取引している銀行とされています。

算出方法は、各报价銀行の提示レートから最も高い4件と最も低い4件を除外し、残りの报价を単純平均する方式です。標準的には18行の报价から上下各4行を除くため、残り10行の平均がSHIBORとなります。公表時刻は、各営業日の北京時間11:00です。

| 項目 | 内容 |
| --- | --- |
| 正式名称 | Shanghai Interbank Offered Rate |
| 日本語名 | 上海銀行間取引金利、上海銀行間同業拆放利率 |
| 対象通貨 | 中国本土人民元、CNY |
| 金利性質 | 単利、無担保、卸売性の銀行間資金レート |
| 対象市場 | 中国本土の銀行間人民元資金市場 |
| 公表期間 | O/N、1W、2W、1M、3M、6M、9M、1Y |
| 公表時刻 | 各営業日 北京時間11:00 |
| 算出方式 | 18行の报价から上下各4行を除外し、残りを算術平均 |
| 表示単位 | 年率％ |
| Day count | Act/360 |
| 決済前提 | T+0 |

报价銀行は、各営業日の午前10:55までに报价を行い、O/Nから1Yまでの8期間について年率％、Act/360、T+0ベースで提示します。公式実施準則では、报价は4桁小数で行うとされています。

## 各期間の見方

| 期間 | 主な意味 |
| --- | --- |
| O/N | 翌日物。最も短期の銀行間資金需給を反映しやすい。流動性の逼迫や一時的な資金余剰に敏感。 |
| 1W | 1週間物。短期の資金繰り、公開市場操作、週次の流動性環境を見る際に有用。 |
| 2W | 2週間物。月末・連休前後など、やや長めの短期資金需要を確認する際に使いやすい。 |
| 1M | 1カ月物。月次の資金調達環境、銀行間の短期資金コストを見る指標。 |
| 3M | 3カ月物。短期市場だけでなく、四半期ベースの資金調達環境を確認する際に重要。 |
| 6M | 6カ月物。中期の人民元資金調達コストや金利期待を反映しやすい。 |
| 9M | 9カ月物。1年以内の中長めの資金調達環境を見る補助指標。 |
| 1Y | 1年物。1年以内の銀行間無担保人民元資金コストの目安。 |

短期ゾーン、特にO/Nや1Wは変動が大きく、日々の資金需給の影響を受けやすい一方、3M以上は比較的なめらかに推移しやすく、中期的な金融環境の変化を見るのに適しています。

## 重要な読み方

### 短期SHIBORの上昇

O/N、1W、2Wなどの短期SHIBORが上昇する場合、中国本土の銀行間市場で短期資金の需給が引き締まっている可能性があります。特にO/Nの急騰は、短期的な流動性逼迫、季末・月末要因、資金供給オペの不足感、金融機関の一時的な資金需要増加などを示すことがあります。

ただし、O/Nだけが一時的に上昇している場合は、恒常的な金融引き締めではなく、日次の資金需給要因である可能性もあります。そのため、1W、2W、1Mが同時に上昇しているかを確認する必要があります。

### 長期SHIBORの上昇

3M、6M、9M、1Yが上昇する場合、より中期的な資金調達コストの上昇や、金融機関の人民元資金調達環境の悪化を示唆することがあります。短期金利だけでなく長めのSHIBORも上昇している場合、単なる一時的な資金逼迫ではなく、市場全体で人民元資金コストが上がっている可能性を考えます。

### SHIBORカーブの傾き

SHIBORは単一の金利ではなく、O/Nから1Yまでの金利カーブとして見ることが重要です。

| カーブ形状 | 解釈の目安 |
| --- | --- |
| 短期だけ上昇 | 一時的な流動性逼迫、月末・季末要因、短期資金需要の増加 |
| 全期間が上昇 | 広範な金融環境の引き締まり、人民元資金コストの上昇 |
| 長期だけ上昇 | 中期の資金調達コスト上昇、金融政策・信用環境への警戒 |
| 短期が長期を上回る | 短期資金市場の強い逼迫、流動性ストレスの可能性 |
| 全期間が低下 | 流動性環境の改善、資金供給の増加、緩和的な金融環境 |

## 市場への影響

### 中国債券市場

SHIBORの上昇は、銀行間の人民元資金調達コスト上昇を示すため、短期債利回りや短期金融商品の利回りに上昇圧力をかけることがあります。特にO/Nや1Wの急騰は短期債市場に影響しやすく、3M以上の上昇はより広い期間の金利期待に影響しやすくなります。

### 株式市場

SHIBORの急上昇は、金融環境の引き締まりや短期流動性の悪化として受け止められることがあり、銀行、証券、不動産、レバレッジ依存度の高いセクターにはマイナス材料になりやすいです。ただし、株式市場への影響は、景気見通し、政策対応、信用供給、規制環境、海外リスク選好と同時に判断する必要があります。

### 人民元為替

SHIBOR上昇は人民元金利の上昇を通じて人民元の保有コストや短期金利差に影響します。ただし、人民元相場は金利だけでなく、基準値、資本規制、貿易収支、ドル指数、米中金利差、当局の為替管理姿勢にも大きく左右されます。そのため、SHIBOR上昇＝人民元高と単純化するのは不適切です。

### クレジット市場

銀行間資金調達コストが上がると、金融機関の資金運用・資金調達環境が厳しくなり、信用スプレッドや社債市場にも波及する場合があります。特に不動産、地方政府融資平台、低格付け社債など信用リスクが意識されやすい分野では、SHIBOR上昇と信用スプレッド拡大を併せて確認する価値があります。
