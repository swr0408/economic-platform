## 指標の概要

**Central Parity Rate（USD/CNY基準値、人民元対米ドルの中間値・Fixing）**とは、中国人民銀行（PBOC）の授権を受けた中国外貨取引センター（CFETS）が、各営業日に公表する人民元相場の公式な基準値です。USD/CNYでは「1米ドル＝何人民元か」を示すため、数値が上昇すると人民元安・米ドル高、数値が低下すると人民元高・米ドル安を意味します。CFETSは人民元の対米ドルおよび主要通貨に対するCentral Parity Rateを各営業日に算出・公表しています。

この基準値は、単なる市場実勢レートではなく、中国の管理変動相場制度における重要な参照レートです。オンショア人民元（CNY）のスポット取引は、この基準値を中心とした一定の変動許容範囲内で取引されます。現在のUSD/CNYオンショア・スポット市場では、CFETSが当日に公表した基準値を中心に上下2％の範囲内で取引される仕組みです。

## 公表主体・公表タイミング

公表主体は**中国外貨取引センター（CFETS / China Foreign Exchange Trade System）**です。PBOCが直接すべての市場価格を提示するというより、PBOCの授権を受けたCFETSが基準値を算出・公表する制度です。CFETSの公式ページでは、最新のCentral Parity Rate、過去データ、形成メカニズムが確認できます。

公表時刻は通常、北京時間の朝に行われます。CFETSの市場運営通知では、CNY Central Parity Rateの公表時刻は9:15 a.m.、USD/CNYスポットの終値時刻は**4:30 p.m.**と説明されています。インターバンク人民元外為市場のスポット取引は9:30から開始されるため、基準値は取引開始前にその日の取引レンジの中心として提示されます。

## USD/CNY基準値の算出メカニズム

USD/CNYのCentral Parity Rateは、CFETSが各営業日の市場開始前にマーケットメーカーから提示価格を取得し、そのデータをもとに算出されます。マーケットメーカーは、前営業日のインターバンク外為市場の終値、外為市場の需給状況、主要通貨の為替変動を参照して提示価格を出すことになっています。

算出時には、CFETSが提示価格のうち最高値と最低値を除外し、残りの価格について加重平均を計算します。加重平均のウェイトは、各マーケットメーカーの市場での取引量やマーケットメイク実績などを踏まえてCFETSが決定します。したがって、USD/CNY基準値は完全な固定レートではなく、市場価格を参照しつつも制度的に管理された公式基準値です。

## スポットレートとの違い

**基準値（Fixing）**は、その日のオンショア人民元取引における中心レートです。一方、USD/CNYスポットは実際の市場取引価格です。オンショア市場では、スポットレートは基準値を中心とした許容レンジ内で変動します。2014年3月17日以降、USD/CNYのオンショア・インターバンクスポット市場の変動幅は、基準値の上下2％に拡大されています。

チャート上で、基準値とスポットレートを並べて見ると、中国当局が市場実勢にどの程度追随しているか、または市場変動をどの程度抑制しようとしているかを把握しやすくなります。たとえば、スポットが基準値よりも大きく人民元安方向に乖離している場合、市場では人民元売り圧力が強いと解釈されやすくなります。逆に、基準値が市場予想より人民元高方向に設定される場合、当局が人民元安を抑制する意図を示していると受け止められることがあります。

## 見方の基本

USD/CNYは「1米ドルあたりの人民元価格」です。したがって、数値の方向と人民元の強弱は逆に見える点に注意が必要です。

| USD/CNYの動き | 意味 |
| --- | --- |
| USD/CNYが上昇 | 人民元安・米ドル高 |
| USD/CNYが低下 | 人民元高・米ドル安 |
| 基準値が前日より高い | 公式基準値ベースで人民元安方向 |
| 基準値が前日より低い | 公式基準値ベースで人民元高方向 |
| スポットが基準値より上 | 市場では人民元安方向に取引されている |
| スポットが基準値より下 | 市場では人民元高方向に取引されている |

特に重要なのは、基準値そのものの水準だけでなく、前日終値、市場予想、スポットレート、CNH、ドル指数、米中金利差などと比較することです。基準値が一見小幅な変化でも、市場予想から大きく外れていれば、政策シグナルとして重視される場合があります。

## 分析で確認すべきポイント

### 基準値の前日比

まず確認すべきなのは、基準値が前日から人民元高方向に動いたのか、人民元安方向に動いたのかです。小幅な変化であっても、連続して人民元高方向・人民元安方向に設定される場合、当局の為替安定姿勢や許容レンジを判断する材料になります。

### 基準値とスポットの乖離

基準値とスポットの差は、市場実勢と公式基準値のズレを示します。スポットが基準値より継続的に人民元安方向へ乖離している場合、市場の人民元売り圧力が強い可能性があります。一方、基準値が市場実勢より人民元高方向に置かれる場合、当局が過度な人民元安を抑えようとしている可能性があります。

### スポットが変動許容幅のどこにあるか

オンショアUSD/CNYスポットは基準値の上下2％内で取引されるため、スポットがそのレンジの上限に近づくほど人民元安圧力が強いと見られます。逆に下限に近づく場合は、人民元高方向の圧力が強いと解釈できます。2014年以降のUSD/CNYオンショア・スポット市場では、この上下2％の変動幅が制度上の重要な目安です。

### CNHとの比較

Central Parity Rateはオンショア人民元（CNY）に関する基準値です。オフショア人民元（CNH）は香港など中国本土外で取引される人民元であり、CNYよりも市場需給や海外投資家のリスク認識を反映しやすい場面があります。CNYとCNHの乖離が拡大する場合、オンショア市場とオフショア市場の見方に差が出ている可能性があります。

### ドル指数・主要通貨・通貨バスケット

CFETSの形成メカニズムでは、マーケットメーカーが主要通貨の為替変動も参照するため、USD/CNY基準値を見る際はドル指数や主要通貨の動きも確認する必要があります。CFETSの説明では、USD/CNYの提示にあたり、前日終値、外為市場の需給、主要通貨の動きが参照されます。

## 相場への影響

Central Parity Rateは、中国当局の為替政策スタンスを読むうえで非常に重要です。人民元は完全な自由変動相場ではなく、管理変動相場制度のもとで運営されています。IMFも、中国の為替制度について、2005年以降はより柔軟になってきたものの、依然として慎重に管理されていると説明しています。

人民元基準値は、以下の市場に影響を与える可能性があります。

| 影響対象 | 見るべきポイント |
| --- | --- |
| USD/CNY・USD/CNH | 人民元安・人民元高の政策許容度 |
| 中国株 | 人民元安が資本流出懸念や外資心理に影響する場合がある |
| 香港株 | CNHや中国リスクプレミアムを通じて影響しやすい |
| アジア通貨 | 人民元がアジア通貨のアンカーとして意識される場面がある |
| コモディティ | 中国需要・ドル建て価格・人民元購買力の連想で影響する場合がある |
| 米国債・ドル指数 | 人民元安圧力が強い局面では、ドル高・リスク回避と同時に観察されることがある |

ただし、Central Parity Rateだけで市場全体の方向を判断するのは不十分です。中国景気、米中金利差、ドル指数、中国株、資本フロー、PBOCの流動性供給、貿易摩擦、地政学リスクなどと合わせて確認する必要があります。

## 実務上の使い方

### 人民元安圧力の確認

USD/CNY基準値が連日人民元安方向に設定され、スポットも基準値より人民元安方向に推移している場合、人民元安圧力が強い局面と判断しやすくなります。この場合、中国株や香港株、アジア通貨、資源国通貨への波及を確認します。

### 当局の防衛ラインの確認

市場が人民元安方向に動いているにもかかわらず、基準値が市場予想よりも人民元高方向に設定される場合、当局が人民元安を抑制しようとしている可能性があります。これは、短期的にはUSD/CNHの上値抑制や人民元安ポジションの巻き戻しにつながる場合があります。

### リスクオン・リスクオフの補助指標

人民元は中国経済やグローバルリスク心理を反映しやすいため、Central Parity Rateはリスクオン・リスクオフ判断の補助指標として利用できます。人民元安が進む局面では、中国景気不安、資本流出懸念、ドル高圧力が意識されやすくなります。一方、人民元高方向の基準値設定やスポットの安定は、中国当局による為替安定姿勢や市場心理の落ち着きを示す材料になります。
