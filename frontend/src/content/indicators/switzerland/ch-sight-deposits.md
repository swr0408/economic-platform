## SNB当座預金（Sight Deposits with the SNB）とは

SNB当座預金とは、銀行などの金融機関がスイス国立銀行（SNB）に保有するスイスフラン建ての即時利用可能な預金残高を指す。銀行にとってSNBの当座預金は最も流動性の高い資産の一つであり、決済、最低準備要件の充足、短期流動性の確保に利用される。SNB自身も、当座預金残高を金融政策運営上の重要な流動性指標として位置づけている。

この指標は、スイスフラン市場の流動性、SNBの金融政策オペレーション、為替介入の可能性、短期金利のコントロール環境を確認するために使われる。ただし、単体で「SNBが介入した」「銀行が貸出を増やす／減らす」と断定できる指標ではない。

## データの位置づけ

SNBは、金融政策や経済監視に重要な統計を SNB Data Portal で公表している。現在、かつてPDF形式で公表されていた "Important monetary policy data" は、2022年4月19日を最後に従来形式のプレスリリースとしては終了し、それ以降は SNB Data Portal 上で公表されている。

本指標が参照している系列は、SNB Data Portal 上の "Sight deposits with the SNB" で、検索結果上では以下の時系列キーが確認できる。

| 項目 | 内容 |
| --- | --- |
| 指標名 | Sight deposits with the SNB |
| 日本語名 | SNB当座預金 |
| データセット | Monthly banking statistics |
| 系列キー | BSTA@SNB.MIRE_U.MIR.AAK.GGU{U,T,CHF,A50} |
| 単位 | CHF |
| Exponent | 3 |
| 実務上の表示 | 千CHF単位として扱い、通常は十億CHF（CHF bn）に換算して表示 |

## 何を表しているか

SNB当座預金は、SNBのバランスシート上では主に負債側に計上される項目である。SNBの負債には、銀行券、銀行のSNB当座預金、スイスフラン・レポ取引からの負債、SNB Bills、外貨建て負債、自己資本などが含まれる。これらの多くは、SNBによる金融政策運営、つまり市場への流動性供給または吸収を反映する。

SNB当座預金の主要な構成要素は、国内銀行の当座預金である。その他に、スイス連邦政府向け負債、外国銀行・外国機関の当座預金、清算機関や保険会社など非銀行主体の当座預金も含まれる。

## 増減要因

### 増加しやすい要因

SNBが流動性供給型のレポ取引を行うと、相手方のSNB当座預金口座にスイスフランが入金されるため、当座預金残高は増加する。また、SNBが外貨を購入し、対価としてスイスフランを供給する場合も、スイスフラン建て当座預金は増加する。

市場では、当座預金の急増が見られると、SNBによる為替介入、特にスイスフラン高を抑えるための外貨購入が疑われることがある。ただし、これはあくまで一つの解釈であり、レポ取引、SNB Billsの償還、その他の流動性操作でも増加し得る。

### 減少しやすい要因

SNBが外貨を売却してスイスフランを吸収する場合、当座預金は減少する。また、流動性吸収型のレポ取引、SNB Billsの発行、外貨スワップによるスイスフラン流動性の吸収も、当座預金を減少させる。

SNBは、2022年9月以降、金融環境の変化を受けて、流動性吸収型レポや短期SNB Billsの発行によって当座預金を減少させ始めた。この減少傾向は2023年から2024年にも続いたとSNBは説明している。

### その他の要因

銀行券流通高が増えると、銀行がSNB当座預金を現金に交換するため、当座預金は減少しやすくなる。また、SNBの利益分配がスイス連邦政府や州に行われる場合、当座預金が増加することがある。

## 金融政策との関係

SNBは、スイスフラン短期金融市場の金利、特に SARON を SNB政策金利の近くに維持することを重視している。そのために、当座預金への付利条件、流動性供給・吸収オペレーション、外貨取引などを組み合わせて金融市場の流動性を調整している。

SNBは、銀行や金融市場参加者がSNBに保有するスイスフラン建て当座預金に対して付利を行う。一定の閾値までは SNB政策金利が適用され、閾値を超える部分には SNB政策金利からディスカウントを差し引いた金利が適用される。また、最低準備要件を満たすために保有される当座預金部分は付利されない。

2026年3月19日の金融政策発表では、SNB政策金利は0%に据え置かれ、当座預金は一定閾値までは政策金利で付利され、閾値を超える部分には0.25ポイントのディスカウントが適用されると説明されている。

また、SNBは2026年3月1日から、最低準備要件の対象となる当座預金口座保有者について、付利閾値を計算するための係数を 16.5 から 15 へ引き下げた。これは金融政策スタンスそのものの変更ではなく、金融政策の実効性と短期金融市場の取引活性を維持するための調整と説明されている。

## 為替市場での見方

SNB当座預金は、CHF相場を見るうえで有用な補助指標である。特に EUR/CHF や USD/CHF と組み合わせると、SNBが市場にスイスフラン流動性を供給しているのか、逆に吸収しているのかを推測する材料になる。

一般的には、当座預金の大幅な増加は、スイスフラン流動性の増加を示す。外貨購入を伴う場合、これはスイスフラン売り介入に近い性質を持ち、CHF高を抑制する方向に働く可能性がある。一方、当座預金の減少は、流動性吸収、外貨売却、SNB Bills発行、流動性吸収型レポなどを反映し得る。

ただし、当座預金の増減だけで為替介入を断定するのは不適切である。SNB自身も、当座預金の水準は金融政策オペレーション、現金需要、その他の要因によって変化すると説明している。したがって、実務上は以下を同時に確認する必要がある。

| 確認項目 | 見る理由 |
| --- | --- |
| EUR/CHF・USD/CHF | CHF高圧力がある局面か確認 |
| SNB政策金利 | 付利条件と短期金利環境を確認 |
| SARON | SNB政策金利への誘導状況を確認 |
| SNB Bills・レポ取引 | 流動性吸収・供給の有無を確認 |
| 外貨準備・SNBバランスシート | 外貨購入・売却の可能性を確認 |
| 銀行券流通高 | 現金需要による当座預金減少を識別 |

## 解釈の目安

### 当座預金が増加している場合

スイスフラン流動性が増えている状態である。SNBによる流動性供給、外貨購入、レポ取引、SNB Billsの償還などが背景にある可能性がある。CHF高が進んでいる局面で同時に当座預金が急増する場合、市場では為替介入の可能性が意識されやすくなる。

### 当座預金が減少している場合

スイスフラン流動性が吸収されている状態である。SNB Billsの発行、流動性吸収型レポ、外貨売却、現金需要の増加などが背景にある可能性がある。2022年以降の減少局面では、SNBが金融環境の変化に応じて当座預金を減らしてきたことが公式に説明されている。

### 高水準が続いている場合

高水準の当座預金は、過去の大規模な流動性供給や外貨購入の結果を反映している可能性がある。ただし、「銀行が資金をSNBに滞留させて貸出をしていない」と単純に解釈するのは誤りである。SNBは、当座預金総額は SNB の金融政策オペレーションまたは現金との交換によってしか変化せず、個別銀行が当座預金を減らしても、それは別のSNB当座預金口座へ移るか、現金として流通するだけだと説明している。

## 誤解しやすい点

### 「増加＝必ず為替介入」ではない

当座預金の増加は、外貨購入を通じたスイスフラン供給で起こることがあるが、レポ取引、SNB Billsの満期、その他の流動性操作でも発生する。為替介入の可能性を見る場合は、為替レート、外貨準備、SNBの発表、短期金融市場の状況と合わせて確認する必要がある。

### 「減少＝必ず金融引き締め」ではない

当座預金の減少は流動性吸収を示すことがあるが、現金需要、レポ取引の満期、SNB Bills発行、外貨売却など複数の要因で生じる。単純に CHF高要因または金融引き締めと決めつけるべきではない。

### 「銀行が資金を溜め込んでいる指標」ではない

当座預金総額は、個別銀行の意思だけで増減するものではない。銀行間で資金が移動しても、SNB全体の当座預金総額は変わらないため、貸出姿勢を直接示す指標ではない。

### 「政府預金」とは異なる

SNB当座預金にはスイス連邦政府向け負債なども含まれ得るが、指標全体を「政府預金」と同一視するのは不正確である。主な構成要素は国内銀行のSNB当座預金であり、その他に外国銀行・機関、非銀行主体などの当座預金が含まれる。
