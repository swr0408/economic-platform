# カナダドル（CAD）

## 米国経済との結びつき

カナダドルは、豪ドルやNZドルと並ぶ代表的な資源国通貨ですが、性格はかなり異なります。最大の特徴は、**米国経済との結びつきの強さ**です。

- 2025年のカナダの財輸出のうち**71.7%**は米国向け
- カナダドルは**米景気、米通商政策、米金利、米ドルの動向**の影響を強く受ける

## 原油との結びつき

カナダドルは**原油との結びつきが強い**通貨です:

- カナダの貿易統計では、エネルギー製品が大きな純輸出超過
- 2024年にはエネルギー製品の純輸出額が**1,437億カナダドル**（最大）
- カナダから米国への原油・石油製品・天然ガス・NGLの輸出額は**1,630億カナダドル**（2023年）

CADをみる際は、豪ドルのように多種類の資源を広く見るより、まず**原油と米国要因を優先**するのが合理的です。

## 金利差の影響

カナダドルは金利差にも反応します:

- BoCは、カナダと米国の**金利差拡大がカナダドル安要因**となることを示している
- 2024年後半の局面では、対米金利差の拡大がCADの下落に寄与
- ただしBoCも、金利差だけでは説明しきれず、**為替リスクや米ドル要因**も重要だとしている

## 金価格との関係

金価格をカナダドルの主要ドライバーとして扱うのは適切ではありません。カナダは産金国でもありますが、BoCや公的統計が示す主要な説明軸は、あくまで**エネルギー・米国要因・金利差**です。金は補助材料としては見てもよいものの、原油以上に重視するのは避けた方が安全です。

## 実務上の要点

CADは**原油、米国景気、米加金利差の三本柱**でみるのが分かりやすいです。

| 材料 | 重要度 |
|------|--------|
| 原油価格 | 最重要 |
| 米国景気・通商政策 | 非常に重要 |
| 米加金利差（BoC vs FRB） | 重要 |
| 米ドル全体の強弱 | 重要 |
| 金価格 | 補助材料 |
