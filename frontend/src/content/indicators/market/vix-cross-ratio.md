## VIXクロスレシオとは

VIXクロスレシオは、株式市場のボラティリティ指標である **VIX** を分母に置き、株式以外の資産や別種のリスクを測るボラティリティ指数を分子に置いた比率である。両者の「水準そのもの」ではなく「相対関係」を見ることで、いま市場のどこにストレスが偏っているのか、リスクの性質がどう変化しているのかを読み取ることを目的とする。

VIXは、S&P 500指数オプション価格から算出される米国株式市場の今後30日程度の予想変動率である。これに対し、分子に置く各指数（VVIX・SKEW・MOVE・VXN・OVX・GVZ）は、それぞれ異なる市場・異なるリスクのインプライドボラティリティを表す。比率にすることで、VIX全体が上下しても、相対的な歪みだけを抽出できる点が特徴である。

この画面では、ビューを切り替えることで以下6種類のクロスレシオを確認できる。各比率には生値（分子・VIX）、必要に応じて移動平均と関連資産のオーバーレイが併せて表示される。

| 比率 | 分子の指数 | 何を測るか |
| --- | --- | --- |
| **VVIX/VIX** | VVIX（VIXのオプションから算出するVIX自身の変動率＝ボラのボラ） | 変動率の振れやすさが、変動率水準に対してどれだけ高いか |
| **SKEW/VIX** | SKEW（OTMプット価格に織り込まれたテールリスク指数） | 急落・テールリスクへの備えが、平常時ボラに対してどれだけ高いか |
| **MOVE/VIX** | MOVE（米国債オプションの予想変動率＝金利ボラ） | 金利・債券市場のストレスが、株式ボラに対してどれだけ高いか |
| **VXN/VIX** | VXN（Nasdaq 100のインプライドボラ） | ハイテク・グロース集中のリスクが、S&P全体に対してどれだけ高いか |
| **OVX/VIX** | OVX（原油ETFオプションの予想変動率） | 原油・エネルギーのストレスが、株式ボラに対してどれだけ高いか |
| **GVZ/VIX** | GVZ（金ETFオプションの予想変動率） | 金市場のストレスが、株式ボラに対してどれだけ高いか |

## 読み方

クロスレシオは「比率が上昇＝分子側のリスクが相対的に強まっている」「比率が低下＝株式（VIX）側のリスクが相対的に強まっている」と読むのが基本である。絶対水準よりも、過去のレンジに対して高いか低いか、トレンドが上向きか下向きかで判断するのが有効である。

### 1. VVIX/VIX

VVIXはVIXオプションから算出される「VIXの予想変動率」であり、いわゆるボラのボラ（vol-of-vol）である。VVIX/VIXが高いほど、VIX自体が大きく動くことが織り込まれている＝コンベクシティ需要やVIXコールによるテールヘッジが強い状態を示しやすい。VIXが落ち着いていてもVVIX/VIXが高止まりする場合、表面的な平静の裏で急変動への備えが残っている可能性がある。

### 2. SKEW/VIX

SKEWは、OTM（アウト・オブ・ザ・マネー）プットの相対的な割高さから、左裾（急落方向）のテールリスクを数値化したものである。SKEW/VIXが高いほど、平常時のボラ水準に対してクラッシュヘッジ・テールヘッジの需要が強いことを示しやすい。VIXが低いのにSKEW/VIXが高い局面は、市場が穏やかに見えても下方リスクへの保険が買われている「静かな警戒」を示すことがある。

### 3. MOVE/VIX

MOVEは米国債オプションから算出される金利のインプライドボラである。MOVE/VIXが高いほど、ストレスが株式よりも金利・債券市場に偏っていることを示しやすい。金融政策の不透明感、インフレ・財政を巡る金利急変動の局面で上昇しやすい。この画面では米国債10年利回りをオーバーレイ表示し、金利水準との関係を併せて確認できる。

### 4. VXN/VIX

VXNはNasdaq 100のインプライドボラである。VXN/VIXが高いほど、ハイテク・グロース株への集中リスクがS&P 500全体に対して強まっていることを示しやすい。AI・半導体・メガキャップ主導の相場でテック側の変動懸念が高まると上昇しやすい。Nasdaq 100をオーバーレイ表示する。

### 5. OVX/VIX

OVXは原油ETF（USO）オプションから算出される原油の予想変動率である。OVX/VIXが高いほど、エネルギー・原油市場のストレスが株式に対して相対的に強い状態を示しやすい。地政学リスク、供給ショック、需給急変の局面で上昇しやすい。WTI原油価格をオーバーレイ表示する。

### 6. GVZ/VIX

GVZは金ETF（GLD）オプションから算出される金の予想変動率である。GVZ/VIXが高いほど、金市場のボラが株式に対して相対的に高い状態を示す。安全資産需要の急変、実質金利・ドルの急変動、地政学リスクの局面で動きやすい。金価格をオーバーレイ表示する。

## 実務上の使い方

クロスレシオは、単体で売買シグナルとして使うより、VIX水準、株価指数の方向、金利、各資産価格、重要イベントと組み合わせて「リスクの所在」を確認するために使うのが有効である。

| 状況 | 解釈 |
| --- | --- |
| VIXは低いのに SKEW/VIX・VVIX/VIX が高い | 表面的な平静の裏でテール・急変動ヘッジが買われている可能性 |
| MOVE/VIX が上昇 | ストレスの中心が株式より金利・債券市場にある可能性 |
| VXN/VIX が上昇 | リスクがハイテク・グロースに集中している可能性 |
| OVX/VIX・GVZ/VIX が上昇 | 株式以外（原油・金）に固有ショックが発生している可能性 |
| 各比率が一斉に低下 | リスクが株式（VIX）側に回帰、または全般的なボラ正常化の可能性 |

移動平均（VVIX/VIXは5日、SKEW/VIXは20日）は、日次のノイズをならしてトレンドの向きを確認するために併用する。

## 注意点

クロスレシオは将来の価格方向を直接予測する指標ではない。比率が高い／低いことが、そのまま特定資産の上昇・下落を意味するわけではない。

また、分子と分母は対象市場も算出方法も異なる別個の指数である。VVIX・VXN・OVX・GVZはオプション価格ベースのインプライドボラ、SKEWはOTMプットの歪みから導く無次元の指数（おおむね100〜150のレンジ）、MOVEは金利オプションのbp建てボラであり、比率の絶対値そのものに普遍的な意味はない。必ず過去のレンジ（パーセンタイル的な高低）とトレンドで相対評価することが前提となる。

加えて、VIXが極端に低い局面では、わずかな分子の上昇でも比率が大きく見える点に注意が必要である。低VIX局面の比率上昇は、分子のリスク増大ではなく分母の低下による「見かけ上の上昇」であることがある。

データソースはCboe（VIX・VVIX・SKEW・OVX・GVZ・VXN）およびICE BofA（MOVE）系の日次終値で、関連資産（S&P 500・Nasdaq 100・米国債10年・WTI・金）をオーバーレイとして併記している。
