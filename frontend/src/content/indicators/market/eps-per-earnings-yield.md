# EPS・PER・株式益利回り

## EPS（1株当たり利益）

EPSは、企業の利益を1株当たりに換算した指標です。厳密には、普通株主に帰属する利益を、期中の加重平均株式数で割って算出します。上場企業では、基本EPSに加えて、転換社債やストックオプションなどの潜在株式を反映した希薄化後EPSも重要です。したがって、EPSを見るときは、単に「利益が増えたか」だけでなく、株式数の変化や希薄化の有無も合わせて確認する必要があります。

株価指数や個別株の分析でEPSを使うときは、実績EPSそのものよりも、予想EPSや予想EPSの上方・下方修正の方が市場に与える影響が大きいことが少なくありません。株価は将来の利益見通し、金利、リスクプレミアムの組み合わせで動くため、利益見通しの改善は株価の支援材料になりやすく、逆に見通し悪化は重しになりやすいです。

また、EPSの上昇がそのまま本業の収益力改善を意味するとは限りません。自社株買いで株式数が減ればEPSは押し上がりやすく、増資や希薄化があればEPSは押し下がりやすくなります。そのため、EPSは水準だけでなく、増減要因が業績要因なのか、株式数要因なのかを切り分けて見るのが重要です。

## PER（株価収益率）

PERは、株価を1株当たり利益で割った指標で、投資家が利益1円に対して何倍の価格を払っているかを示します。一般に、PERはその企業や指数に対する成長期待、収益の安定性、金利環境、リスク認識などを反映します。高PERは将来利益への期待やリスクの低さを、低PERは成長期待の弱さやリスクの高さを反映することがありますが、高いから必ず割高、低いから必ず割安とは言えません。比較する際は、自身の過去平均、同業他社、市場全体、金利環境をあわせて見るのが基本です。

PERを見るうえで重要なのは、trailing（過去実績ベース）なのか、forward（先行予想ベース）なのかを混同しないことです。実績PERと予想PERでは意味が異なり、株式市場では先行12か月予想利益を使ったforward PERが重視される場面が多くあります。とくに指数分析では、予想EPSを使うか、実績EPSを使うかで水準感も解釈も変わるため、定義を揃えて比較する必要があります。

理論的には、PERは利益成長率、無リスク金利、投資家が要求するリターン、リスクプレミアム、還元政策などの影響を受けます。したがって、PERは「市場心理だけ」で決まるわけではなく、金利低下・利益成長期待・リスク許容度改善などが重なると上がりやすく、逆に実質金利上昇・利益見通し悪化・リスク回避強まりでは下がりやすくなります。

PER主導で株価が上昇している局面は、EPSの上方修正を伴う上昇よりも不安定になりやすいことがあります。利益見通しが改善していないのにPERだけが拡大している場合、金利上昇やセンチメント悪化で評価倍率が縮小しやすいためです。したがって、株高局面では、株価上昇がEPS要因なのか、PER要因なのかを分けて見ることが有効です。

なお、EPSが赤字でマイナスのときはPERの解釈は難しくなります。これは割安を意味するものではなく、単に利益が出ていない状態を示します。こうした局面では、PERよりも売上成長率、営業利益率、キャッシュフロー、財務体質などを重視する方が適切です。

## 株式益利回り

株式益利回りは、EPSを株価で割ったもので、PERの逆数です。株価に対してどれだけ利益が乗っているかを見る指標で、株式の相対的な割高・割安感を考える際の基礎的な見方の一つです。益利回りが高ければ、利益に対して株価が相対的に低いことを、低ければ利益に対して株価が相対的に高いことを示します。

ただし、益利回りが高いからといって自動的に投資妙味が高いとは限りません。低成長、高リスク、利益の質の低さ、景気悪化懸念などを反映して高く見えている場合もあります。逆に、益利回りが低くても、利益成長期待が強く、リスクプレミアムが縮小している局面では株価が高く評価されることがあります。したがって、益利回りは単独で判断せず、利益見通し、金利、信用環境、リスク選好とあわせて見るのが安全です。

## S&P500益利回り − 10年実質金利

S&P500の12か月先予想益利回りから10年実質金利を引いた差は、株式と実質債券の相対価値や、投資家が株式に求める追加リターンをみるための実務的な proxy です。Federal Reserve の Financial Stability Report でも、S&P500の forward earnings-to-price ratio と 10年 expected real Treasury yield の差を、equity premium の一つの尺度として継続的に参照しています。

ただし、これは厳密な意味での implied ERP そのものではありません。Fed自身も、リスクプレミアムは直接観測できず、複数の指標やモデルでみる必要があるとしています。そのため、この差は株式と債券の相対評価をみる簡易指標として使うのが適切であり、単独でフェアバリューを断定する用途には向きません。

このスプレッドの縮小は、実質金利上昇、利益見通し悪化、または株式に対するリスク許容度の変化を反映しうるため、株式の相対的な魅力が低下している可能性を示します。逆に拡大は、実質金利低下や利益見通し改善を示すことがありますが、株価急落などのストレス局面でも起こりえます。したがって、拡大＝常に追い風、縮小＝常に悪材料と機械的に決めつけるべきではありません。株価、EPS改定、実質金利、ボラティリティとあわせて、トレンドと過去レンジの中で読むことが重要です。

なお、Fedの資料で用いられる実質金利は、単純な市場の10年TIPS利回りそのものではなく、expected real Treasury yieldです。したがって、実務上10年TIPS実質利回りで近似することは可能でも、Fed完全準拠の再現ではない点には注意が必要です。

## 実務での見方

実務上は、株価をEPS要因とPER要因に分けて考えると、相場の質が把握しやすくなります。

- **EPS上昇＋PER上昇**：業績改善と評価改善が同時に進む強い相場
- **EPS上昇＋PER低下**：業績は強いが金利上昇や評価圧縮が重石
- **EPS低下＋PER上昇**：金融緩和期待やリスク選好で支えられる相場
- **EPS低下＋PER低下**：業績悪化と評価悪化が重なる弱い相場

という整理が有効です。株価は将来利益、金利、リスク補償で説明されるため、この分解は市場解釈に役立ちます。

また、指数でEPS・PERを使う場合は、実績か予想か、基本EPSか調整後EPSか、どのデータベンダー定義かを揃えることが重要です。指数のEPSは個別企業の会計上のEPSと完全には同じではなく、継続事業ベース、調整後、コンセンサス予想など定義差があるため、比較時には系列の一貫性を優先すべきです。

## ISM製造業景況指数と予想EPSの関係

ISM製造業景況指数の改善は、企業業績見通しの改善と整合的に動きやすい傾向があります。製造業の受注や生産が持ち直す局面では、企業の売上や利益率の期待が上向きやすく、それがアナリストの業績予想に反映され、最終的に株価の支えになりやすいためです。

ISMの前年差 と S&P500予想EPSの前年比 は強い正の関係を示しました。ただし、この関係はISMが明確に大きく先行するというより、同時期に連動しやすいという見方のほうが適切です。市場はISM公表前から先回りして業績見通しを織り込むことがあるため、ISM改善を見てからEPSが必ず後追いで改善する、という単純な一方向関係ではありません。したがって、ISMはEPSの方向感を確認する材料としては有用ですが、単独で予想EPSの将来を機械的に決める指標ではありません。
