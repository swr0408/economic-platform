## この画面で確認できること

この画面では、米国の気温由来のエネルギー需要を把握するために、HDD（Heating Degree Days：暖房度日）、CDD（Cooling Degree Days：冷房度日）、および CPCの気温・降水見通しを確認できる。

HDD/CDD は、気温がエネルギー需要に与える影響を数値化した指標である。HDDは主に冬場の暖房需要、CDDは主に夏場の冷房需要を測るために使われる。NOAA/CPC は、degree day を住宅・事業所の暖房・冷房エネルギー需要を反映する定量指標として説明している。

この画面は、特に天然ガス市場を見る際に有用である。冬は HDDの増加が暖房用ガス需要を押し上げやすく、夏は CDDの増加が冷房用電力需要を通じて発電用ガス需要を押し上げやすい。ただし、価格への影響は在庫水準、LNG輸出、供給量、パイプライン制約、予報の織り込み度合いにも左右されるため、HDD/CDD 単独で売買判断を行うべきではない。

## HDD/CDDの計算方法

HDD/CDD は、日平均気温と基準温度である 65°F との差から計算される。NOAA/CPC の説明では、日平均気温は日最高気温と日最低気温の平均であり、HDD/CDD の基準はどちらも 65°F である。

計算式は次の通り。

| 指標 | 計算式 | 意味 |
| --- | --- | --- |
| HDD | max(65°F − 日平均気温, 0) | 気温が低いほど暖房需要が増えやすい |
| CDD | max(日平均気温 − 65°F, 0) | 気温が高いほど冷房需要が増えやすい |

例として、日平均気温が 50°F なら HDDは15、CDDは0。日平均気温が 80°F なら HDDは0、CDDは15。

注意点として、1地点だけを見れば同じ日に HDDと CDDが同時に大きくなることは基本的にない。しかし、米国全体や広域の人口加重データでは、北部で暖房需要、南部で冷房需要が同時に発生するため、HDDと CDDが同じ日にどちらも表示されることがある。本データも日付ごとに hdd と cdd を持つ日次系列として構成されている。

## データソースの特徴

本画面の主要データソースは NOAA CPC（Climate Prediction Center）である。CPC は、日次の HDD/CDD を米国の気候区分、州、Census division、CONUS などの単位で提供しており、現在の CPC の degree days ページでは、日次 HDD/CDDについて 2010年国勢調査の人口データと、暖房燃料顧客人口について 2010年ACSデータを使用していると説明されている。

CPC は、実績の日次 HDD/CDD に加えて、同じ地域区分について次の 7日間の予測値も提供している。この 7日予測は、NDFD（National Digital Forecast Database）のグリッド予報に基づくものである。CPC ページでは、日次実績、7日予測、1981–2010年平年値がそれぞれ提供されている。

NDFD は、NWS の Weather Forecast Offices と NCEP のデータを用いて作成される、気温・降水・風などのグリッド型予報データベースである。NCEI は、NDFD を NWS が作成する予報および NCEP のグリッドモデルデータを利用したデータベースとして説明している。

## 気温見通しの読み方

気温見通しでは、CPC の 6–10日、8–14日 などの見通しを使い、各地域について気温が平年より高い、平年並み、平年より低いのどれに傾きやすいかを表示する。

CPC の 6–10日見通しは、日次で米国東部時間の午後 3時〜4時頃に発表される。8–14日見通しも同様に日次で発表される。

CPC の気温見通しは、対象期間の平均気温が次の 3分類のどれに入りやすいかを確率で示すものである。

| 表示 | CPC表記 | 意味 |
| --- | --- | --- |
| 暖 | A / Above | 平年より高い気温になりやすい |
| 平年 | N / Near normal | 平年並みになりやすい |
| 寒 | B / Below | 平年より低い気温になりやすい |

CPC は、6–10日気温見通しについて、対象期間の平均気温が「below / normal / above」の 3分類のどれに入る確率が高いかを示すものと説明している。これらの分類は、1991–2020年の気候値を 3等分したカテゴリに基づく。

重要なのは、「暖」は具体的に何度高いかを示すものではなく、平年より高いカテゴリに入る確率が相対的に高いという意味である点である。CPCの説明でも、色の濃淡は予報官の確信度、等値線の数値は該当カテゴリの確率を示すとされている。

## HDD/CDDと気温見通しの関係

HDD/CDD は、気温の実績または予測から計算された需要量に近い指標である。一方、気温見通しは、平年より暖かい・寒い・平年並みになりやすいという確率カテゴリである。

そのため、次のように使い分ける。

| 見る項目 | 主な役割 |
| --- | --- |
| HDD/CDD実績 | 直近の暖房・冷房需要がどの程度発生したかを見る |
| HDD/CDD予測 | 今後数日間の需要増減を数値で見る |
| 6–10日・8–14日見通し | 需要トレンドが続きやすいか、反転しやすいかを見る |
| 降水見通し | 気温需要を補助的に解釈する。多雨・曇天は冷房需要を抑える場合がある |

特に天然ガスでは、単純に「暖かい＝強気」「寒い＝弱気」とはならない。冬の暖かさは HDD を減らしやすいため弱気材料になりやすく、夏の暖かさは CDD を増やしやすいため強気材料になりやすい、という季節依存の解釈が必要である。

## 天然ガス市場での基本的な読み方

天然ガス市場では、HDD/CDD を次のように解釈する。

| 状況 | 需要面の解釈 | 天然ガス価格への一般的な示唆 |
| --- | --- | --- |
| 冬に HDD が増加 | 暖房需要が増えやすい | 強気材料になりやすい |
| 冬に HDD が減少 | 暖房需要が弱まりやすい | 弱気材料になりやすい |
| 夏に CDD が増加 | 冷房用電力需要・発電用ガス需要が増えやすい | 強気材料になりやすい |
| 夏に CDD が減少 | 冷房需要が弱まりやすい | 弱気材料になりやすい |
| 春・秋に HDD/CDD が低い | 天候由来の需要が弱い | 方向感が出にくい場合がある |

ただし、価格反応で重要なのは絶対水準だけではなく、予報の変化幅である。すでに市場が寒波や熱波を織り込んでいる場合、HDD/CDD が高くても追加の強気材料にならないことがある。逆に、直前の予報から HDD/CDD が大きく上方修正されると、価格が反応しやすくなる。

## 重点地域の考え方

天然ガス需要を見る場合、米国全体の HDD/CDD だけでなく、人口密度や暖房需要の大きい地域を重視する。画面上では、East North Central、Northeast、Mid-Atlantic などを天然ガス需要の重要地域として確認できる構成にしている。

特に冬場は、以下の地域の寒気が重要である。

| 地域 | 見る理由 |
| --- | --- |
| East North Central | 暖房需要が大きく、寒波時の HDD 増加が天然ガス需要に効きやすい |
| Northeast / Mid-Atlantic | 都市圏・暖房需要が大きく、冬場の需要変化を確認しやすい |
| South / Texas | 夏場の CDD 増加による冷房・発電需要を見る際に重要 |

地域別の気温見通しでは、単に「米国全体が暖かいか」ではなく、需要の大きい地域が暖かいのか、寒いのかを確認することが重要である。

## 降水見通しの補助的な使い方

気温見通しと併せて、降水見通しも確認する。CPC の見通しでは、降水についても A/N/B が使われるが、気温とは意味が異なる。CPC の説明では、気温は A=Above、N=Near normal、B=Below であり、降水は A=Above、N=Near median、B=Below として整理されている。

降水見通しは、天然ガス需要に対して間接的に影響する。夏場は多雨・曇天が冷房需要を抑える場合があり、冬場は降水を伴う寒気が暖房需要や地域の需給制約に影響する場合がある。ただし、降水見通しは HDD/CDD そのものではないため、需要判断では気温・HDD/CDD を主軸にし、降水は補助材料として扱う。
