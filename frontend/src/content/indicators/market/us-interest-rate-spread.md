## イールドカーブの見方と監視頻度

### 概要

イールドカーブは、残存期間ごとの国債利回りを結んだ曲線です。
短期金利は主に金融政策見通しを、長期金利は景気・インフレ・需給・タームプレミアムを反映しやすいため、イールドカーブの形状や変化を見ることで、金融政策、景気サイクル、市場のリスク選好、債券需給を把握できます。

実務上は、単にカーブの形を見るだけでなく、どの年限が主導して動いたかまで確認することが重要です。
同じスティープ化でも、短期金利低下によるものか、長期金利上昇によるものかで、市場への意味合いは大きく異なります。

---

## どの頻度で見るべきか

### 日次で見る意義

日次では、日々の市場判断に必要な変化を確認します。主に見るのは以下です。

- カーブがスティープ化しているか
- フラット化しているか
- それが短期主導か長期主導か
- CPI、雇用統計、FOMC、国債入札、四半期定例入札、財政関連材料の後にどう変化したか

日次で重要なのは、同じ「スティープ化」でも意味が異なるためです。
たとえば、短期金利低下によるスティープ化は利下げ期待を反映しやすく、長期金利上昇によるスティープ化は成長期待・インフレ期待・国債供給懸念を反映しやすいです。
株式、為替、金などへの影響も変わるため、日次では「形」だけでなく「どこが動いたか」を見る必要があります。

### 週次で見る意義

週次では、日々のノイズを落として、相場テーマの継続性を確認します。主に以下の判断に向いています。

- 金融引き締めが続いているか
- 景気期待が上向いているか
- recession trade が強まっているか
- 逆イールドの深さや再スティープ化の進行がどうか

週次は、短期イベントの反応ではなく、その週を通じて市場が何を織り込んだかを見るのに適しています。

### 月次で見る意義

月次では、景気局面の確認に使います。
主に以下の局面判定に有効です。

- 景気回復初期
- 景気過熱
- 景気減速
- 景気後退
- 緩和局面

月次では、金融政策と景気サイクルの関係をより大きな流れで把握できます。
短期ノイズよりも、景気と政策の整合性を見ることが主目的です。

## 主要5スプレッドの見方

### 1. 2年-10年スプレッド（2s10s）

最も広く参照される代表的な長短金利差です。
2年金利は今後の政策金利見通しを、10年金利は景気・インフレ・タームプレミアム・中期成長期待を反映しやすいため、金融政策と先行き景気の綱引きを見るのに適しています。

**何を見るか**

- 引き締めが強まっているか
- 景気やインフレ期待が上向いているか
- 逆イールドが深まっているか
- 再スティープ化が進んでいるか

**向いている頻度**: 日次（最重要）、週次（重要）、月次（重要）

### 2. 3か月-10年スプレッド（3m10y）

景気後退シグナルとして特に有名な組み合わせです。
3か月金利は現在の政策金利に近く、10年金利は先行きの成長・インフレ期待を含むため、今の政策が将来の成長見通しに対して厳しすぎないかを見るのに適しています。

**何を見るか**

- 景気後退リスク
- 金融引き締めの行き過ぎ
- 逆イールドの深さ
- 景気減速シグナルの継続性

**向いている頻度**: 日次（補助的）、週次（重要）、月次（最重要）

### 3. 5年-30年スプレッド（5s30s）

一般向けにはやや地味ですが、金利市場では非常に実務的な指標です。
5年金利は政策の先数年や中期景気見通しを、30年金利は超長期のインフレ期待・需給・タームプレミアム・年金/保険需要を反映しやすいため、ロングエンドの質や歪みを見るのに向いています。

**何を見るか**

- 超長期債の需給悪化
- 財政赤字懸念
- 国債増発やQTの影響
- タームプレミアムの変化
- 長期インフレ不安

**向いている頻度**: 日次（重要）、週次（重要）、月次（補助的に有用）

### 4. 10年-30年スプレッド（10s30s）

より超長期ゾーンに特化したスプレッドです。
景気後退判断よりも、超長期債の需給、年金・保険の買い、財政拡大による供給懸念などを見る色合いが強いです。

**何を見るか**

- 超長期だけ特別に売られていないか
- 30年ゾーンの需給悪化
- タームプレミアムの変化
- 年金・保険の需要変化

**向いている頻度**: 日次（補助的）、週次（補助的）、月次（補助的）

### 5. 3か月-2年スプレッド（3m2y）

短期政策見通しを読むうえで有用な指標です。
3か月金利は現在の政策金利に近く、2年金利は今後1〜2年程度の利上げ・利下げ期待を反映しやすいため、市場が近い将来の政策変更をどう織り込んでいるかを確認できます。

**何を見るか**

- 利上げ継続を織り込んでいるか
- 利下げ転換を織り込んでいるか
- FOMC前後で政策見通しがどう変わったか

**向いている頻度**: 日次（補助的）、週次（補助的）、月次（補助的）

## 頻度ごとに一般的に見る組み合わせ

### 日次で一般的

日次では、市場がその日にどこを動かしたかを確認するため、政策近辺と長期ゾーンの反応が分かりやすい組み合わせが使われます。

**主に見る組み合わせ**: 2s10s、5s30s

**補助的に見る組み合わせ**: 10s30s、2s30s

日次では3か月金利は政策金利に近く、短期間ではあまり動かないことがあるため、日々のカーブ変化を見る主役は2年・10年・30年になりやすいです。

### 週次で一般的

週次では、相場テーマの継続性や逆イールドの深さを確認します。

**主に見る組み合わせ**: 2s10s、3m10y、5s30s

| 組み合わせ | 役割 |
|---|---|
| 2s10s | その週が政策主導か景気期待主導かを見る |
| 3m10y | 景気減速シグナルの継続性を見る |
| 5s30s | ロングエンドのストレスを見る |

### 月次で一般的

月次では、景気サイクルと金融政策サイクルを大きな流れで確認します。

**主に見る組み合わせ**: 3m10y、2s10s

**補助的に有用**: 2s30s、5s30s

| 組み合わせ | 役割 |
|---|---|
| 3m10y | 景気後退リスクを最も分かりやすく確認 |
| 2s10s | 引き締め局面か緩和期待局面かを把握 |
| 2s30s | カーブ全体の歪みを把握 |
| 5s30s | 長期財政・供給要因が中長期に効いていないか確認 |

## スティープ化・フラット化の基本定義

### ベアスティープニング

利回りが全体として上昇し、かつ長期金利の上昇幅が短期金利より大きく、長短金利差が拡大する状態です。
背景としては、景気回復期待、インフレ期待上昇、財政拡張、国債増発懸念、タームプレミアム上昇などが考えられます。

**市場への典型的影響**

| 資産 | 影響 |
|---|---|
| 債券 | 下落 |
| 株 | 景気期待主導なら景気敏感株やバリュー株に追い風 |
| グロース株 | 長期金利急騰なら逆風 |
| 銀行株 | 比較的追い風 |
| 為替 | その国の長期金利上昇が優勢なら通貨高要因 |
| 金 | 実質金利上昇なら逆風 |

### ベアフラットニング

利回りが全体として上昇し、かつ短期金利の上昇幅が長期金利より大きく、長短金利差が縮小する状態です。
背景としては、中央銀行の利上げ、金融引き締め、景気過熱抑制、先行き成長期待の鈍化などが考えられます。

**市場への典型的影響**

| 資産 | 影響 |
|---|---|
| 債券 | 特に短期債が弱い |
| 株 | 全体として逆風になりやすい |
| グロース株 | 割引率上昇で不利 |
| 銀行株 | フラット化しすぎると逆風 |
| 為替 | 利上げ通貨として買われやすいことが多い |

### ブルスティープニング

利回りが全体として低下し、かつ短期金利の低下幅が長期金利より大きく、長短金利差が拡大する状態です。
背景としては、利下げ期待、景気減速、景気後退入り、緩和転換などが考えられます。

**市場への典型的影響**

| 資産 | 影響 |
|---|---|
| 債券 | 上昇 |
| 株 | 初期は景気悪化懸念で弱くなりやすい。その後、利下げ安心感で持ち直す場合もある |
| 銀行株 | 景気悪化懸念が強いと弱くなりやすい |
| グロース株 | 金利低下で支えられやすいが、景気悪化が重いと一概に強いとはいえない |

### ブルフラットニング

利回りが全体として低下し、かつ長期金利の低下幅が短期金利より大きく、長短金利差が縮小する状態です。
背景としては、インフレ沈静化、長期成長期待の低下、安全資産需要、QE、景気減速の先取りなどが考えられます。

**市場への典型的影響**

| 資産 | 影響 |
|---|---|
| 債券 | 長期債が強い |
| 株 | ディフェンシブ株には比較的追い風 |
| グロース株 | 長期金利低下で支えられる場合がある。ただし景気不安が背景なら景気敏感株には逆風 |
| 為替 | 長期金利低下だけなら通貨安要因になりやすいが、リスクオフでは逆になることもある |

### ツイストスティープニング

短期金利が低下し、長期金利が上昇し、長短金利差が拡大する状態です。
利下げ期待と長期インフレ懸念、または長期需給悪化が同時に出ている場面で見られやすいです。

### ツイストフラットニング

短期金利が上昇し、長期金利が低下し、長短金利差が縮小する状態です。
引き締め進行と先行き景気鈍化期待が同時に進んでいる場面で見られやすいです。

## 画像の説明を使う際の注意点

画像の定義部分は概ね正しいですが、そのまま機械的に株価や為替と一対一対応させるのは危険です。

**注意点1**: 「ベア」「ブル」は株式ではなく債券の言葉です。

- ベア = 債券安 = 利回り上昇
- ブル = 債券高 = 利回り低下

したがって、ベアスティープニングだから株に必ず弱い、ブルフラットニングだから株に必ず強い、とは限りません。

**注意点2**: 同じ形でも背景によって意味が変わります。

たとえばベアスティープニングでも、
- 景気回復・インフレ期待上昇が理由なら株にプラス寄り
- 財政悪化・国債増発・タームプレミアム上昇が理由なら株にマイナス寄り

となります。

**注意点3**: 為替との関係も固定ではありません。

為替は以下の要因で変わります。
- どの国のカーブか
- 実質金利か名目金利か
- 金利差か景気差か
- リスクオン/オフか

そのため、図中の円高・円安方向は参考程度に扱うのが適切です。

## 逆イールド解消は必ずしも安心材料ではない

逆イールドの後にカーブが再びスティープ化しても、それだけで景気懸念の後退を意味するとは限りません。長期金利上昇主導のスティープ化であれば、成長期待・インフレ期待・国債供給懸念・タームプレミアム上昇を反映している可能性があります。一方で、短期金利低下主導のスティープ化であれば、利下げ観測や景気悪化懸念が強まっている可能性があります。Fedのnear-term forward spreadの議論でも、近い将来の政策金利低下を市場が織り込むとスプレッドが低下し、それは景気鈍化・景気後退懸念の反映でありうると説明されています。したがって、逆イールド解消＝景気後退回避とは機械的に読まない方が安全です。

この点からも、イールドカーブは「景気後退を引き起こす指標」としてではなく、市場が将来の金融政策や景気減速を先回りして織り込んでいることを示す先行指標として扱うのが適切です。FRBSFは、逆イールドと景気後退の相関は強い一方で、相関だけでは因果関係は特定できないと明記しており、Fedもnear-term spreadの予測力は市場参加者の政策見通しを反映した結果だと整理しています。

## 銀行株・貸出との関係は「要注意」だが単純化しすぎない

イールドカーブのフラット化や逆イールドは、一般に銀行の利ざや圧迫リスクとして意識されます。実際、Fedの分析では、引き締め局面では短期金利上昇とカーブのフラット化によって、銀行の純金利マージン（NIM）が低下または横ばいになりやすいとされています。

ただし、これも「逆イールド＝銀行株急落・貸出急減」と機械的に結びつけるのは危険です。FedのFOMC公開メモでは、かなりのフラット化でも銀行のNIMが大きくは影響を受けなかった局面があり、銀行は資産・負債のリプライシング調整やヘッジである程度対応してきたとされています。また、影響は逆イールドの継続期間、短期金利上昇主導かどうか、預金金利の上がり方、銀行の業態によって変わると整理されています。したがって、銀行セクターを見るときは、イールドカーブだけでなく、SLOOS、貸出伸び、銀行株の相対パフォーマンスも併せて確認する方が実務的です。

## 長期金利は「景気期待」だけでなくタームプレミアムでも動く

長期金利は、単純に「将来の政策金利見通し」だけで決まるわけではありません。New York Fedの整理では、長期国債利回りは、将来の短期金利見通しとタームプレミアムに分解して考えることができます。タームプレミアムとは、将来の短期金利が想定どおりに推移しないリスクを投資家が引き受ける対価です。したがって、10年金利や30年金利の上昇を見たときは、景気・インフレ期待の上振れなのか、財政赤字・国債増発・QT・需給悪化などによるタームプレミアム上昇なのかを分けて考える必要があります。

## 実務上の見方

実務では、次の順序で確認すると整理しやすいです。

1. 2年金利は上がったか下がったか
2. 10年金利は上がったか下がったか
3. 30年金利はどう動いたか
4. スプレッドは拡大したか縮小したか
5. その変化は政策要因か、景気要因か、供給要因か
6. 株式、為替、クレジットスプレッドはどう反応したか

イールドカーブは「形そのもの」よりも、どの年限が、なぜ動いたかまで合わせて読むのが重要です。
