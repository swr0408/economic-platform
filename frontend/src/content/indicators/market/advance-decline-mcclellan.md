# A/Dライン・マクレランオシレーター

## 1. 概要

**A/Dライン（Advance/Decline Line）** と **マクレランオシレーター（McClellan Oscillator）** は、どちらも米国株式市場の**マーケット・ブレッドス（市場の内部参加度）**を見る指標です。

S&P500やNasdaq100のような時価総額加重指数は、NVDA、MSFT、AAPLなど一部大型株の影響を強く受けます。一方、A/Dラインやマクレランオシレーターは、上昇銘柄数と下落銘柄数の差を使うため、**指数上昇が市場全体に広がっているのか、それとも一部大型株だけに偏っているのか**を確認するために使われます。

---

## A/Dライン

### 2. A/Dラインとは

A/Dラインは、日々の **上昇銘柄数 − 下落銘柄数** を累積した指標です。StockChartsは、A/Dラインを「Net Advances、つまり上昇銘柄数から下落銘柄数を引いた値に基づくブレッドス指標」と説明しています。A/DラインはNet Advancesがプラスなら上昇し、マイナスなら低下します。

計算式は以下です。

```
Net Advances = 上昇銘柄数 − 下落銘柄数

A/D Line = 前日のA/D Line + 当日のNet Advances
```

初回値は任意の開始点から計算されるため、A/Dラインでは **絶対値そのものより、方向、傾き、高値更新・安値更新、指数との乖離** を見ることが重要です。StockChartsも、A/Dラインの実際の値は計算開始点に依存し、重要なのは線の形状と方向だと説明しています。

### 3. A/Dラインが示すもの

A/Dラインは、相場上昇または下落にどれだけ多くの銘柄が参加しているかを示します。

| 状態 | 解釈 |
|---|---|
| 指数上昇 + A/Dライン上昇 | 上昇参加銘柄が広がっている。健全な上昇 |
| 指数上昇 + A/Dライン低下 | 一部大型株主導の上昇。ブレッドス悪化 |
| 指数下落 + A/Dライン低下 | 下落参加銘柄が多い。市場内部は弱い |
| 指数下落 + A/Dライン上昇 | 下落参加銘柄が減っている。売り圧力鈍化の可能性 |

典型的な使い方は、**指数とのダイバージェンス確認**です。StockChartsは、A/Dラインが指数の上昇・下落を同方向に確認すべきであり、強気・弱気ダイバージェンスは市場参加度の変化を示し、反転を先取りする可能性があると説明しています。

### 4. A/Dラインの代表的な見方

#### 4.1 上昇相場の確認

指数が高値を更新しているときにA/Dラインも高値を更新していれば、上昇は広範な銘柄に支えられています。これは、指数上昇の質が比較的良い状態です。

反対に、S&P500やNasdaqが高値を更新しているのにA/Dラインが伸びない場合、指数上昇が大型株や一部セクターに偏っている可能性があります。

#### 4.2 弱気ダイバージェンス

```
指数：高値更新
A/Dライン：高値更新できない、または低下
```

この場合、指数は強く見えても、内部では上昇参加銘柄が減っている可能性があります。**天井圏の警戒材料**になります。

#### 4.3 強気ダイバージェンス

```
指数：安値更新
A/Dライン：安値更新しない、または切り上がる
```

この場合、指数は弱く見えても、下落参加銘柄が減っている可能性があります。**底打ち前の内部改善**として使われます。

### 5. A/Dラインの注意点

#### 5.1 時価総額加重指数とは性質が違う

A/Dラインは、基本的に1銘柄を1票として扱います。大型株も小型株も、上昇なら+1、下落なら-1です。そのため、時価総額加重のS&P500やNasdaq100とは挙動がズレます。StockChartsも、A/D統計は小型株・中型株の影響を相対的に強く受け、大型株1銘柄の上昇も小型株1銘柄の上昇も同じ1件として数えると説明しています。

#### 5.2 Nasdaq A/Dラインは長期低下しやすい場合がある

Nasdaqは成長株・小型株・投機的企業が多く、上場廃止や入れ替えの影響を受けやすいため、Nasdaq A/DラインはNasdaq指数と長期的に乖離することがあります。StockChartsは、Nasdaq A/Dラインについて、上場廃止された企業の負の影響が累積ラインに残るため、Nasdaq指数が上昇していてもA/Dラインが長期間低下することがあると説明しています。

#### 5.3 絶対値より形状を見る

A/Dラインは累積指標なので、データ開始日が違えば水準も変わります。したがって、異なるデータソース間で「A/Dラインの数値が高い・低い」と比較するより、同じソースでの **方向、移動平均との関係、指数との乖離** を見た方が安全です。

## マクレランオシレーター

### 6. マクレランオシレーターとは

マクレランオシレーターは、A/Dデータを使って市場内部の**短期モメンタム**を測るブレッドス指標です。StockChartsは、マクレランオシレーターを「Net AdvancesのMACD型オシレーター」と説明しており、Net Advancesの19日EMAから39日EMAを引いて作られると説明しています。

基本的な考え方は以下です。

```
McClellan Oscillator
  = 19日EMA(Net Advances) − 39日EMA(Net Advances)
```

短期EMAが中期EMAを上回るとプラス、下回るとマイナスになります。

### 7. traditional版とratio-adjusted版

マクレランオシレーターには、大きく分けて **traditional版** と **ratio-adjusted版** があります。

#### 7.1 traditional版

traditional版は、単純なNet Advancesを使います。

```
Net Advances = 上昇銘柄数 − 下落銘柄数

McClellan Oscillator
  = 19日EMA(Net Advances) − 39日EMA(Net Advances)
```

これは古典的な計算方法ですが、NYSEやNasdaqの上場銘柄数は時代によって変化するため、**長期比較では水準が歪みやすい**です。

#### 7.2 ratio-adjusted版

ratio-adjusted版は、上昇銘柄数と下落銘柄数の合計に対して、Net Advancesを比率化します。

```
RANA = (上昇銘柄数 − 下落銘柄数) / (上昇銘柄数 + 下落銘柄数)

McClellan Oscillator
  = 19日EMA(RANA) − 39日EMA(RANA)
```

StockChartsでは、取引銘柄数の変化を考慮するためにratio-adjusted版を使い、RANAを1000倍して小数を避ける説明をしています。これにより、時系列をまたいだ比較がしやすくなります。

実務上は、長期比較やダッシュボード表示では **ratio-adjusted版を標準採用** するのが無難です。StockChartsでも、`$NYMO`と`$NAMO`はratio-adjusted版、`$NYMOT`と`$NAMOT`はtraditional版として整理されています。

### 8. マクレランオシレーターの読み方

| 状態 | 解釈 |
|---|---|
| 0より上 | 上昇銘柄側のモメンタムが優勢 |
| 0より下 | 下落銘柄側のモメンタムが優勢 |
| 大きくプラス化 | ブレッドス改善、買い参加の急拡大 |
| 大きくマイナス化 | ブレッドス悪化、売り参加の急拡大 |
| マイナス圏から急反発 | ブレッドス・スラスト、底打ち候補 |
| 指数上昇中に低下 | 上昇参加銘柄の鈍化、弱気ダイバージェンス候補 |

StockChartsは、マクレランオシレーターがプラスなら上昇銘柄が優勢、マイナスなら下落銘柄が優勢とし、MACDと同様に、**ゼロライン、ダイバージェンス、ブレッドス・スラスト**を主要な見方として挙げています。

### 9. ブレッドス・スラスト

マクレランオシレーターで重要なのが、**ブレッドス・スラスト**です。これは、深いマイナス圏から強いプラス圏へ急反発する動きです。

StockChartsは、一般的にマクレランオシレーターが **-50未満から+50超へ上昇するような+100ポイント以上の急伸** をブレッドス・スラストとして説明しています。重要な底打ち局面では、売り圧力から抜け出すために強いブレッドス急回復が必要になるとされています。

ただし、ブレッドス・スラストは万能な買いシグナルではありません。指数の価格構造、主要移動平均、VIX、金利、信用スプレッド、出来高などと併用する必要があります。

## A/Dラインとマクレランオシレーターの違い

| 項目 | A/Dライン | マクレランオシレーター |
|---|---|---|
| 指標タイプ | 累積ブレッドス指標 | ブレッドス・モメンタム指標 |
| 元データ | 上昇銘柄数 − 下落銘柄数 | 上昇銘柄数 − 下落銘柄数 |
| 主な目的 | 市場参加度の中期・長期確認 | 市場内部の短期〜中期モメンタム確認 |
| 見るポイント | 高値更新、安値更新、指数との乖離 | 0ライン、急反発、ダイバージェンス |
| 注意点 | 開始点で水準が変わる | ノイズが多く、シグナル過多になりやすい |

簡単に言えば、**A/Dラインは市場内部の累積トレンド、マクレランオシレーターはA/Dラインのモメンタム**です。StockChartsも、マクレランオシレーターをA/Dラインに対するMACDのようなものと説明しています。
