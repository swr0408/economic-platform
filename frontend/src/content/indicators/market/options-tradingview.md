## オプションの見方（TradingView）

この画面は、原資産のオプション市場が、**どの価格帯・どの満期・どの方向のリスクをどう織り込んでいるか**を確認するための画面です。
商品オプションでは、原資産は現物ではなく先物価格を基準に見られることが多く、オプション価格やIVもその前提で形成されます。

画面は大きく、

- **チェーン**
- **ボラティリティ**

の2つに分かれます。

## 1. チェーン画面の見方

チェーン画面では、各ストライクごとのコール・プットの価格やギリシャ指標を確認できます。
通常は、

- 中央にストライク
- 左にコール
- 右にプット

が並びます。

まずは**現在の原資産価格に近いストライク（ATM）**を見つけ、そこを起点に周辺のストライクを比較すると分かりやすくなります。

### 主な列の意味

| 列 | 説明 |
|----|------|
| ストライク | 権利行使価格。コール・プットの価値の基準 |
| 価格 | オプションの取引価格。流動性が低いと参考値に近い場合あり |
| Bid / Ask | 買い気配と売り気配。差が広いほど流動性が低い |
| 出来高 | 当日の取引量。関心やフローの集中度を見る材料 |
| IV | オプション価格から逆算した変動期待。高いほど保険料が高い |

## 2. ギリシャ指標の意味

### デルタ（Delta）

原資産価格が少し動いたときに、オプション価格がどれくらい動くかを示します。

- コールはプラス、プットはマイナス
- ATM付近は絶対値が 0.5前後
- 深いITMは 1に近づく、遠いOTMは 0に近づく

デルタは、**方向感の強さ**と**ヘッジ量の大きさ**を見る上で最重要の指標のひとつです。

### ガンマ（Gamma）

デルタがどれくらい変わりやすいかを示します。

- ATM付近で大きい
- 満期が近いほど大きくなりやすい
- 深いITMや遠いOTMでは小さい

ガンマが高い価格帯では、**ヘッジ調整が増えやすく、短期的な値動きが大きくなりやすい**と考えられます。

### シータ（Theta）

時間の経過によってオプション価値がどれだけ減りやすいかを示します。
オプション買い手にとっては、基本的に時間経過は不利です。

- ATM付近で効きやすい
- 短期物ほど影響が大きい

### ベガ（Vega）

IVが変化したときに、オプション価格がどれくらい動くかを示します。

- ATM付近で大きくなりやすい
- 満期が長いほど大きい

ベガは、**イベント前後のボラ上昇**、**ボラティリティ売買**、**カレンダースプレッド**などを見るときに重要です。

### ロー（Rho）

金利変化に対するオプション価格の感応度です。
短期の商品オプションでは、デルタ・ガンマ・IV・ベガより優先度は低いことが多いです。

## 3. チェーン画面をどう読むか

| ステップ | 内容 |
|---------|------|
| ① | 原資産価格を確認し、ATMストライクを特定する |
| ② | ATM付近のIV・デルタ・ガンマ・ベガ・Bid/Askを確認 |
| ③ | 少し離れたストライクでスキュー（左右差）を確認 |
| ④ | Bid/Askと出来高・OIで流動性を確認 |

## 4. ボラティリティ画面の見方

ボラティリティ画面では、主に次の2つを確認します。

### ボラティリティカーブ

同じ満期で、ストライクごとのIVを並べたグラフです。

- 横軸 = ストライク
- 縦軸 = IV

**どの価格帯のオプションに高い保険料がついているか**を見るためのグラフです。

| カーブの形 | 意味 |
|-----------|------|
| ATM付近が低く、両端が高い | 両方向のテールリスクが意識されている |
| Put側だけ高い | 下方向リスクへの警戒が強い |
| Call側だけ高い | 上方向リスクへの警戒が強い |

この形は、**スマイル**や**スキュー**と呼ばれます。

### ATM IV タームストラクチャー

満期ごとのATM IVを並べたグラフです。

- 横軸 = 1W, 2W, 1M, 2M, 3M, 6M などの満期
- 縦軸 = ATM IV

**同じATM付近で、期間が変わるとIVがどう変わるか**を見ています。

| カーブの形 | 意味 |
|-----------|------|
| 短期だけ高い | 近い将来のイベントや短期不安が強い |
| 先の満期まで高い | 不安がより構造的・持続的 |
| 右下がり | 短期イベント警戒が強い |
| 右上がり | 先の期間の不確実性がより重い |

## 5. ボラティリティカーブとタームストラクチャーの違い

| | ボラティリティカーブ | タームストラクチャー |
|---|---|---|
| 横軸 | ストライク | 満期 |
| 固定 | 同じ満期 | 同じATM付近 |
| 見るもの | どの価格帯の保険料が高いか | どの期間の不安が強いか |

この2つは別物ですが、両方見ることで**どの方向を警戒しているか**、**その警戒が短期なのか中長期なのか**を整理しやすくなります。

## 6. 実務で特に重視される項目

機関投資家やディーラーがまず重視するのは、**価格そのものより、どこにリスクがたまっているか**です。

**特に重要:**
- ストライク / IV / Bid-Ask / 出来高・OI / デルタ / ガンマ / ベガ

**補助的:**
- シータ / ロー

特に短期オプションでは、ローよりもデルタ・ガンマ・IV・ベガの方が実務上の優先度は高いです。

## 7. この画面を見るときの基本手順

1. 原資産価格を確認する
2. ATMストライクを特定する
3. ATMのIV・デルタ・ガンマ・ベガを見る
4. 少し離れたストライクでスキューを見る
5. Bid/Ask、出来高、OIで流動性を確認する
6. ATM IV タームストラクチャーで期間別の不安を見る
7. ボラティリティカーブでどちらの尾リスクが高いか確認する

## まとめ

この画面は、

- **チェーン**で各ストライクの価格・IV・ギリシャ指標を見る
- **ボラティリティ**でストライク別IVの形と満期別IVの形を見る

ための画面です。

特に重要なのは、

- どこがATMか
- IVが高いか低いか
- どちら側の尾リスクが高いか
- 流動性があるか
- 短期だけ不安なのか、先まで不安なのか

を整理して読むことです。
