# Cboe Realized Volatility Index（GAMMA）

## 1. 概要

**Cboe Realized Volatility Index、ティッカー：GAMMA** は、S&P500指数オプション市場の短期的な実現ボラティリティ環境を把握するためのCboe指数です。

ただし、名前に「Realized Volatility」とありますが、これは単純にS&P500の過去リターンから標準偏差を計算した一般的な実現ボラティリティ指標ではありません。Cboeのメソドロジーでは、GAMMAは **SPXW、つまりS&P500指数の週次オプションを使った、5本の最短期ストラドルをデルタヘッジしたポートフォリオのトータルリターン指数** と定義されています。参照資産はSPXW、ロール頻度は日次、計算頻度は5秒ごと、ローンチ日は2022年12月12日、初回値日は2012年6月1日です。

## 2. 何を表す指標か

GAMMAは、実務上は次のように理解するとよいです。

> **短期SPXオプションのロング・ガンマ／ロング・ボラティリティ戦略が、どの程度有利または不利に推移しているかを見る指数。**

GAMMAの理論ポートフォリオは、SPXWの短期ATMストラドルを保有し、デルタが中立になるようにヘッジされます。Cboeのメソドロジーでは、各営業日の米東部時間16:00に、満期を迎えるオプションを失効させ、新しい1週間ATMストラドルを組み入れ、同時にSPXWオプションを用いたフォワードでポートフォリオ全体をデルタヘッジするとされています。

このため、GAMMAが上昇している局面は、一般に **短期オプションを買ってデルタヘッジする戦略が利益を出しやすい環境**、つまり実現値動きが大きい、短期ボラが強い、ガンマ・スキャルピングが効きやすい環境を示唆します。逆にGAMMAが低下している局面は、短期オプションの時間価値減少やボラ低下が勝ちやすく、ロング・ストラドル戦略にとって不利な環境を示唆します。

## 3. 読み方

| GAMMAの動き | 解釈 |
|---|---|
| 上昇 | 短期SPXオプションのロング・ボラ／ロング・ガンマ戦略が有利に推移 |
| 急上昇 | 短期的な実現変動が大きい。急落、急反発、イベント通過時に出やすい |
| 下落 | 実現値動きがオプション価格に対して小さい、または短期ボラが剥落している可能性 |
| 長期低下トレンド | 短期ボラティリティ・プレミアムが売り方優位に推移している可能性 |
| 低位安定 | SPXの短期変動が落ち着き、ガンマ・イベント色が弱い状態 |

## 4. 注意点

GAMMAで最も重要なのは、**ディーラーのGamma Exposure、いわゆるGEXとは別物**という点です。

| 誤解しやすい点 | 正しい理解 |
|---|---|
| GAMMA = GEX | 誤り。GAMMAはCboeの指数であり、SPXW短期ストラドルのデルタヘッジ済みポートフォリオ指数 |
| GAMMA = S&P500の単純な実現ボラティリティ | 誤り。価格リターンの標準偏差ではなく、オプション戦略のトータルリターン指数 |
| GAMMAの水準 = ボラティリティ％ | 誤り。GAMMAは指数値であり、198なら198%ボラという意味ではない |
| GAMMA低下 = 必ず株高 | 誤り。GAMMAは株価方向ではなく、短期オプション戦略の損益環境を表す |

したがって、GAMMAは「相場の方向」を直接予測する指標ではなく、**短期的な変動環境、イベントリスク、短期オプション市場の効き方を見る補助指標**として使うべきです。

## 5. 実務での使い方

GAMMAは、以下のような場面で有効です。

### 1. 短期ボラティリティ環境の確認

S&P500やNASDAQが大きく動いていても、GAMMAが上がっていない場合、オプション市場のロング・ガンマ戦略としてはそれほど強い環境ではない可能性があります。逆に、GAMMAが急上昇している場合は、短期的な実現変動が強く、相場が荒れている可能性があります。

### 2. VIXとの比較

VIXは主に30日程度のS&P500予想ボラティリティを見る指標です。一方、GAMMAはSPXW短期ストラドルのデルタヘッジ済み戦略パフォーマンスを表します。したがって、VIXが高くなくてもGAMMAが上昇する場合、かなり短期の値動きが強い可能性があります。

### 3. 0DTE・短期オプション環境の補助確認

GAMMAは0DTEそのものの指数ではありませんが、SPXWの短期ストラドルを使うため、短期オプション市場の緊張感を見る補助指標として使えます。特に、FOMC、CPI、雇用統計、決算集中期、急落局面では参考になります。
