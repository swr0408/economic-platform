# 円

## 安全資産通貨と低金利通貨の両面

円は、歴史的には安全資産通貨として扱われやすく、世界的な株安や金融市場の緊張が強まる局面では買われやすい通貨です。一方で、近年の円相場は「リスクオフだから常に円高」という単純な動きではなく、**日米金利差、原油価格、日本の輸入コスト、ドル全体の強弱**の影響を強く受けています。

円を見るときは「安全資産としての円」と「低金利通貨・資源輸入国通貨としての円」の両面を意識する必要があります。

## 年度末フローと実需

日本は会計年度が4月1日から翌年3月31日であり、2月末から3月末にかけては月末・期末・年度末の実需フローが意識されやすい時期です。特に東京時間では、輸出企業の円買い、決算期末に絡むフロー、機関投資家のリバランスなどが材料視されやすく、需給面から円が下支えされることがあります。

ただし、「毎年必ず大きな円高が起こる」という意味ではありません:

- 日本の経常黒字は近年、貿易黒字よりも**第一次所得収支**の寄与が大きい
- その中には再投資収益のように必ずしも国内へ還流せず、海外に残る所得も含まれる
- 「年度末＝大規模レパトリで円高」と機械的に決めつけるのは危険

安全な整理は、**「年度末は円買い需給が意識されやすい」**までです。

## 原油価格と円

原油安は円にプラス要因になりやすい、という整理は概ね妥当です。日本はエネルギー輸入依存度が高く、原油については**中東依存が9割超**とされます。

- **原油高** → 輸入コスト増加、交易条件悪化、企業収益・家計負担悪化 → 円に重し
- **原油安** → それらの負担軽減 → 円に追い風

実務上も、原油高＋円安は日本のインフレや景気に重石となりやすく、当局の警戒感を強める要因になります。

ただし、短期のドル円では、原油よりも日米金利差やドル買いの強さが優先される局面が少なくありません。日銀も、足元の為替市場では名目金利差だけでなく実質金利差も含めて注目されていると説明しています。原油安だけを見て円高を決め打ちするのではなく、**「原油」「日米金利差」「米ドル全体の方向」「株式市場のリスクセンチメント」**をセットで確認するのが基本です。

## 安全資産としての限界

円はリスクオフ局面で対ドル上昇しやすい通貨として整理されていますが、その性質も常に一定ではありません。

- 安全資産としての**ドル買い**が強まる局面では、円よりドルが優位になることがある
- **原油高**による日本の交易条件悪化が重なると、リスク回避でも円が素直に買われないことがある

昔ながらの「リスクオフ＝円高」という理解は、今でも有効な場面はあるものの、以前より**条件付き**で考える必要があります。

## 当局発言

円相場では日本当局の発言も重要です。ただし、当局が問題視するのは特定の価格水準そのものというより、**急激で一方向的な変動や過度なボラティリティ**です。円の急変時には「いくらまで行ったか」だけでなく、どの速さで、どの材料で動いたかを見る必要があります。

## 実務上の要点

円を見るうえでは、まず**日米金利差**を中心軸に置き、そのうえで原油価格、リスクオン／オフ、月末・年度末フロー、当局発言を補助材料として重ねると解像度が上がります。

| パターン | 円への影響 |
|---------|----------|
| リスクオフ＋米金利低下 | 円買いが入りやすい典型パターン |
| リスクオフ＋原油高＋ドル全面高 | ドルが優位になり、円が思ったほど買われないことがある |
| 年度末接近の東京時間 | 実需の円買いが意識されやすいが、毎年同じ規模・方向とは限らない |
| 原油安＋輸入コスト低下期待 | 円にプラス要因だが、短期では金利差に負けることがある |
