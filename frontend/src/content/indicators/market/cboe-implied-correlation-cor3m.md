# Cboe 3-Month Implied Correlation Index（COR3M）

## 1. 概要

**Cboe 3-Month Implied Correlation Index、ティッカー：COR3M** は、S&P500構成銘柄が今後3カ月間にどの程度同じ方向へ動くとオプション市場が織り込んでいるかを示す、Cboeのインプライド相関指数です。

Cboeは、Implied Correlationを「将来の分散効果に関する市場期待」と説明しており、COR3Mは **SPX指数オプションのインプライド・ボラティリティと、S&P500上位50銘柄の個別株オプションのインプライド・ボラティリティの関係から算出**されます。Cboeの説明では、COR3Mは3カ月ATMデルタ相対・定満期のSPXオプションと構成銘柄オプションのIVを使って計算されます。

## 2. 何を表す指標か

COR3Mは、簡単に言えば次の指標です。

> **S&P500の上位50銘柄が、今後3カ月間にどれだけ一斉に動きやすいと市場が見ているかを示す指標。**

Cboeのホワイトペーパーでは、COR3MはSPX指数オプションと個別構成銘柄オプションの相対的なプレミアム変化を反映し、SPX構成銘柄間の期待相関を測定するものと説明されています。

通常、S&P500の指数ボラティリティは、構成銘柄それぞれのボラティリティだけでなく、構成銘柄同士の相関によっても変化します。個別株がバラバラに動くなら、指数全体の変動は抑えられます。逆に、構成銘柄が同じ方向に動くと、指数全体の変動は大きくなります。

## 3. 計算イメージ

COR3Mの背景にある考え方は、ポートフォリオ分散の分解です。

```
指数の分散
  = 個別銘柄それぞれの分散の加重合計
  + 銘柄間の共分散・相関部分
```

Cboeのホワイトペーパーでは、SPXオプションのインプライド分散と、上位50構成銘柄のインプライド分散を比較し、そこから平均的なインプライド相関を抽出する考え方が示されています。具体的には、SPXオプションのインプライド分散から、相関がない場合の上位50銘柄ポートフォリオのインプライド分散を差し引き、それをペアワイズの加重ボラティリティ積で割ることで、平均的なインプライド相関を求める設計です。

## 4. 読み方

| COR3Mの動き | 解釈 |
|---|---|
| 上昇 | S&P500構成銘柄が同方向に動きやすいと市場が織り込んでいる |
| 急上昇 | リスクオフ、指数主導の売り、分散効果の低下、システマティックリスク上昇 |
| 低下 | 個別株・セクターごとのばらつきが大きく、分散効果が効きやすい |
| 低位安定 | 指数全体よりも個別銘柄・セクター要因が相対的に強い |
| 高位継続 | 市場がマクロ・金利・信用・政策リスクなど共通要因を強く意識している可能性 |

Cboeも、相関の上昇は分散効果の低下、システマティックリスクの増加、急激な市場変動を伴うテールイベント発生可能性の上昇と関連すると説明しています。

## 5. COR3Mで見られる相場環境

### COR3M上昇局面

COR3Mが上がる局面では、投資家は「個別株がバラバラに動く」よりも、「S&P500構成銘柄が同じ方向に動く」リスクを強く織り込んでいます。

典型的には以下のような局面です。

| 局面 | 内容 |
|---|---|
| リスクオフ | 指数全体が売られやすい |
| 金利ショック | 成長株・景気敏感株・金融株などが同時に反応しやすい |
| クレジット不安 | セクターをまたいだ売りが出やすい |
| マクロイベント前後 | CPI、FOMC、雇用統計、地政学リスクなど |
| 相場急落 | 個別要因よりも指数全体のヘッジ需要が強まる |

### COR3M低下局面

COR3Mが低下する局面では、個別株やセクターごとの違いが出やすく、指数全体の一方向リスクは相対的に低下していると解釈できます。

典型的には以下のような局面です。

| 局面 | 内容 |
|---|---|
| 決算相場 | 個別企業要因が主導しやすい |
| セクターローテーション | 指数全体より業種間格差が目立つ |
| 安定相場 | マクロショックが後退し、分散効果が効きやすい |
| ディスパージョン環境 | 指数オプションより個別株オプションの相対価値が注目されやすい |
