## CFTCポジション動向の読み方

CFTC（米商品先物取引委員会）が毎週金曜に公表する **Commitments of Traders（COT）レポート** は、先物市場の主要参加者がどのようなポジションを保有しているかを示すデータです。

## 1. レポートの種類

| レポート | 対象 | 主な分類 |
|---------|------|---------|
| TFF（Traders in Financial Futures） | 株式指数・為替・債券先物 | Dealer / Asset Manager / Leveraged / Other |
| Disaggregated | 商品先物 | Producer / Swap Dealer / Managed Money / Other |

当プラットフォームでは、**Non-Commercial（投機筋）** と **Commercial（実需筋）** のポジションを中心に表示しています。

## 2. 基本的な見方

### ネットポジション

ロング（買い持ち）からショート（売り持ち）を差し引いた値です。

- **ネットロング（プラス）**: 投機筋が上昇を見込んでいる
- **ネットショート（マイナス）**: 投機筋が下落を見込んでいる

### ポジションの増減で読む

| 変化 | 解釈 |
|------|------|
| ネットロング拡大 | 新規の買いポジションが増加 |
| ネットロング縮小 | 買いポジションの決済（利確・損切り） |
| ネットショート拡大 | 新規の売りポジションが増加 |
| ネットショート縮小 | 売りポジションの決済（ショートカバー） |

**ポジションの増減を見ることで、新規ポジションが入っているのか、既存ポジションが決済されているのかを判断できます。**

## 3. 転換点のシグナル

IMMポジション（為替先物のCFTCポジション）は、**偏りが極端になった場合に転換点のシグナル**となることがあります。

### 注意すべき水準

| シグナル | 内容 |
|---------|------|
| 過去最高水準のネットポジション | 一方向への偏りが限界に近い |
| 年初来最高のネットポジション | その年の中での極端な偏り |
| 急激なポジション増加 | 短期間での急な積み上がり |

### なぜ転換点になるのか

ポジションが極端に偏ると、以下のメカニズムで反転しやすくなります：

1. **これ以上の新規参入余地が減る** — すでに多くの参加者がポジションを持っている
2. **決済の連鎖** — 一部が利確を始めると、含み損のポジションも損切りに動く
3. **逆方向のトリガー** — ストップロスの発動が連鎖的な動きを生む

## 4. 投機筋 vs 実需筋

| | 投機筋（Non-Commercial） | 実需筋（Commercial） |
|---|---|---|
| 目的 | 利益追求 | ヘッジ |
| 動き | トレンドフォロー型 | 逆張り型 |
| 注目点 | ポジションの偏り・転換 | ヘッジ需要の変化 |

投機筋のポジションがトレンド方向に極端に偏った状態で、実需筋が逆方向に大きなポジションを持っている場合、**反転の可能性がより高まります**。

## 5. 実務での使い方

- 週次データのため、**中期的なトレンド判断**に適している
- 日々のトレード判断ではなく、**大きな方向感の確認**に使う
- 他のテクニカル分析やファンダメンタルズと**組み合わせて**判断する
- ポジションの**水準**だけでなく**変化量（前週比）**にも注目する
