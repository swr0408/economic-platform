## 指標の概要

クラックスプレッドとは、原油価格と、原油から精製される石油製品価格との差を表す指標である。主に、製油所の短期的な採算性、すなわち「原油を仕入れてガソリン・軽油・暖房油などに精製した場合の粗い利幅」を見るために使われる。

ここでいう「クラック」は、原油を熱・圧力・触媒処理などによって分解し、ガソリンや中間留分などの製品に変換する精製工程に由来する。CME Group も、RBOBガソリンやULSDなどの精製品を原油に対するスプレッドとして取引するものをクラックスプレッドと説明している。

本画面の「WTIベース」は、原油価格として WTI原油先物を基準にしていることを意味する。したがって、表示される値は「精製品価格 − WTI原油価格」の差であり、Brent原油やLLS原油を基準にしたクラックスプレッドとは数値が異なる。

## 表示系列の意味

| 系列 | 意味 | 主な見方 |
| --- | --- | --- |
| RBOB Crack | RBOBガソリン価格とWTI原油価格の差 | ガソリン市場の採算性・需給逼迫度を見る |
| ULSD Crack | ULSD価格とWTI原油価格の差 | ディーゼル・暖房油など中間留分市場の採算性を見る |
| 3:2:1 Crack | 3バレルの原油から、2バレルのガソリン、1バレルの中間留分を得ると仮定した総合スプレッド | 製油所全体の代表的な粗マージン指標 |
| WTI | WTI原油価格 | 原油コスト側の基準 |

RBOBとULSDはCME上では1契約あたり42,000ガロンで取引される。これは 1バレル＝42ガロン換算で 1,000バレルに相当する。WTI原油先物も1契約あたり1,000バレルであるため、1:1のクラックスプレッドを組みやすい設計になっている。CME も、RB・HO先物は42,000ガロン、CL先物は1,000バレルであり、1つの精製品先物と1つのWTI先物で 1:1クラックを構成できると説明している。

## 数値の読み方

### クラックスプレッドが拡大する場合

クラックスプレッドの上昇は、一般に精製品価格が原油価格よりも相対的に強いことを意味する。これは、ガソリン・ディーゼル・暖房油などの製品需給が引き締まっている、または製油所の採算が改善している可能性を示す。

主な背景例は次のとおり。

| 背景 | 影響 |
| --- | --- |
| ガソリン需要の増加 | RBOB Crackが上昇しやすい |
| ディーゼル・暖房油需要の増加 | ULSD Crackが上昇しやすい |
| 製油所の停止・メンテナンス・ハリケーン被害 | 製品供給が減り、クラックが上昇しやすい |
| 製品在庫の減少 | 精製品価格が支えられやすい |
| 原油価格の下落に対して製品価格が下がりにくい | クラックが拡大しやすい |

CME も、製油所のメンテナンスや想定外の停止、ハリケーン、冬季・夏季の季節性、製品需要、環境規制、道路交通量などをクラックスプレッドに影響する要因として挙げている。

### クラックスプレッドが縮小する場合

クラックスプレッドの低下は、一般に原油価格に対して精製品価格が弱いことを意味する。これは、製油所マージンの悪化、製品需要の鈍化、または製品供給過剰を示す場合がある。

主な背景例は次のとおり。

| 背景 | 影響 |
| --- | --- |
| 原油価格が急騰する一方、製品価格が追随しない | クラック縮小 |
| ガソリン需要の鈍化 | RBOB Crack低下 |
| ディーゼル需要の鈍化 | ULSD Crack低下 |
| 製油所稼働率の上昇による製品供給増 | 製品価格に下押し圧力 |
| 景気減速懸念 | 特にULSD Crackが弱くなりやすい |

## 3:2:1 Crackの実務的な意味

3:2:1クラックは、米国の典型的な製油所が、3バレルの原油から2バレルのガソリンと1バレルの中間留分を生産するという簡略化された前提に基づく代表的な精製マージン指標である。EIA も、3:2:1クラックを「3バレルの原油に対して、2バレルのガソリンと1バレルの留出油を得る」と仮定した指標として説明している。

ただし、これは実際の製油所利益そのものではない。EIA は、クラックスプレッドは精製マージンの推定に使われる簡便な指標であり、すべての製品収入を反映せず、原油以外の精製コストも含まないと説明している。

したがって、3:2:1クラックは「製油所の実利益ではなく、精製採算の方向感を示す近似指標」と理解するのが適切である。

## この指標で確認すべきポイント

### 1. 3:2:1 Crackが上昇しているか

3:2:1クラックが上昇している場合、ガソリン・ULSDの総合的な精製マージンが改善している可能性がある。製油所株、エネルギー株、石油製品価格、インフレ圧力を見る際の補助指標になる。

### 2. RBOB CrackとULSD Crackのどちらが主導しているか

同じ 3:2:1クラックの上昇でも、内訳は重要である。

| 主導系列 | 解釈 |
| --- | --- |
| RBOB Crack主導 | ガソリン需給、ドライブシーズン、ガソリン在庫が重要 |
| ULSD Crack主導 | ディーゼル、物流、鉱工業活動、暖房需要、ジェット燃料・中間留分需給が重要 |
| 両方上昇 | 製品全般の需給逼迫、製油所制約、原油対比での製品高を示唆 |

### 3. WTI価格と逆方向に動いているか

クラックスプレッドは単純な原油価格ではなく、精製品と原油の相対価格である。そのため、WTIが上昇していても、RBOBやULSDがそれ以上に上がればクラックは拡大する。逆に、WTIが下落しても、精製品価格がより大きく下落すればクラックは縮小する。

### 4. Brentベースとの差

WTIベースのクラックスプレッドは、米国WTIを原油コストとみなした計算である。一方、Brentベースでは原油側にBrentを使う。EIA も、クラックスプレッドでは WTI、LLS、地域別ガソリン、RBOBなど、使用する原油・製品・地域の組み合わせによって結果が変わると説明している。

そのため、WTIベースとBrentベースは次のように使い分けると分かりやすい。

| 種類 | 主な用途 |
| --- | --- |
| WTIベース | 米国WTIを基準にした精製採算・米国エネルギー市場の確認 |
| Brentベース | 国際原油価格を基準にした精製採算・グローバル比較 |
| WTI−Brent差 | 原油側の地域差・輸送制約・米国内需給の確認 |
