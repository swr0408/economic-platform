# 豪ドル（AUD）

## 資源国通貨としての豪ドル

豪ドルは、代表的な資源国通貨の一つです。豪州は鉄鉱石、石炭、天然ガスなどの輸出比率が高く、近年の輸出構成でも鉄鉱石、石炭、天然ガスが上位を占めています。RBA（豪準備銀行）も、豪ドルの長期的な決定要因として、**商品価格に強く左右される交易条件**と**主要国との金利差**を重視しています。

実務上は、豪ドルを単に「原油で動く通貨」とみるより、まず以下を優先して考える方が適切です:

- **鉄鉱石**
- **石炭**（原料炭・一般炭）
- **LNG**

原油の影響が全くないわけではありませんが、それは豪州輸出の主軸というより、世界的な商品市況やインフレ期待を通じた間接的な影響として捉える方が安全です。

## リスクセンチメントとの連動

豪ドルは短期的には世界の株式市場やリスクセンチメントと同方向に動きやすい傾向があります。RBAも、豪ドルは日々の値動きにおいてリスクセンチメントやグローバル株価と広く連動しやすいと説明しています。

- **リスクオン** → 豪ドルは買われやすい
- **リスクオフ** → 豪ドルは売られやすい

「株式が膠着している時だけ相関しやすい」というより、むしろリスク感応的な通貨の一つと整理する方が実態に近いです。

## 中国要因

豪ドルを見るうえでは、**中国要因**も非常に重要です:

- 中国は豪州最大の輸出相手国（2024-25年に豪州の財・サービス輸出の**29%**）
- RBAのTWI（貿易加重指数）でも**人民元のウェイトが最大**
- 豪ドルは資源価格だけでなく、**中国景気・鉄鋼需要・不動産やインフラ関連需要**にも反応しやすい

## 金価格との関係

豪州は主要産金国であり、金が豪州輸出の一部を占めるため、豪ドルと無関係ではありません。ただし、輸出構成やRBAの説明を踏まえると、**金は豪ドルの主軸ドライバーではなく補助材料**です。豪ドルをみる際に、金を鉄鉱石や石炭より優先するのは適切ではありません。

なお、2025年のUSGSでは世界の主要産金国は中国、ロシア、豪州、カナダ、米国の順とされています。

## 実務上の要点

豪ドルの主要ドライバー（優先順）:

| 材料 | 重要度 |
|------|--------|
| 鉄鉱石・石炭・LNG価格 | 最重要（交易条件） |
| 中国景気・鉄鋼需要 | 非常に重要 |
| RBAの金融政策・金利差 | 重要 |
| リスクセンチメント・株式市場 | 短期で影響大 |
| 金価格 | 補助材料 |
| 原油価格 | 間接的影響 |
