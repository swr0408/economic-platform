## OptionChartsの見方

[OptionCharts.io](https://optioncharts.io/) は、SPY・QQQなどの個別オプションについて、ストライク別の建玉・出来高・ガンマ／デルタエクスポージャー・スキューなどを可視化するサイトです。
この画面で見たいのは、**「今、市場のどの価格帯・どの満期に、どんなポジションとフローが集中しているか」** です。

オプション情報は、**価格を当てる道具ではなく、「ここに来たらヘッジ調整や反応が出やすい価格帯」を絞り込む補助** として使います。
必ず TradingView の水平線・VWAP・前日高値安値・EMA などのチャート節目と組み合わせて使ってください。

## 1. Open Interest by Strike：建玉の壁を見る

![Open Interest by Strike](/optioncharts/oi_by_strike.png)

### 何を見る項目か

Open Interest（OI）は、まだ決済・清算されていないオプション契約数です。
ストライク別OIは、**どの価格帯に未決済ポジションが溜まっているか** を可視化します。

OICの説明でも、両者が新規建てならOIは増加、両者が決済なら減少、一方が決済で一方が新規ならOIは変わらない、とされています。
つまりOIは「買いが多い」「売りが多い」を直接示すものではなく、**その価格に未決済ポジションが多いことを示すだけ** です。

### 実務での見方

| 位置 | 主に見るもの | 実務上の意味 |
|------|--------------|--------------|
| 現値より上 | Call OI | 上値の節目、Call Wall候補 |
| 現値より下 | Put OI | 下値の節目、Put Wall候補 |
| 現値付近 | Call / Put両方 | ピン留め、攻防、短期レンジ候補 |
| 遠いストライク | 巨大OI | 中長期建玉、ヘッジ、参考情報 |

Call＝買う権利、Put＝売る権利は正しいですが、壁を見るときは「権利の意味」だけでなく、**現値に対してOTMかITMか** を見ます。

例：SPY現値が737の場合

| ストライク | 種類 | 状態 | 見方 |
|------------|------|------|------|
| 745 Call | OTM Call | 現値より上 | 上値のCall Wall候補 |
| 730 Put  | OTM Put  | 現値より下 | 下値のPut Wall候補 |
| 745 Put  | ITM Put  | 現値より上 | 壁というより既に価値を持つPut |
| 730 Call | ITM Call | 現値より下 | 壁というより既に価値を持つCall |

短期需給の節目として見やすいのは、**現値より上のOTM Call** と **現値より下のOTM Put** です。

### 実務ルール

1. 現値を確認する
2. 現値より上のCall OI上位3つを確認する
3. 現値より下のPut OI上位3つを確認する
4. 現値付近でCall/Put両方のOIが多い価格を確認する
5. その価格をTradingViewの水平線、前日高値安値、当日高値安値などと照合する

| 判定 | 評価 |
|------|------|
| OI集中のみ | 弱い根拠 |
| OI集中 + Volume集中 | 中程度の根拠 |
| OI集中 + GEX/DEX集中 | 中程度〜強い根拠 |
| OI集中 + TradingViewの重要水平線 | 強い根拠 |
| OI集中 + Volume + GEX/DEX + チャート節目 | 最重要ゾーン |

## 2. Option Volume by Strike：当日フローを見る

![Option Volume by Strike](/optioncharts/volume_by_strike.png)

### 何を見る項目か

Volumeは、その日の取引セッション中にどのストライクでどれだけオプションが取引されたかを示します。
**OIが「残っている建玉」なら、Volumeは「今日動いたフロー」** です。

### OIとの組み合わせ

| 状況 | 解釈 |
|------|------|
| OI大 + Volume大 | 既存建玉も多く、当日も注目されている |
| OI小 + Volume大 | 新しいフローが入っている可能性 |
| OI大 + Volume小 | 建玉は残っているが、当日は動いていない |
| OI小 + Volume小 | 優先度は低い |

重要なのは、**Volumeだけでは買いか売りか分からない** ことです。
例えば740 PutのVolumeが多くても、Put買いによる下落ヘッジ、Put売りによる下値サポート狙い、既存Putの決済、スプレッド取引の一部、のどれかは断定できません。

### 0DTEではVolumeの重要度が上がる

当日満期の0DTEでは、OIは前日までのデータであり、当日の需給変化はVolumeに出ます。
そのため、0DTEでは以下の優先順位が実用的です。

| 優先度 | 項目 |
|--------|------|
| 1 | 現値近くのVolume急増 |
| 2 | GEX / DEXの集中 |
| 3 | OI集中 |
| 4 | Max Pain |
| 5 | Historical Data |

添付例（現値737.35付近）では、740〜745付近のCall Volume、738〜742付近のPut Volumeが目立っています。
これは現値周辺からやや上側に短期フローが集中している状態と読めますが、**これだけで上方向・下方向を断定してはいけません**。

## 3. Open Interest Total by Expiry：どの満期が重いかを見る

![Open Interest Total by Expiry](/optioncharts/oi_by_expiry.png)

### 何を見る項目か

満期ごとに合計OIがどれだけあるかを見るチャートです。
市場参加者がどの満期に注目しているかを把握できます。

### 実務での使い方

| 満期 | 実務上の意味 |
|------|--------------|
| 0DTE | 当日中のピン留め、急変動、Gamma影響 |
| 今週満期 | 数日単位の短期需給 |
| 月次満期 | 大きな建玉が残りやすい重要満期 |
| 四半期・長期満期 | 中長期ヘッジ、大口ポジション |

確認項目：

- 今日の満期にOIが多いか
- 今週満期にOIが多いか
- 月次満期が近いか
- Put OIとCall OIの偏りが大きいか
- 現値近くのストライクに集中しているか

## 4. Gamma Exposure / GEX：値動きの重さ・荒さを見る

![Gamma Exposure by Strike](/optioncharts/gex_by_strike.png)

### 何を見る項目か

GEXは、マーケットメーカーがガンマ中立を維持するために、**原資産価格が1%動いたときに必要とされる推定ドルヘッジ量** です。
価格がどこで重くなりやすいか、どこで荒くなりやすいかを見るための指標です。

### 基本的な考え方

| 状態 | 一般的な解釈 |
|------|--------------|
| Positive GEXが大きい | 値動きが抑制されやすい、レンジ化しやすい候補 |
| Negative GEXが大きい | 値動きが加速しやすい、ボラが出やすい候補 |
| GEXが現値付近に集中 | 現値周辺でヘッジ調整が増えやすい |
| GEXの符号が切り替わる付近 | Gamma Flip、相場の性質が変わりやすい候補 |

ただし、GEXは推定値です。
計算方法、符号、マーケットメーカーのポジション仮定はデータベンダーによって異なります。**GEX単独で売買方向を決めるのは危険** です。

### 実務での使い方

| 状況 | 実務判断 |
|------|----------|
| OI集中 + GEX集中 | 重要価格帯 |
| GEX集中のみ | 補助材料 |
| Negative GEXが下側に集中 | 下抜け時の加速リスクに注意 |
| Positive GEXが現値付近に集中 | レンジ化・ピン留め候補 |
| GEXが薄い価格帯 | 価格が通過しやすい可能性 |

添付例では、現値737.35付近を境に、下側〜現値周辺にNegative GEX、上側にPositive GEXが見えます。
下側へ崩れた場合は値動きが荒くなりやすい候補、上側では一部で値動きが抑制される候補と見ます（必ずそう動くという意味ではありません）。

## 5. Delta Exposure / DEX：方向性ヘッジ圧力を見る

![Delta Exposure by Strike](/optioncharts/dex_by_strike.png)

### 何を見る項目か

DEXは、マーケットメーカーがデルタ中立を維持するために、**原資産価格が1%動いたときに必要とされる推定ドルヘッジ量** です。
GEXが「値動きの加速・抑制」を見る指標なら、DEXは**方向性のヘッジ偏り** を見る補助指標です。

### 実務での使い方

| 見る場所 | 意味 |
|----------|------|
| 現値付近の大きなDEX | ヘッジ調整が入りやすい |
| 上側の大きなDEX | 上昇時のヘッジ圧力候補 |
| 下側の大きなDEX | 下落時のヘッジ圧力候補 |
| DEXとGEXが同じ価格帯で集中 | 重要ゾーン |
| DEXの偏りが急に変化 | ポジション調整の可能性 |

DEXもGEXと同じく、方向を当てる指標ではありません。
**「この価格帯に来たらディーラーのヘッジ調整が出やすい」** と見るのが適切です。

## 6. Volatility Skew：ヘッジ需要と警戒感を見る

![Volatility Skew](/optioncharts/volatility_skew.png)

### 何を見る項目か

ストライクごとのIV分布を見るチャートです。
CallとPutの各ストライクにおけるIVを表示し、低価格・高価格のオプションを見極める補助になります。

### 実務での見方

SPYでは、通常、下落ヘッジ需要があるためPut側IVが高くなりやすいです。
そのため、単に「Put IVが高い」だけでは材料になりません。

| 状況 | 解釈 |
|------|------|
| Put Skewが急に立つ | 下落ヘッジ需要が強まっている可能性 |
| ATM IVが上昇 | 直近イベント・急変動警戒 |
| Call側IVが大きく上昇 | 上方向の投機需要・急騰期待 |
| 期近IVが期先IVより高い | 直近イベントリスク |
| 両翼のIVが高い | 大きな変動を警戒している可能性 |

添付例では、Put側IVが高く、遠いCall側IVも上昇しています。
これは「下落だけを警戒」と見るより、**満期に近いオプションで両側のテールリスクが価格に反映されている** と見る方が安全です。

## 7. Max Pain：SPYでは低優先度の補助情報

![SPY Max Pain](/optioncharts/max_pain.png)

### 何を見る項目か

Max Painは、満期時にオプション買い手の損失が最大化し、オプション売り手の損失が最小化される理論上の価格です。
**最も多くのオプション契約が無価値で満期を迎える価格水準** を示す概念で、OIに基づくため1日1回更新されます。

### SPYでの注意点

Max Painは小型株や流動性の低い銘柄で効果が出やすく、**大型株やSPY・QQQのような指数系では効果が弱い、または適用しにくい** とされています。
したがって、SPYでMax Painを使う場合は、**メイン根拠にしてはいけません**。

| 使い方 | 評価 |
|--------|------|
| 満期前の参考価格として見る | 可 |
| OI集中価格と重なるか確認 | 可 |
| TradingViewの水平線と重なるか確認 | 可 |
| 現値が近づいたときの反応を見る | 可 |
| Max Painだけで逆張りする | 不可 |
| 必ずMax Painへ向かうと考える | 不可 |

添付例では、現値737.35に対してMax Painは743.00です。
この場合、743を「必ず向かう目標」と見るのではなく、**満期に向けた参考上側ゾーン** として扱います。

## 8. Unusual Option Activity：異常フローを確認する

![SPY Unusual Option Activity](/optioncharts/unusual_activity.png)

### 何を見る項目か

Volume-to-Open-Interest ratio（**Volume / OI比率**）によって異常な取引活動を示すものです。
「普段の建玉に対して、今日の出来高が異常に大きい契約」を探すための項目です。

### 実務での見方

1. 現値に近いストライクを優先
2. 当日満期・今週満期を優先
3. Volume / OI比率が高いものを見る
4. Volumeの絶対量も確認する
5. Option ChainでBid/AskとSpreadを確認する
6. 翌日OIが増えたか確認する

注意点として、Volume / OIが高くても、以下は断定できません：

- 買いフローか売りフローか
- 新規建てか決済か
- 単体取引かスプレッド取引の一部か
- 投機かヘッジか

添付例では、741 Call、742 Call、740 Call、743 CallなどでVolume/OI比率が高く、同時に740 Put、738 Put、735 Putなどにも大きなVolumeがあります。
これは、**740付近を中心に短期フローがかなり活発** と読むのが妥当です（方向は断定しない）。

## 9. Option Chain：最終確認用の表

![SPY Option Chain](/optioncharts/option_chain.png)

### 何を見る項目か

満期・ストライクごとの個別オプション契約を表形式で確認する画面です。

### 実務で確認する列

| 項目 | 見る理由 |
|------|----------|
| Last Price | 直近約定価格 |
| Bid | 売る場合の参考価格 |
| Ask | 買う場合の参考価格 |
| Spread | 実質的な取引コスト |
| Volume | 当日取引量 |
| Open Interest | 既存建玉 |
| Strike | 権利行使価格 |
| IV | オプション価格の割高・割安 |
| Greeks | 感応度確認 |

SPYは流動性が高いですが、満期・ストライクによってはスプレッドが広がります。
短期売買では、**Spreadが広いだけで期待値が悪化** します。

優先する契約の条件：

| 条件 | 評価 |
|------|------|
| Volumeが多い | 約定しやすい |
| OIが多い | 流動性がある可能性 |
| Bid/Askが狭い | 取引コストが低い |
| 現値に近い | 反応が出やすい |
| IVが極端すぎない | 過剰な割高を避けやすい |

## 10. Historical Data：スイング判断用の背景確認

![SPY Historical Data](/optioncharts/historical_data.png)

### 何を見る項目か

過去のオプション統計を時系列で確認できます。
IV、Put/Call Ratio、Open Interest、Volumeなどの主要オプション統計を確認できます。

### 実務で見る項目

| 項目 | 見る目的 |
|------|----------|
| Option Volume Total | オプション市場の活況度 |
| Option Volume Put-Call Ratio | 当日フローのPut/Call偏り |
| OI Total | 建玉全体が増えているか |
| OI Put-Call Ratio | 建玉構造がPut偏重かCall偏重か |
| IV 30d | 中期的な警戒感 |
| IV Rank | IVが過去比較で高いか |
| GEX Net OI | 全体のガンマ構造 |
| DEX Net OI | 全体のデルタ構造 |

添付例では、Option Volume Put-Call Ratioが1.04、OI Put-Call Ratioが2.48となっています。
これは、**当日Volumeはほぼ拮抗に近い一方、既存建玉はPut側にかなり偏っている** という見方ができます。

ただし、Put OIが多いから必ず下落するわけではありません。
SPYではヘッジ目的のPut建玉が多くなりやすいため、Put OIの多さは「下落予測」ではなく **「ヘッジ需要・防衛ライン・需給の偏り」** として読む方が安全です。

## 11. 実際の分析フロー

### デイトレ・0DTE向け

1. TradingViewでSPY / ES / NQ / VIX / 金利を確認
2. OptionChartsで当日満期を選択
3. Open Interest by StrikeでCall Wall / Put Wall候補を確認
4. Volume by Strikeで当日フローの集中価格を確認
5. GEX / DEXでヘッジ圧力の集中価格を確認
6. Max Painを補助確認
7. Unusual Activityで異常フローを確認
8. 重要価格をTradingViewに水平線として反映
9. 実際の価格反応をTradingViewで確認
10. 反応がなければ、オプション情報だけで入らない

### スイング向け

1. 今週満期・月次満期のOIを確認
2. Open Interest Total by Expiryで重要満期を特定
3. Open Interest by Strikeで大きな建玉ゾーンを確認
4. Historical DataでPut/Call RatioとOI Totalの推移を見る
5. Volatility Skewで下落ヘッジ需要を見る
6. TradingViewで日足・4時間足の水平線と照合
7. 建玉集中価格とチャート節目が重なる場所だけ採用

## 12. よくある誤解

### 誤解1：Call OIが多いから上がる

違います。
Call OIが多いということは、**そのストライクにCall建玉が多い** という意味です。
買われたCallか、売られたCallかはOIだけでは分かりません。

### 誤解2：Put OIが多いから下がる

これも違います。
Put OIは下落ヘッジ、Put売り、スプレッド、既存ポジションなど、さまざまな意味を持ちます。
特にSPYでは、**ヘッジ目的のPutが多くなりやすい** ため、Put OIの多さを単純な弱気シグナルにしない方がよいです。

### 誤解3：Max Painには必ず向かう

違います。
Max Painは理論値であり、特にSPYやQQQのような大型・高流動性商品では過信できません。

### 誤解4：GEXがある価格では必ず反発する

違います。
GEXはマーケットメーカーの推定ヘッジ量であり、実際のポジション、取引主体、ニュース、金利、VIX、指数先物の動きによって結果は変わります。
GEXは、**反発位置を当てるものではなく、値動きが重くなる・荒くなる候補を探すもの** です。

### 誤解5：Unusual Optionsは大口の方向を示す

必ずしもそうではありません。
Unusual ActivityはVolume/OI比率が高い契約を示しますが、**買いか売りか、新規か決済か、単体かスプレッドかは断定できません**。

## まとめ

OptionCharts画面で重要なのは、

- **OI**：どの価格帯に建玉が溜まっているか（壁の候補）
- **Volume**：今日どのストライクが動いているか（当日フロー）
- **GEX**：値動きの重さ・荒さ
- **DEX**：方向性のヘッジ偏り
- **Skew**：どちらの尾リスクが警戒されているか
- **Max Pain**：SPYでは補助情報として
- **Unusual Activity**：異常フローの所在
- **Historical Data**：建玉構造の時系列推移

これらを単独ではなく、**TradingViewのチャート節目と重なる価格** を抽出するためのツールとして使うのが、実務上の正しい使い方です。
