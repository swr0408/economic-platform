# 米国株のバリュー株・グロース株の見方

## 主要指数の特性

米国株では、相場全体を見るときにダウ平均、S&P500、Nasdaq-100、Russell 2000などの主要指数がよく使われます。ただし、これらはそれぞれ指数設計や構成が異なるため、単純に同じ意味で比較するのではなく、どの指数がどのタイプの銘柄を多く含みやすいかを理解したうえで使うことが重要です。

- **ダウ平均**: 30銘柄の価格加重指数
- **S&P500**: 米国大型株を広く表す浮動株調整時価総額加重指数
- **Nasdaq-100**: Nasdaq上場の大手非金融100社で構成される指数
- **Nasdaq Composite**: Nasdaq上場の国内外のcommon type stocks全体を対象とする広い指数
- **Russell 2000**: Russell 3000のうち小型株部分を表す代表的な小型株指数

実務上は、ダウ平均は相対的にバリュー・景気敏感寄り、Nasdaq-100は相対的にグロース寄り、S&P500はその中間的な大型株ベンチマークとして扱われることが多いです。ただし、これはあくまで「傾向」であり、ダウ平均そのものが正式なバリュー指数という意味ではありません。

## Style指数による比較

バリュー株とグロース株をより厳密に比較したい場合は、ダウ平均とNasdaqを対比するよりも、S&P500 Value / GrowthやRussell 1000 Value / Growthのようなstyle指数を使う方が適切です。S&Pのstyle指数は、valueとgrowthをそれぞれ定義ルールに基づいて分類しており、単なる印象論よりも精度の高い比較ができます。

## 実質金利とグロース/バリューの関係

グロース株とバリュー株の相対優位を考えるうえで重要なのが、実質金利の動きです。一般に、実質金利が上昇すると将来利益の現在価値が割り引かれやすくなるため、遠い将来の成長期待を織り込みやすいグロース株には逆風になりやすく、相対的にはバリュー株が優位になりやすい傾向があります。逆に、実質金利が低下する局面ではグロース株が支えられやすくなります。MSCIの分析でも、実質金利の低下局面ではGrowthがValueに対して優位になりやすく、上昇局面では逆の傾向が出やすいことが示されています。

そのため、インフレ再加速や利上げ観測の強まりは、一般にはグロース株、特に大型テクノロジー株が多いNasdaq-100にとって下押し材料になりやすいです。反対に、ディスインフレや利下げ観測の強まりは、実質金利低下を通じてグロース株を支えやすくなります。ただし、これはあくまで一般論であり、実際の市場ではAIなどの強い成長テーマ、利益見通しの上方修正、指数集中などにより、金利動向と株価の関係が一時的に弱まることもあります。したがって、**「金利が上がるから必ずグロース安」「金利が下がるから必ずバリュー高」** のような単純化は避けた方が安全です。

## バリュー株のセクター特性

バリュー株として意識されやすいセクターには、金融、資本財、素材、エネルギーなどがあります。これらは景気改善やインフレ再加速の局面で買われやすいことがありますが、単に金利が上がれば常に有利というわけではありません。たとえば金融株は、利ざや改善期待が追い風になることがある一方で、景気悪化や信用コスト上昇を伴う金利上昇局面では逆風にもなり得ます。資源株や素材株も、金利そのものというより、需要見通し、商品市況、景気循環の影響を強く受けます。したがって、バリュー優位を判断する際は、金利だけでなく景気と需給の文脈もあわせて見る必要があります。これはstyleの一般論というより、指数やセクターの性格を踏まえた実務上の見方です。

## Nasdaq-100とNasdaq Compositeの違い

Nasdaqに関しては、Nasdaq-100とNasdaq Compositeを区別して見ることが有効です。Nasdaq-100はNasdaq上場の大手非金融100社で構成されるため、大型テクノロジー株や成長株の影響を強く受けます。一方、Nasdaq CompositeはNasdaq上場株全体を広く含むため、より裾野の広い動きを反映します。このため、Nasdaq-100の上昇が目立つときは「大型グロース主導」の相場である可能性があり、Nasdaq Compositeまで幅広く強いときは、より広い銘柄群へ買いが広がっている可能性があります。単に「Nasdaqが強いから他市場にも好材料」と考えるのではなく、上昇の中身が大型グロース集中なのか、市場全体へ波及しているのかを見分ける視点が重要です。

## S&P500 Equal Weightとの比較

米国株全体の上昇が一部大型株に偏っているのか、それとも市場全体に広がっているのかを見るうえでは、通常のS&P500とS&P500 Equal Weightの比較も有効です。S&P500 Equal Weightは、通常の時価総額加重のS&P500と同じ構成銘柄を使いながら、各銘柄を均等ウェイトで組み入れた指数です。そのため、通常のS&P500だけが強く、Equal Weightが弱い場合は、一部大型株への集中が強い相場である可能性があります。逆に、Equal Weightも強い場合は、上昇がより幅広い銘柄に広がっていると解釈しやすくなります。

## Russell 2000と小型株

Russell 2000は、小型株の代表指数として、金融環境や国内景気への感応度が比較的高いと見られています。小型株は大型株より資金調達面で不利になりやすく、借入条件の影響を受けやすい傾向があります。そのため、利下げ観測や金融緩和期待はRussell 2000にとって支援材料になりやすいです。FTSE Russellも、借入金利の低下は現金余力や資金調達手段が限られやすい小規模企業により恩恵を与えやすいと述べています。ただし、小型株は景気鈍化や信用不安にも弱いため、「利下げ期待だから常に小型株高」とは限らず、景気悪化懸念との綱引きになる点には注意が必要です。
