# VIX先物カーブ（M1-M3）の見方

## 概要

VIX先物カーブは、**Cboe Futures Exchange（CFE）** で取引される **Cboe Volatility Index Futures（VX futures）** の限月別価格から作成するボラティリティ市場のタームストラクチャーです。VIX先物は、Cboeの説明では「将来の特定満期日におけるVIX指数水準に対する市場の推定値を反映する商品」と位置付けられています。

スポットVIXやVIX3Mは、SPX/SPXWオプション価格から算出される **キャッシュ（インデックス）** のボラティリティ指数です。VIXは30日先の期待ボラティリティ、VIX3Mは3か月のインプライド・ボラティリティを一定満期で測ります。これに対して、VX先物カーブは **実際に取引される限月別先物価格** から作られるため、短期ボラティリティの需給、ヘッジ需要、ロール圧力、イベント前後の歪みを **VIX/VIX3Mより直接的に観察しやすい** 指標です。

ただし、VX先物価格は「ヘッジ需要だけ」を純粋に表すものではありません。**将来のVIX水準への期待、リスクプレミアム、ポジション需給、裁定、イベントリスク、金利・証拠金・流動性条件など**が合成された市場価格として扱う必要があります。

## 使用する限月：VX1 / VX2 / VX3

本カードでは、月次VIX先物のうち、満期が近い順に以下の3本を使います。

| 表記 | 意味 |
|---|---|
| VX1 / M1 | 第1限月、最も満期が近い月次VIX先物 |
| VX2 / M2 | 第2限月 |
| VX3 / M3 | 第3限月 |

CFEはVIX先物について **月次限月** に加えて **週次限月** も上場しています。Cboeの当日セトル一覧にも、月次VXだけでなく、VX21、VX22 のような週次限月コードが並ぶ場合があります。M1-M3カーブを月次ベースで作る場合は、**週次VIX先物を除外し、月次VXのみ** を抽出する必要があります。

月次VX先物の **最終決済日** は、原則として「その先物限月の翌月第3金曜日の30日前にあたる水曜日」です。最終決済日を境に対象限月が入れ替わるため、日次セトル系列ではこのタイミングでM1/M2/M3の参照対象がローテーション（ロール）します。

## 主要指標

### 1. フロントスプレッド：VX1 − VX2

フロントスプレッドは、最も重要な基本指標です。

```
Front Spread = VX1 − VX2
```

| 値 | 状態 | 解釈 |
|---|---|---|
| プラス | バックワーデーション | 期近のVX1がVX2より高い。短期ストレス、イベント警戒、急なヘッジ需要を示しやすい |
| ゼロ近辺 | フラット | 短期ボラティリティの織り込みが中立化している状態 |
| マイナス | コンタンゴ | 通常時に多い形。VX1がVX2より低く、短期VIXロングETPにはロールコストが発生しやすい |

Cboeの当日セトル一覧では、各限月のシンボル、満期日、Settlement Priceが確認できます。

### 2. ダブルスプレッド／曲率：VX1 − 2×VX2 + VX3

ダブルスプレッドまたは曲率は、M1・M2・M3のカーブ形状の歪みを見る指標です。

```
Curvature = VX1 − 2 × VX2 + VX3
          = (VX1 − VX2) − (VX2 − VX3)
          = 2 × { (VX1 + VX3) / 2 − VX2 }
```

これは、M2がVX1とVX3の直線補間に対してどの位置にあるかを見る指標です。

| 値 | 解釈 |
|---|---|
| プラス方向 | VX2がVX1とVX3の中点より低い。フロント側の歪みが強く、M1が相対的に強い、またはM2が相対的に沈んでいる |
| ゼロ近辺 | M1〜M3がほぼ直線的に並んでいる |
| マイナス方向 | VX2がVX1とVX3の中点より高い。M2側にボラ需要が残っている、またはM1だけが相対的に低い |

ここで重要なのは、**マイナス方向＝必ずM1だけが弱い、とは限らない** 点です。曲率はあくまで3点の形状指標なので、M2がイベントリスクで高い場合、M1が低い場合、M3が低い場合など、複数の原因でマイナスになります。

曲率は、単純なM1-M2スプレッドだけでは分からない **フロント3限月の形状の歪み** を確認するために使う指標です。特に、ストレスがM1だけに集中しているのか、M2/M3側まで残っているのかを切り分けるのに有効です。なお、曲率も最終決済日前後にはM1/M2/M3の参照対象が切り替わるため、**ロール日には不連続が出ます**。単純スロープより形状の歪みを見やすい、という位置付けで扱うのが適切です。

### 3. M1-M3スロープ：VX1 − VX3

M1-M3スロープは、フロント3限月全体の傾きを見る指標です。

```
M1-M3 Slope = VX1 − VX3
```

| 値 | 状態 | 解釈 |
|---|---|---|
| プラス | フロント3限月がバックワーデーション | 短期ボラ需要が強く、ストレスがフロントカーブ全体に波及している |
| ゼロ近辺 | フラット | 短期から3限月までのボラ織り込みが均衡 |
| マイナス | コンタンゴ | 通常環境。先の限月ほど高い |

M1-M3スロープは、曲率とは違い、カーブの「折れ曲がり」ではなく、単純にM1とM3の **高低差** を見るものです。フロントスプレッド・曲率・M1-M3スロープは性質が異なるため、分けて表示するのが望ましいです。

## M1残存日数（DTE）の見方

VIX先物カーブを見る際は、スプレッド水準だけでなく、**M1の満期までの残存日数（DTE）** も重要です。VX先物の最終決済日は原則として水曜日であり、満期が近づくほどM1はスポットVIXや最終決済値への収束を意識しやすくなります。

ただし、DTE別の挙動は **公式ルールではなく、経験則・統計検証の対象** です。以下は実務上よく言われる傾向として参照してください。

| DTE | 経験的に観察されやすい傾向 |
|---|---|
| 15日以上 | まだ満期まで余裕があり、M1はイベントリスクやボラティリティ期待を比較的広く反映しやすい |
| 5〜10日 | ロールと満期接近の影響が強まり、M1-M2スプレッドの変動が大きくなりやすい |
| 2日以下 | M1が最終決済・スポットVIXに近づき、フロントスプレッドが急変しやすい |

「フロント月の残存日数が約18日ある段階としては、スプレッド水準が高く粘着的」というような表現は、DTEとスプレッド水準を組み合わせた **実務的な経験則** です。これは公式仕様ではなく、過去データで検証すべき見方として扱うのが安全です。

## 短期VIX ETPとの関係

VXX、VIXY、UVXYなどの **ロング系短期VIX商品** は、基本的に第1限月・第2限月VIX先物を日次でロールする **短期VIX先物指数** の性質を持ちます。S&P 500 VIX Short-Term Futures Indexは、近い2本のVIX先物を使い、期近から次限月へ日次でロールする構造で、一定の1か月ロングポジションを再現する指数です。

フロントスプレッドを `VX1 − VX2` と定義する場合、**ロング系** 短期VIX ETPのロール環境は以下のように整理できます。

| フロントスプレッド | カーブ | ロング系VIX ETPへの影響 |
|---|---|---|
| マイナス | コンタンゴ | 期近を売って高い次限月を買うため、ロールコストが発生しやすい |
| ゼロ近辺 | フラット | ロールコストの影響が小さい |
| プラス | バックワーデーション | 期近を売って安い次限月を買うため、ロール面では有利になりやすい |

一方、SVXYのような **インバース系商品** は、ロング系短期VIX ETPと方向が逆になります。コンタンゴ環境ではインバース系に追い風、バックワーデーション環境ではインバース系に逆風、という関係です。ロング系とインバース系をまとめて説明しないよう注意してください。

実際のETP価格は、先物価格変動、レバレッジ、日次リバランス、手数料、トラッキング誤差にも左右されます。「フロントスプレッド＝ETPロール利回り」とは断定せず、ロール環境を方向感として読み取る用途に留めるのが安全です。

## ロール利回りの表現

ロング系短期VIX ETPのロール寄与は、概念的には次のように整理できます。

```
日次でM1からM2へ乗り換える際の価格差に左右される。

Front Spread = VX1 − VX2 と定義する場合、
  Front Spread < 0（コンタンゴ）  → ロール寄与は不利
  Front Spread > 0（バックワーデーション） → ロール寄与は有利
```

式を載せる場合は、概算として以下に留めるのが適切です。

```
概算ロール寄与 ≒ 日次ロール比率 × (VX1 − VX2) / 加重平均先物価格
```

ただし、これは簡略式であり、実際の指数リターンは公式指数メソドロジーのウェイト、先物価格変動、日次リバランスによって決まります。

## 実務での読み方

### 1. 通常コンタンゴ環境

```
VX1 < VX2 < VX3
Front Spread < 0
M1-M3 Slope  < 0
```

平時のVIX先物カーブでよく見られる形です。スポットVIXや期近ボラティリティが低く、将来の不確実性に対するプレミアムが奥の限月に残っている状態です。ロング系短期VIX ETPにはロールコストが発生しやすく、インバース系短期VIX ETPには追い風になりやすい局面です。

### 2. フロント・バックワーデーション

```
VX1 > VX2
Front Spread > 0
```

期近のボラティリティ需要が急増している状態です。株式市場の急落、重要イベント、金融不安、地政学リスク、急なヘッジ需要などで発生しやすい形です。ロング系商品は先物価格上昇とロール面の両方で有利になりやすい一方、インバース系商品やショートボラ戦略には大きな損失リスクが生じます。

### 3. 曲率が大きくプラス

```
VX1 − 2×VX2 + VX3 > 0
```

M1が相対的に高い、またはM2が相対的に低い状態です。短期イベントにボラ需要が集中している可能性があります。

ただし、曲率だけで「イベント通過後に必ずボラが剥落する」とは判断できません。スポットVIX、SPXの下落率、VIX9D、SKEW、VVIX、オプション満期、FOMC/CPI/雇用統計などのイベント日程と合わせて確認する必要があります。

### 4. 曲率が大きくマイナス

```
VX1 − 2×VX2 + VX3 < 0
```

M2がVX1とVX3の中点より高い状態です。これは、M1より少し先の限月にイベントリスクやヘッジ需要が残っている可能性を示します。「M1だけが安いから市場が完全に落ち着いている」と短絡しない方がよく、M2/M3側が下がりにくい場合、ボラティリティ市場はまだ先のリスクを織り込んでいる可能性があります。

## 注意点

### 1. 月次VXと週次VXを混ぜない

Cboeの一覧には、月次VXと週次VXが同時に表示されることがあります。M1-M3の月次カーブを作る場合は、**週次限月を除外し、月次限月だけでVX1/VX2/VX3を定義** してください。

### 2. SettleとCloseを混同しない

カードの基準値は **CFEのDaily Settlement Price**（公式決済値）を使うのが望ましいです。Cboeのセトルページでは、各限月のSettlement Priceが確認できます。取引時間中のLastや終値とは異なる可能性があるため、データ定義は **「settle基準」と明記** してください。

### 3. ロール日前後の不連続を処理する

M1が最終決済日を迎えると、それまでのM2が新しいM1になります。連続時系列として見る場合、スプレッド系列には構造的な不連続が発生します。

| 方法 | 内容 |
|---|---|
| ロール日フラグ | ロール日前後に印を付ける |
| DTE表示 | M1残存日数を必ず併記する |
| ロール日前後除外 | 統計判定ではDTE 1〜2日を除外する |
| パーセンタイル化 | DTEバケット別にスプレッド水準を評価する |

### 4. 「歴史的に高い・低い」はDTE別に見る

同じ `VX1 − VX2 = −2.0` でも、DTEが18日ある場合と2日しかない場合では意味が異なります。単純な全期間パーセンタイルではなく、以下のようなDTE別評価が望ましいです。

- DTE 15〜20日の中で、現在のFront Spreadが何パーセンタイルか
- DTE 10〜15日の中で、現在のCurvatureが何パーセンタイルか
- DTE 5〜10日の中で、現在のM1-M3 Slopeが何パーセンタイルか

これにより、「残存18日としては高い／低い」という実務的な表現が可能になります。

### 5. キャッシュVIX / VIX3Mとの違い

スポットVIXや定常満期のVIX3Mは、SPXオプションから算出される指数で、実際の先物価格ではありません。先物カーブの方が、需給・ヘッジ・ロール圧力に直接対応します。
