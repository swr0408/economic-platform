## 銀行金利（MIR：MFI Interest Rate Statistics）

銀行金利（MIR）は、ユーロ圏の金融機関が家計・非金融企業に適用している預金金利・貸出金利を集計したECBの統計です。ECBでは、ユーロ圏居住のMFI（Monetary Financial Institutions、中央銀行・マネーマーケットファンドを除く金融機関）が、ユーロ建ての預金・貸出について、家計および非金融企業に適用する金利を対象としています。MIRは、金融政策が銀行貸出金利・預金金利へどの程度波及しているか、また企業金融・住宅ローン環境がどの程度引き締まっているかを確認するために使われます。

## 1. 指標の基本的な意味

MIRは、単なる政策金利ではなく、実際に銀行と顧客の間で合意された金利を集計した統計です。ECBの説明では、MFI金利統計は銀行と顧客の間で個別に合意された金利を年率換算し、年率パーセントで表示するものとされています。ユーロ圏全体では、新規取引と残高ベースを含む多数の金利系列が収集されています。

主に確認すべき対象は、企業向け貸出金利、住宅ローン金利、消費者ローン金利、家計・企業の預金金利です。特に景気・金融環境を見る場合は、企業向け貸出金利と住宅ローン金利が重要です。企業向け貸出金利は設備投資・資金繰り・企業信用環境に影響し、住宅ローン金利は住宅購入需要・住宅価格・家計の金利負担に影響します。

## 2. 新規貸出金利と残高ベース金利の違い

MIRを見る際は、「New business（新規取引）」と「Outstanding amounts（残高ベース）」を明確に区別する必要があります。

新規取引は、当月中に新たに合意された預金・貸出契約、または既存契約の条件変更・再交渉を含みます。一方、自動更新されただけで顧客や銀行が積極的に条件を再交渉していない契約は、新規取引には含まれません。残高ベースは、既に存在している預金・貸出残高全体に適用されている金利を示します。

市場分析では、新規取引金利の方が金融環境の変化を早く反映しやすいです。残高ベース金利は既存契約の平均的な金利負担を示すため、政策金利の変更に対して遅れて動きやすくなります。

## 3. 企業向け貸出金利の見方

企業向け貸出金利は、ユーロ圏企業が銀行から資金を借りる際の資金調達コストを示します。上昇している場合、企業の借入コストが高まり、設備投資、在庫投資、M&A、運転資金需要を抑制しやすくなります。低下している場合は、企業金融環境が緩和方向に向かっている可能性があります。

ただし、企業向けMIRには複数の系列があります。例えば、貸出金額が「25万ユーロ以下」「25万ユーロ超100万ユーロ以下」「100万ユーロ超」などに分かれる系列や、金利固定期間が「変動金利・3か月以内」「3か月超1年以内」「1年超」などに分かれる系列があります。したがって、グラフの凡例で単に「企業向け」と表示する場合でも、ヘルプでは対象が「総合的な企業借入コスト」なのか、「特定条件の企業向け新規貸出金利」なのかを明記する必要があります。ECBの最新リリースでも、企業向け貸出については金額区分・金利固定期間別の金利が個別に示されています。

企業向け金利を見る際は、特に以下を確認します。

| 見るポイント | 解釈 |
| --- | --- |
| 企業向け貸出金利の上昇 | 企業の借入コスト上昇。投資・在庫・資金繰りに下押し圧力。 |
| 企業向け貸出金利の低下 | 金融環境の緩和。資金調達負担の軽減。 |
| 政策金利との乖離 | ECB利下げ・利上げが銀行貸出金利へどの程度波及しているかを確認。 |
| 小口貸出と大口貸出の差 | 中小企業向け信用環境と大企業向け信用環境の違いを見る材料。 |
| 国別差 | ユーロ圏内の金融分断・信用リスク差・銀行システム差を確認。 |

## 4. 住宅ローン金利の見方

住宅ローン金利は、家計の住宅購入コストを示す重要な金利です。住宅ローン金利が上昇すると、住宅購入の月々返済負担が増え、住宅需要・住宅価格・建設投資を抑制しやすくなります。低下している場合は、住宅取得環境が改善し、住宅市場の下支え要因になります。

ECBの住宅ローン系列は、主に「家計向け住宅購入ローン」を対象とし、変動金利・固定期間別に細かく分類されています。例えば、変動金利または金利固定期間1年以内、1年超5年以内、5年超10年以内、10年超などの系列があります。ECB Data Portalでは、住宅購入ローンの一部系列について、月次、ユーロ圏、年率パーセント、家計・対家計非営利団体向け、新規取引といった条件が明示されています。

住宅ローン金利を見る際は、短期固定・変動型と長期固定型を分けて見ることが重要です。変動型・短期固定型は政策金利や短期市場金利の影響を受けやすく、長期固定型は長期金利、スワップ金利、銀行の長期調達コストの影響を受けやすくなります。

## 5. Composite Cost of Borrowingとの違い

ECBには、個別の銀行貸出金利系列とは別に、Composite Cost of Borrowing Indicator（総合借入コスト指標）があります。これはMFI金利統計を基に、非金融企業および住宅購入目的の家計向け貸出コストをより比較しやすくするために作られた総合指標です。ECBは、企業向け・住宅ローン向けの短期・長期貸出金利を基礎に、借入コストを評価するための指標として説明しています。

総合借入コスト指標は、個別の貸出金利系列を単純平均したものではありません。ECBのリリースでは、過度な月次変動を抑えるため、新規取引額の24か月移動平均を用いたウェイト付けが使われると説明されています。そのため、個別系列の前月比変化だけで総合借入コスト指標の動きを完全に説明することはできません。

掲載時には、以下を明確に区別してください。

| 表示名 | 内容 |
| --- | --- |
| 企業向け貸出金利 | 特定条件の企業向け新規貸出金利である可能性がある。金額区分・金利固定期間を確認する。 |
| 住宅ローン金利 | 家計向け住宅購入ローンの金利。固定期間別系列と総合指標を区別する。 |
| Composite Cost of Borrowing | 複数系列を基にした総合的な借入コスト指標。単純な個別金利ではない。 |

## 6. 金利上昇・低下の市場インプリケーション

MIRが上昇している局面では、銀行経由の金融環境が引き締まっていると判断しやすくなります。企業向け金利上昇は、設備投資や企業信用に対する下押し要因となり、住宅ローン金利上昇は、住宅需要や不動産価格に対する下押し要因となります。特に、金利上昇が長期間続く場合は、貸出需要の減少、信用成長の鈍化、住宅市場の減速、企業収益の圧迫につながりやすくなります。

一方、MIRが低下している局面では、銀行貸出環境が緩和方向にあると見られます。ただし、金利が低下しても、銀行の貸出基準が厳しい場合や、景気不安によって借入需要が弱い場合には、実体経済への波及は限定的になります。そのため、MIRだけで景気回復を判断するのではなく、貸出量、銀行貸出調査、企業景況感、住宅価格、信用スプレッドと併せて見る必要があります。
