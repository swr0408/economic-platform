## CISSとは

CISSは **Composite Indicator of Systemic Stress** の略で、ECBが公表している金融システム全体のストレス度合いを示す複合指標である。日本語では「システミックストレス指標」「金融システムストレス指標」などと訳せる。

CISSは、単に株価が下落している、金利が上昇している、為替が変動しているといった個別市場の動きだけを見る指標ではない。金融仲介機関、短期金融市場、株式市場、債券市場、外国為替市場など、複数の市場セグメントで同時にストレスが高まっているかを確認するための指標である。そのため、CISSは「市場全体の緊張度」や「金融不安の広がり」を見る目的に適している。

## 何を見るための指標か

CISSで確認するべき中心点は、次の3つである。

第一に、金融市場全体でストレスが高まっているかどうかである。株式だけ、債券だけ、為替だけではなく、複数市場にまたがる緊張を確認する。

第二に、ストレスが一時的な市場変動にとどまっているのか、金融システム全体に広がっているのかを見る。CISSは、複数市場のストレスが同時に高まる局面で上昇しやすい設計になっている。

第三に、リスクオン・リスクオフ環境の確認に使う。CISSが上昇している局面では、株式やクレジットなどリスク資産への警戒が強まりやすく、安全資産需要、流動性選好、信用スプレッド拡大などが起こりやすくなる。

## 構成分野

CISSは、主に以下の5つの市場セグメントから構成される。

| 分野 | 主な意味 |
| --- | --- |
| 金融仲介機関 | 銀行・金融機関セクターのストレス |
| 短期金融市場 | 銀行間金利、短期資金調達、流動性ストレス |
| 株式市場 | 株価変動、株式市場の損失・ボラティリティ |
| 債券市場 | 国債・社債市場のボラティリティ、信用スプレッド |
| 外国為替市場 | ユーロ為替の変動、為替市場のストレス |

ECBの元論文では、各分野に複数の市場ベース指標を割り当て、それらを標準化したうえでサブインデックス化し、最終的に統合してCISSを算出している。

## 代表的な入力指標

CISSは、主に以下のような市場指標を使う。

**短期金融市場**では、3か月Euriborの変動、3か月Euriborと短期国債利回りのスプレッド、ECBの限界貸出ファシリティ利用などが含まれる。

**債券市場**では、ドイツ10年国債関連のボラティリティ、社債と国債の利回りスプレッド、10年スワップスプレッドなどが使われる。

**株式市場**では、非金融株の実現ボラティリティ、株価下落率を示すCMAX、株式・債券相関などが使われる。

**金融仲介機関**では、銀行株の市場全体に対する固有リターンのボラティリティ、金融債と非金融債のスプレッド、金融セクターの株価下落とバリュエーション悪化を組み合わせた指標などが使われる。

**外国為替市場**では、ユーロの対ドル、対円、対ポンドなどの為替変動が使われる。

## 算出方法の考え方

CISSの重要な特徴は、単純平均ではなく、複数市場のストレスが同時に高まっているかを重視する点である。

一般的な金融ストレス指標は、複数の市場指標を標準化して平均するだけの場合がある。しかしCISSは、各市場セグメントのストレス指標をサブインデックス化したうえで、それらの相関関係も考慮して統合する。

つまり、ある1市場だけでストレスが高い場合よりも、複数市場で同時にストレスが高まり、それらが連動している場合のほうが、CISSはより強く上昇しやすくなる。これは「金融ストレスが広範囲に波及しているほど、システミックリスクが高い」という考え方に基づいている。

## 数値の読み方

CISSは単位を持たない指数である。基本的には、値が高いほど金融システムのストレスが高く、値が低いほどストレスが低いと解釈する。

ただし、CISSは「景気後退確率」や「金融危機確率」を直接示す指標ではない。例えばCISSが0.30だから金融危機確率が30%という意味ではない。

実務上は、絶対水準だけでなく、以下を確認する。

| 見るポイント | 解釈 |
| --- | --- |
| 水準 | 現在の金融ストレスが高いか低いか |
| 変化方向 | ストレスが上昇中か低下中か |
| 上昇速度 | 急速に金融不安が広がっているか |
| 高止まり期間 | 一時的ショックか、継続的ストレスか |
| 他市場との整合性 | 株安、信用スプレッド拡大、金利低下、ドル高などと整合するか |

## 目安となる水準

ECBが公式に「この水準を超えたら危機」といった固定閾値を示しているわけではない。そのため、解釈の際には公式閾値のように断定しないことが重要である。

実務上は、過去分布との比較で便宜的に以下のように整理できる。

| CISSの状態 | 実務上の見方 |
| --- | --- |
| 低位 | 金融市場のストレスは限定的 |
| 平均的な範囲 | 通常の市場変動の範囲 |
| 上位25%程度 | ややストレスが高い |
| 上位10%程度 | 金融環境の悪化に注意 |
| 上位5%程度 | 明確なストレス局面 |
| 上位1%程度 | 危機的・準危機的なストレス局面 |

ただし、この区分は公式分類ではなく、過去データの分布に基づく便宜的な目安である。実際の判断では、株式、債券、クレジット、為替、銀行株、短期金融市場の状況と合わせて確認する必要がある。

## 市場分析での使い方

CISSは、単独で売買判断に使うよりも、マクロ・流動性・信用リスクの確認指標として使うのが適切である。

**株式市場**では、CISSが低位で低下傾向ならリスクオン環境を確認しやすくなる。一方、CISSが急上昇している場合は、株価指数の下落、銀行株の弱さ、信用スプレッド拡大、ボラティリティ上昇が連動している可能性がある。

**債券市場**では、CISS上昇時に安全資産需要が強まると、ドイツ国債や米国債などに買いが入りやすくなる。ただし、インフレ・財政不安・国債需給悪化が原因の場合は、国債利回りが必ず低下するとは限らない。

**為替市場**では、CISS上昇時にユーロ安、ドル高、円高などの安全通貨選好が出ることがある。ただし、原因が欧州固有の金融不安か、グローバルなリスクオフかによって反応は異なる。

**クレジット市場**では、CISS上昇時に社債スプレッド、銀行債スプレッド、CDSなどの拡大を確認することが重要である。CISS上昇と信用スプレッド拡大が同時に進む場合は、金融ストレスの質が悪化している可能性がある。
